# 승인한 S-06 원본 전달 위치

이 폴더에 마지막으로 승인한 ‘상자 안의 종이왕’ PNG 한 장을 원래 파일명 그대로 올린다. 현재 대화의 인라인 PNG는 시각 입력으로 보이지만 작업 도구에 원본 경로나 다운로드 ID가 전달되지 않아, 저장소 파일 경로로 우회한다. 같은 방식의 채팅 재첨부를 요구하지 않는다.

업로드 후 개발 측 작업:

1. 이 폴더의 새 PNG를 직접 열어 승인한 그림과 대조한다.
2. 원본과 SHA256을 보존하고 실제 격자를 확인해 `public/scenes/shipping-company.png`로 반입한다.
3. S-06 운송 컷에 연결하고 완성 원화 위의 전투용 배우 합성을 제거한다. 실제 생존자 대사 분기는 유지한다.
4. 667×375 / 915×412 / 1024×768 / 1280×720에서 인물·대사 가림·패턴 뭉침을 검수하고 기존 사건·보스와 대조한다.

이 안내 파일은 원본 수령이나 반입 완료를 뜻하지 않는다. 원본 수령 전 기존 게임 그림과 실행 각본은 바꾸지 않는다. main 병합·APK 빌드는 별도 요청 전 실행하지 않는다.
