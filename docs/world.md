# 체크메이트 공장의 세계와 용어 (D-425)

현재 이야기·진행 정본은 [본편 3장과 선택 도전](brief/scenario-runtime.md), 선택한 주제는 [시나리오 핵심](brief/scenario-core.md)이다. 옛 소설·반품 회귀·13겹의 비밀은 사용하지 않는다. 아래 §4~§6은 시각 언어와 이름 규칙으로 계속 사용한다.

## 0. 고정 전제

1. 공장에서 흰 세트와 검은 세트가 싸운다.
2. 우리 세트의 킹 자리에는 종이 왕관을 쓴 아홉 번째 폰이 들어갔다.
3. 지면 세트가 녹는다.
4. 공정을 모두 넘으면 출하할 수 있다.

## 1. 공장과 판정

공장의 서열은 만들어진 몸을 자격으로 삼는다. 폰은 킹이 되지 않고도 킹 자리에서 분대를 지휘한다. 게임의 K는 그 지휘 역할이며, 진엔딩을 위해 전투 중 일부러 폰 행마로 바뀌는 조건은 없다.

승리는 실제 출하의 자격이다. 바깥의 멸시와 반품까지 없애지는 못한다. 도금왕은 밖으로 나가기 싫어 왕좌를 지키고, 도전자가 지위를 빼앗을까 경비를 강화한다. 승자는 남에게 평가받는 상품 대신 남을 판정하는 왕의 몸을 택할 수 있다.

## 2. 종이왕의 변화

함께 나가려던 사람이 자기만 왕으로 남는다. 동료들은 살아서 출하하되 그가 오지 않았음을 겪는다. 마지막 폰은 그 유혹을 원하면서도 불량인 몸과 동료를 택할 수 있다. 정품으로 인정받거나 공장을 정지시켜야만 가능한 구원이 아니다. 아이와 부모는 선택 뒤의 짧은 에필로그에만 나온다.

## 3. 플레이와 인물의 동일성

| 단위/규칙 | 현재 세계와의 연결 |
|---|---|
| 본편 1~3장 | 각 장의 새로운 폰과 분대. 앞의 왕이 실제로 새긴 경비 규정을 다음 분대가 만난다 |
| 한 판 안의 1~3막 | 주조·조립·검수 공정. 이후 종막 출하구에서 도금왕과 싸운다 |
| 흰/검은 세트 | 같은 공장에서 살기 위해 싸우는 기물들. 검은색 자체가 악의 본질은 아니다 |
| 흠집·기벽 | 수리할 상처와 남아도 되는 차이. 체스 본래의 행마를 불량 사유로 삼지 않는다 |
| 대국의 쓰러짐 | 심장 톱니 손상. 남은 톱니와 정비로 복귀할 수 있으나, 영구 폐기는 원부에 남는다 |
| 세트의 패배 | 용광로에서 이 시도의 삶이 끝난다. 다음 폰에게 전생의 기억을 주지 않는다 |
| 원수의 유품 | 나사 가치 회수. 죽은 동료의 시리얼을 그대로 부활시키지 않는다 |
| 도전 난도 | 본편 뒤의 별도 전술 플레이·기록. 진엔딩 다음에 주인공이 다시 왕으로 타락하는 후일담이 아니다 |
| 태엽/나사/명령서 | 행동력/화폐/명령 카드. 전투의 미리보기와 실행은 같은 규칙을 쓴다 |

### 비중 (9장 §9.1 대체)
흑백 체스 실루엣 **50** · 황동 기계 장치 **25** · 고딕 건축(아치·장미창 = 시계 문자판) **15** · 붉은 과열 **10**

### 이펙트 문법 (12장 피드백 박자와 연결)
모든 이펙트는 **4가지 부품 파티클**의 조합이다 — 그리기 쉽고, 세계관과 맞고, 한눈에 구분된다.

| 파티클 | 의미 | 쓰는 때 |
| :--- | :--- | :--- |
| **증기 퍼프** (흰·청록 도트 구름) | 움직임 | 착지, 이동 꼬리, 레버 |
| **스파크** (황동·금 점) | 힘이 들어감 | 타격, 개량, ★걸작, 보상 |
| **톱니·스프링 파편** | 부서짐 | 처치(흰/검은 파편), 바닥 꺼짐 |
| **붉은 열기** (붉은 아지랑이 선) | 위험 | 적 의도, 체크, 과열, 대기관 |

## 5. 용어집 (목업 → 세계 용어)

**규칙 1: 체스 규칙어는 체스 그대로** — 폰·나이트·비숍·룩·퀸·킹, 체크, 체크메이트, 승급, 캐슬링, 포크, 관통(스큐어). 처음 보는 사람도 바로 안다.
**규칙 2: 시스템어는 세계 용어로 전부 통일.** 화면 글자는 이 표의 「세계 용어」만 쓴다 (코드 ID는 그대로).

## 6. 이름 짓기 규칙
- 재료·장치 어휘: 태엽, 톱니, 피스톤, 보일러, 밸브, 증기, 놋쇠, 황동, 흑철, 백자, 테이프, 레버, 렌즈.
- 공장 어휘: 공정, 주조, 거푸집, 반장, 도금왕, 컨베이어, 검수, 도장(스탬프), 포장, 출하, 하자품(진 세트를 깔보는 말 — D-359), 폐기 처분, 정품. 「불량 도장」은 검수 반장 기믹 이름으로만 남긴다.
- 개조 이름 = 「무엇을 + 어떻게 고쳤나」 (예: E01 기병대 돌격 교리 → **피스톤 박차**, E06 마공학 축전기 → **예비 태엽통**, E16 미래 예지 → **테이프 감청**).
- 쓰지 않는 말: 마법·마공학·차원·균열·크랙·원자로·레이저 같은 판타지/SF 어휘, 영어 음차(오버클럭, 모드 …). **예외: 등급 이름 커먼 · 레어 · 유니크 · 에픽** (사용자 결정 D-113).
- **사람이 나오지 않는다** (D-132 · D-133): 공장에는 기물과 기계뿐이다. 말하는 이는 기물 · 기계 캐릭터 — 검수 저울 · 녹슨 룩(고물상) · 외눈 비숍(공방) · 떠돌이 정비 폰 · 동전 나이트 · 견습 폰 · 다른 공장의 흑 비숍. 사람은 진 엔딩의 아이 하나 (공장 밖).
- 돈 · 직장 말 대신 부품 말: 처치 수당 → **노획 집게**, 보관 이자 → **나사통 적립**. (이름에만 해당 — 이펙트 그림의 번개·광선은 피스톤 방전·렌즈 빛으로 본다, D-035)
- 개조 16종·천공 카드 12종·사건·시작 세트 이름은 D-085에서 이 규칙으로 지었다 (`src/data/enchants.ts`·`cards.ts`·`run/events.ts`, 화면 문구 `src/data/text.ts`).
