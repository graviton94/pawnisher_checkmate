# 세계관 & 메인 테마 (초안 v2)

> 상태: ✅ 방향 확정 (D-032 → D-037, 2026-10-30 — 스팀펑크 체스 공장, AP = 태엽, 화폐 = 나사). 이야기·인물·컷은 `docs/story.md`. 세계관은 사용자 담당 — 이 문서는 **게임 규칙과 그래픽 제작 방식에서 거꾸로 세운 제안**이다.
> v1(대국의 대성당·균열)은 지금 쓰는 목업 이름에 맞춰 세웠다는 피드백을 받아 버렸다. 지금 이름(크랙 제단, 인챈트, 대장간 …)은 모두 목업으로 보고 §5에서 전부 다시 정했다.
> 고정된 것: 게임 이름 **Pawnisher : Checkmate**, 앱 아이콘(흰 왕관 폰 + 붉은 사선), 기물 도트(흰·검은), 흑·백·적·황동 색.

## 1. 세계를 고른 기준

1. **규칙이 설명되는 세계**: "왜 예약한 순서대로 움직이나", "왜 이동한 기물만 치나", "왜 판이 끝나면 다 살아나나"가 세계 안에서 자연스러워야 한다.
2. **그래픽이 싸게 풍부해지는 세계**: 작은 단색 부품 + 코드 조합(`docs/art-assets.md`)으로 이펙트·아이콘이 쏟아져 나와야 한다.
3. **스팀펑크를 가져간다**: 이펙트(증기·스파크·톱니 파편)가 풍부하고 도트로 표현하기 좋다.
4. **흑·백·붉은색과 체스 실루엣**을 해치지 않는다.

→ 결론: **태엽 자동인형이 두는 체스.** 고딕 시계탑 안에서, 명령을 새긴 테이프대로 움직이는 기계 기물들의 대국.

## 2. 한 줄 테마

> **킹 자리에 잘못 들어간 아홉째 폰이 종이 왕관을 쓰고, 태생으로 값을 매기는 규격을 체크메이트로 깬다.** (D-037, 이야기는 `docs/story.md`)

## 3. 세계

### 체크메이트 공장
- 증기와 톱니로 돌아가는 체스 세트 공장. 주조 → 조립 → 검수 → 포장의 36단 공정이 곧 36층이다. 층마다 바닥이 **기계 체스판**(리벳 박힌 금속 작업대, 아래는 톱니)이다.
- 공장의 법은 **규격**: 기물의 값은 태어날 때 정해진다. 세트는 폰 8 · 킹 1.
- 완성된 세트는 **시험용 흑 세트와 대국**을 치른다. 공정마다 **반장**(각 라인을 맡은 대형 정품 기물)이 검수를 맡는다.
- 적·위험의 **붉은색 = 용광로의 쇳물과 경고등**.

### 주인공
- **아홉째 폰** — 킹 자리에 잘못 들어간 폰. 상자를 오린 종이 왕관을 쓰고 킹 노릇을 한다. 게임의 **내 킹**이 그다.

### 규칙의 세계 근거

| 규칙 | 세계에서 |
| :--- | :--- |
| 계획 → 제출 → 순서대로 실행 | 명령을 **테이프에 새기고**(예약) **레버를 당기면**(제출) 기물들이 새긴 순서대로 움직인다 |
| 미리보기 = 결과 (결정론) | 기계는 새긴 대로만 움직인다 |
| 이동한 기물만 공격 | 기물의 무장은 **착지 충격으로 태엽이 풀릴 때** 발사된다 |
| 행동력(AP) | **태엽** — 한 턴에 감을 수 있는 양. 무거운 기물일수록 많이 든다 |
| 킹의 죽음 = 승패 | 킹 자리가 무너지면 "불량 혼입" — 세트째 **폐기** |
| 체크 (한 턴에 못 끝냄) | 킹 자리의 **안전 밸브**가 한 번 버틴다 |
| 판이 끝나면 완전 부활 | 대국 사이에 **정비 라인**이 고친다 |
| 같은 규칙의 적 | 시험용 흑 세트도 같은 규격으로 찍은 기물. 차이는 두는 솜씨 |
| 유형별 고정 능력·덱 한도 | **규격** — 주인공이 깨려는 규칙 |
| 유형 단위 강화 | **거푸집 개량** — 나이트 거푸집을 고치면 모든 나이트가 바뀐다 |
| 요충지 (AP 보상) | 판 위에 깃발로 표시되는 **요충지** — 점거하면 태엽을 더 감는다 (D-068: 세계관 이름 대신 규칙 이름 그대로) |
| 붕괴 | 낡은 작업대가 **톱니 아래로 꺼진다** (붉은 금 = 쇳물 예고) |
| 합체 | 두 기물의 **결합** |
| 최후의 일격 | 킹 자리 **폭주** |

## 4. 시각 언어

### 비중 (9장 §9.1 대체)
흑백 체스 실루엣 **50** · 황동 기계 장치 **25** · 고딕 건축(아치·장미창 = 시계 문자판) **15** · 붉은 과열 **10**

### 이펙트 문법 (12장 피드백 박자와 연결)
모든 이펙트는 **4가지 부품 파티클**의 조합이다 — 그리기 쉽고, 세계관과 맞고, 한눈에 구분된다.

| 파티클 | 의미 | 쓰는 때 |
| :--- | :--- | :--- |
| **증기 퍼프** (흰·청록 도트 구름) | 움직임 | 착지, 이동 꼬리, 레버 |
| **스파크** (황동·금 점) | 힘이 들어감 | 타격, 개량, ★걸작, 보상 |
| **톱니·스프링 파편** | 부서짐 | 처치(흰/검은 파편), 판 붕락 |
| **붉은 열기** (붉은 아지랑이 선) | 위험 | 적 의도, 체크, 과열, 대기관 |

## 6. 이름 짓기 규칙
- 재료·장치 어휘: 태엽, 톱니, 피스톤, 보일러, 밸브, 증기, 놋쇠, 황동, 흑철, 백자, 테이프, 레버, 렌즈.
- 공장 어휘: 공정, 주조, 거푸집, 반장, 공장장, 컨베이어, 검수, 도장(스탬프), 포장, 출하, 불량, 정품.
- 개조 이름 = 「무엇을 + 어떻게 고쳤나」 (예: E01 기병대 돌격 교리 → **피스톤 박차**, E06 마공학 축전기 → **예비 태엽통**, E16 미래 예지 → **테이프 감청**).
- 쓰지 않는 말: 마법·마공학·차원·균열·크랙·원자로·레이저 같은 판타지/SF 어휘, 영어 음차(오버클럭, 모드 …). (이름에만 해당 — 이펙트 그림의 번개·광선은 피스톤 방전·렌즈 빛으로 본다, D-035)
- 개조 16종·천공 카드 12종·사건·시작 세트 이름은 D-085에서 이 규칙으로 지었다 (`src/data/enchants.ts`·`cards.ts`·`run/events.ts`, 화면 문구 `src/data/text.ts`).
