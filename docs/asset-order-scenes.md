## 0. 쓰는 법
1. **매번 첨부 1장**: `build-res/pieces-small-source.png` (기물 도트 — 기물 모양 · 도트 굵기 기준).
2. **회색 상자 하나 = 한 번 생성.** 아래 「공통 규칙」 상자 + 장면 상자 하나를 이어 붙여 넣는다.
3. 합격 기준: 첨부 기물과 같은 화풍(굵은 도트, 검은 바깥선), 팔레트 밖 색 없음, 글자 없음.

## 1. 공통 규칙 (모든 장면 상자 앞에 붙인다)

```
픽셀 아트 장면 그림 한 장. 크기 160 × 120 도트(4:3), 도트는 크고 또렷하게 — 첨부한 체스 기물 도트와 같은 굵기.
분위기: 다키스트 던전 · 슬레이 더 스파이어의 사건 그림처럼 어둡고 비장한 공장. 사람은 없다. 등장인물은 모두 살아 움직이는 체스 기물(첨부 그림의 모양 그대로, 흰 기물 = 플레이어 쪽, 검은 기물 = 낯선 자)이다.
구도: 가운데 주인공 하나(소품 또는 기물)를 크게, 배경은 어둡게 가라앉히고 한 곳에만 빛(쇳물 주황 · 황동 · 청록 중 하나)을 둔다.
색: 아래 팔레트 14색 + 쇳물 주황 #E8783C · 어두운 주황 #7A3A18 두 색만. 그라데이션 · 반투명 · 흐림 금지, 디더링은 2색 체크무늬만.
팔레트: #0B0B0E #16141C #2F2E36 #56545E #8A8794 #C8C8C8 #F4F1EA #8C6239 #C89B3C #FACC15 #7A1218 #E5262F #38BDF8 #BFEFFF
테두리 없음, 글자 · 숫자 · 로고 없음. 배경은 장면 자체로 꽉 채운다(투명 · 마젠타 없음). 그림 아래 15%와 오른쪽 10%에는 중요한 것을 두지 않는다(잘라 낸다).
```
