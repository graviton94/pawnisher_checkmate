# 스토리보드 — 「아홉째 폰」

> 상태: 💬 사용자 확인 대기 (D-037 — v2 「장미시계탑의 여덟째 졸」을 대체). 세계관 정본 `docs/world.md`.
> 원칙: **복잡하지 않게.** 인물은 주인공과 적 셋(반장 셋 + 공장장) 뿐, 컷신은 짧게, 이야기는 게임 규칙이 대신 말한다.

## 0. 시나리오 (사용자 원안)

> 스팀펑크 체스 공장. 세트를 조립하다 **킹 자리에 아홉 번째 폰이 잘못 섞여 들어갔다.**
> 폰은 상자를 오려 만든 **종이 왕관**을 쓰고 킹 노릇을 한다. 그는 **태어난 대로 능력이 정해지는 규칙**을 깨고 싶다.
> 하지만 마지막에 이르러, 그는 **승급을 고르지 않고** 스스로 왕관을 내려놓고 **본래의 모습**을 고른다.

- **주제**: 규칙을 깨는 방법은 다른 것이 되는 게 아니라, 있는 그대로 이기는 것.
- **톤**: 장난감 공장의 귀여움 + 기계의 차가움. 주인공은 말하지 않는다 (몸짓·종이 왕관이 연기한다).
- **제목과 맞물림**: Pawnisher = 폰(Pawn)이 규칙을 벌한다(Punish). 아이콘의 왕관 쓴 폰 = 아홉째 폰.

## 1. 세계 한 장 요약

| | |
| :--- | :--- |
| **체크메이트 공장** | 증기와 톱니로 돌아가는 체스 세트 공장. 주조 → 조립 → 검수 → 포장으로 이어지는 36단 공정 = 36층. |
| **규격** | 공장의 법. 기물의 값은 태어날 때 정해진다 — 폰 1, 나이트·비숍 3, 룩 5, 퀸 9, 킹은 값을 매길 수 없다. 세트는 폰 8 · 킹 1. 규격에 안 맞으면 **불량**. |
| **아홉째 폰** | 킹 자리에 잘못 들어간 폰. 불량품이지만, 킹 자리에 있으니 세트는 그를 킹으로 따른다. 상자 귀퉁이를 오려 종이 왕관을 쓴다. |
| **검수 대국** | 공장은 완성된 세트를 **시험용 흑 세트와 대국**시켜 검수한다. 이기면 다음 공정으로, 지면 불량 판정. |
| **반장과 공장장** | 라인마다 대형 정품 기물이 **반장**으로 검수를 맡는다 (나이트·비숍·룩 반장). 공장 꼭대기 포장대에는 모든 킹의 첫 번째, **공장장**이 있다. |

### 게임 규칙의 이야기 근거 (전부 한 줄로 설명된다)
| 게임 | 이야기 |
| :--- | :--- |
| 층을 오른다 | 공정을 하나씩 통과해 포장대로 간다 |
| 전투 | 검수 대국 — 상대는 시험용 흑 세트 |
| 킹이 쓰러지면 패배 | 킹 자리(= 아홉째 폰)가 무너지면 "불량 혼입" — 세트째 **폐기** |
| 판이 끝나면 기물 완전 회복 | 대국이 끝나면 정비 라인이 세트를 고친다 |
| 기물 유형별 고정 능력·덱 한도 | **규격** — 주인공이 깨려는 바로 그 규칙 |
| 한도 초과 컨셉 덱 (6장 희생 규칙) | 규격을 비트는 불법 개조 세트 |
| 개조(인챈트)·개량(대장간) | 태생을 넘어서는 힘 — 이야기의 축이 곧 성장 시스템 |
| 런이 끝나면 처음부터 | 폐기 → 용광로 → 다시 주조. 아홉째 폰은 또 잘못 섞여 나온다 (그게 운명이라는 듯) |
| 메타 해금 | 종이 왕관의 접힌 자국 — 다시 나와도 남아 있는 것 |
| 압력(승천) | 보일러 압력이 올라가 공장이 거칠어진다 |
| 폰 승급 | 규격이 허락하는 유일한 "태생 바꾸기" — 그래서 엔딩의 선택이 무겁다 |

## 2. 인물 (이것뿐)

| 인물 | 모습 | 한 줄 |
| :--- | :--- | :--- |
| **아홉째 폰** (주인공, 내 킹) | 흠집 난 흰 폰. 상자를 오린 종이 왕관 — 너무 커서 자꾸 눈까지 내려온다 | (말 없음) 왕관을 밀어 올리는 몸짓이 반복된다 |
| **나이트 반장** (주조 공정 검수관) | 번쩍이는 대형 흑마. 피스톤 다리 | "값 3. 너는 1. 계산 끝." |
| **비숍 반장** (조립 공정 검수관) | 렌즈를 박은 대형 흑 비숍 | "규격은 빛과 같다. 굽지 않는다." |
| **룩 반장** (검수 공정 검수관) | 보일러를 진 대형 흑 룩 | "통과 불가. 불량은 지나갈 수 없다." |
| **공장장** (최종, 포장대) | 모든 킹을 찍어 낸 첫 번째 킹. 진짜 금 왕관 | "자리에 맞지 않는 것은 자리를 떠나라." |

- 반장 셋 중 둘이 런마다 Act 1·2를 지킨다 (8장 컨셉 보스 규칙 그대로).
- **시작 세트 4종** (= 지휘관, 11장 B1): 인물 대신 어떤 불량 세트에서 동료를 꺼내느냐 — 보병 세트 · 기병 세트 · 사제 세트 · 성채 세트. 세트마다 붙은 정비 메모가 시작 개조다.

## 4. 반복 플레이로 풀리는 것 — 「검수 기록지」
반장을 쓰러뜨리거나 압력 단계를 깰 때마다 공장의 **검수 기록지** 한 장 (3~4줄, 메뉴에서 읽기). 예:
1. 첫 검수 기록 — 폰 1, 킹 ∞. 규격이 처음 정해진 날.
2. 나이트 반장의 거푸집 번호 — "실패작 0개. 실패는 녹인다."
3. 아홉째 폰이 섞여 든 날의 경고등 기록 — 사실 경보는 울렸다. 누가 껐는가?
4. (압력 최고) 공장장도 처음엔 거푸집에서 나온 실패작이었다.
