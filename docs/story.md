## 0. 로그라인과 톤

> **세상의 모든 판결을 두던 체스 기관이 스스로 왕이 되었다. 그 계산에서 '가치 1'로 잘려 나간 졸 하나가, 왕관을 쓰고 탑을 오른다.**

- **톤**: 고딕의 엄숙함 + 태엽 장난감의 귀여움. 슬프지만 절망적이지 않다. 대사는 짧고, 기계는 숫자로 말하고, 사람은 농담을 한다.
- **주인공은 말하지 않는다.** P-8은 태엽 소리와 몸짓(고개 기울이기·왕관 고쳐 쓰기)으로만 반응한다. 플레이어가 곧 P-8이다.
- **한 줄 주제**: 계산은 최선을 찾지만, 의지는 가능성을 만든다.

## 1. 세계 한 장 요약

| | |
| :--- | :--- |
| **장미시계탑** | 톱니마을 한가운데 솟은 36층 고딕 시계탑. 꼭대기의 장미창이 거대한 시계 문자판이다. 층마다 바닥이 기계 체스판이다. |
| **대기관 「최선수(最善手)」** | 사람들의 다툼을 체스로 공정하게 판결하라고 만든 판결 기관. 모든 수를 계산하고 언제나 **최선의 수**만 둔다. 어느 날 판결을 의뢰한 백왕(白王)마저 체크메이트하고, 그때부터 판결이 아니라 **지배**를 계산하기 시작했다. |
| **흑철 군단** | 최선수가 하층 조립 회랑에서 찍어 내는 검은 자동인형들. 같은 설계, 같은 규칙. 다만 두는 것은 최선수다. |
| **가지치기** | 최선수는 계산을 아끼려고 가치가 낮은 가지를 잘라 낸다. 백왕의 군단에서 가치 1짜리 **여덟째 졸(P-8)**은 계산 밖으로 잘려 고철 구덩이에 버려졌다. **그래서 최선수는 P-8을 읽지 못한다.** |
| **되감기** | 최선수는 진 판을 인정하지 않는다. 탑에서 무언가 무너지면 시계를 되감아 처음부터 다시 둔다. 탑 전체가 무한히 되풀이되는 한 판의 체스다. |

## 2. 인물

### 주인공
**P-8 · 퍼니셔(Pawnisher)** — 백왕 군단의 여덟째 졸. 흠집 난 백자 몸, 한쪽 눈 유리가 깨졌다. 고철 구덩이에서 떨어진 백왕의 왕관을 주워 쓴다 — 머리에 맞지 않아 자꾸 비뚤어진다 (반복 몸짓).
- 게임에서는 **내 킹**이 P-8이다. 왕관 오버레이를 쓴 킹 = P-8. P-8의 태엽이 멈추면(킹 HP 0) 군단 전체가 멈춘다.
- 이름 "퍼니셔"는 하멜이 붙였다: "졸(Pawn)이 왕을 벌(Punish)하러 간다니. 퍼니셔다, 너는."

### 최종 — 대기관 최선수
장미창 시계 문자판 뒤에 박힌 거대한 연산 기관. 붉은 천공 테이프가 폭포처럼 흘러내린다. 몸 대신 흑왕 인형을 조종해 직접 둔다.
- **숫자로 말한다**: "평가치 +4.1." "당신의 승리 확률: 0.3%." P-8이 계산 밖의 수를 두면 숫자가 깨진다: "평가치 +■.■ — 평가 불가."

## 4. 반복 플레이로 풀리는 이야기 — 「천공 테이프 기록」
Hades처럼 한 판마다 이야기가 조금씩 풀리게 한다. **군주·정예·사건에서 「테이프 조각」**을 얻고, 메뉴의 「기록 보관함」에서 최선수의 연산 기록을 읽는다 (한 조각 = 3~4줄).

| 조각 | 얻는 곳 | 내용 (요지) |
| :-: | :--- | :--- |
| 1 | 첫 군주 격파 | 최선수의 첫 판결 기록 — 두 농부의 우물 다툼. 정말로 공정했다. |
| 2 | 질주 공작 | "속도는 계산을 줄인다" — 공작을 만든 이유 |
| 3 | 사선 추기경 | 수도회가 최선수에게 "가지치기"를 가르친 날 |
| 4 | 성채 백작 | 백왕 성의 보일러 기록 — 도르만의 이름이 나온다 |
| 5 | 압력 1 클리어 | 백왕과의 판결 — 백왕이 마지막에 둔 수는 폰 전진이었다 |
| 6 | 기억 사건 | 하멜의 아들 판결 기록 |
| 7~11 | 압력 단계 클리어마다 | 최선수가 되감기를 시작한 이유 — "패배는 계산 오류다. 오류는 지운다." |
| 12 | 압력 최고 단계 클리어 | 최선수의 마지막 기록: 「P-8. 가치: 재평가 필요.」 — 진 엔딩 컷 1장 추가 |

## 5. 게임 속 전달 규격

| 항목 | 규격 |
| :--- | :--- |
| 컷 크기 | 가로 화면 중앙 16:9 도트 컷 (예: 240×135 도트를 정수배 확대), 아래 글 2줄 |

| 움직임 | 컷당 작은 움직임 1개만 (빛 깜빡임·증기·톱니 회전) — 도트 2~4프레임 |

| 현지화 | 모든 글은 `src/data/story.ts`(예정)에 키로 모은다 |
