# 스토리보드 v4 — 「아홉째 폰」 심화: 값은 누가 매기는가

> 상태: 💬 사용자 확인 대기 (D-128). v3(D-037, 사용자 원안)의 뼈대 — 체스 공장 · 킹 자리의 아홉째 폰 · 종이 왕관 · 규격 · 본래 모습을 고르는 엔딩 — 는 그대로 두고, **세 가지 질문**에 답하도록 깊게 팠다.
> 1. 왜 나는 오르는가 · 2. 왜 그들은 나를 막는가 · 3. 깨고 나면 어떻게 되는가 (왜 되풀이되는가).
> 원칙은 그대로: 인물은 적게, 컷은 짧게, **이야기는 게임 규칙이 대신 말한다.** 주인공은 **짧은 독백**을 한다 (D-129, §2.5). 화면 말투는 짧고 차갑게 + 언더테일식 서술 (D-093 · D-098).

---

## 0. 한 문장

> **공장은 태어난 자리로 값을 매긴다. 킹 자리에 잘못 놓인 폰 하나가, 그 값을 매긴 손을 찾아 꼭대기로 오른다 — 그리고 마지막에 알게 된다. 값은 만든 손이 아니라, 두는 손이 매긴다는 것을.**

## 1. 주제 — 「값」과 「쓸모」

| | 공장의 말 (규격) | 아홉째 폰이 끝내 보여 주는 것 |
| :-- | :-- | :-- |
| 값은 | 태어날 때 정해진다 (폰 1 · 퀸 9 · 킹 ∞) | 판 위에서 **둔 수**로 정해진다 |
| 자리는 | 값을 따른다 (1짜리는 킹 자리에 못 선다) | 자리는 **따르는 이들**이 만든다 |
| 불량은 | 녹인다 (용광로) | 녹여도 **다시 나온다** — 오류는 공장의 일부다 |
| 끝은 | 출하 = 팔리는 것 | 놀이 = **누군가 판을 펴는 것** |

- 체스 기물 값(1 · 3 · 3 · 5 · 9 · ∞)은 실제 체스의 기준점이다. 공장은 그것을 **운명**으로 굳혔다. 이 게임의 모든 성장 장치(개량 · 개조 · 이형 · 에픽 · 결합)는 **그 운명을 거스르는 도구**이고, 규칙서 · 도감 · 반장 대사가 그 논리를 같이 말한다.
- 철학의 뼈대 하나: **"값을 매기는 자는 누구인가"** — 만든 자(공장장) · 검사하는 자(반장) · 쓰는 자(아이 = 플레이어). 마지막 컷에서 답이 화면 밖, 플레이어 쪽으로 넘어간다.

## 2. 세계의 숨은 구조 (기록지로 조금씩 풀린다)

1. **공장장은 첫 번째 오류였다.** 최초의 세트에서 킹 자리에 들어간 것도 폰이었다. 그는 꼭대기까지 올라 **금 왕관을 썼고**, 다시는 자기 같은 것이 나오지 못하게 **규격을 썼다.** 공장장의 "∞"는 태어난 값이 아니라 **스스로 붙인 값**이다.
2. **경고등은 일부러 꺼졌다.** 아홉째 폰이 섞여 들 때마다 경고등이 깜빡였다. 끈 손은 공장장이다. 그는 기다리고 있다 — 자기가 하지 못한 일(금 왕관을 거절하는 일)을 해낼 오류를.
3. **반장들도 불량이 될 뻔했다.** 반장마다 몸의 숫자(3 · 3 · 5 …)를 지키려고 규격의 편에 섰다. 아홉째 폰이 이기는 순간, 그들의 숫자는 아무 뜻이 없어진다. 그래서 막는다 — 악의가 아니라 **두려움**으로.
4. **출하된 세트는 돌아온다.** 꼭대기에서 상자에 담겨 나가도, 공장은 "킹 자리에 폰"을 받아들이지 않는다. **반품.** 상자는 컨베이어를 타고 용광로로 돌아오고, 공장은 보일러 압력을 올린다. 이것이 **압력(승천)** 이다.
5. **아이는 반품하지 않는다.** 압력을 끝까지 버틴 세트만이, 공장 밖 누군가의 손에서 열린다. 그 손은 값을 묻지 않는다. 판을 편다.

## 2.5 아홉째 폰의 목소리 — 독백 (D-129)

- **표기**: 독백은 작은따옴표 ‘ ’ — 반장 · 인물 대사 “ ” / 「 」, 서술 「* 」 와 한눈에 구분된다. 화면에서는 흰 글씨 + 왼쪽에 작은 종이 왕관 표식.
- **말투**: 1인칭 반말, 한 줄에 한 생각, 6~14자 안팎. 감탄 · 다짐 · 설명 없이 **관찰 → 짧은 판단**. 정겨운 말꼬리 · 농담 금지 (D-093 그대로).
- **양**: 아끼면 무게가 생긴다. 컷신 · 반장 격파 · 공정 진입 · 결정적 순간에만, 출하 하나에 열 줄 안팎. 대국 중에는 하지 않는다 (예외: 처음 체크를 당할 때 한 번).
- **변화**: 처음엔 왕관을 의식하고(‘왕관이 크다.’), 오를수록 따르는 이들을 보고(‘아무도 안 물러난다.’), 끝에는 값을 묻는다(‘1이라고 했다. 누가.’).

| 때 | 독백 |
| :-- | :-- |
| 프롤로그 — 종이 왕관을 쓸 때 | ‘크다.’ / ‘…그래도 쓴다.’ |
| 프롤로그 — 첫 검수대 | ‘녹기 싫다. 그거면 된다.’ |
| 첫 대국 시작 (처음 한 번) | ‘움직인 놈만 친다. 알았다.’ |
| 처음 체크를 당할 때 (대국 중 유일) | ‘한 번은 버틴다. 두 번은 없다.’ |
| 주조 공정 진입 | ‘여기서 1이 됐다.’ |
| 조립 공정 진입 | ‘자리가 값이라면, 나는 킹이다.’ |
| 검수 공정 진입 | ‘저울은 누가 맞췄지.’ |
| 나이트 반장 격파 | ‘무거워서 진 게 아니다.’ |
| 비숍 반장 격파 | ‘보이는 대로 보지 않았다.’ |
| 룩 반장 격파 | ‘벽 옆으로 돌았다. 그뿐.’ |
| 폰 반장 격파 | ‘하나여도, 하나는 하나다.’ |
| 이형 반장 격파 | ‘다른 게 되면, 이긴 건 누구지.’ |
| 검문 반장 격파 | ‘서명은 안 받았다. 지나간다.’ |
| 흰 기물들이 따르는 것을 볼 때 (첫 반장 뒤) | ‘아무도 안 물러난다. 왜.’ |
| 공장장 등장 | ‘1이라고 했다. 누가.’ |
| 공장장 「…나도 그랬다.」 뒤 | ‘그럼 너도 폰이었다.’ |
| 선택 화면 | ‘무엇이든 될 수 있다. …무엇이든.’ |
| 엔딩 A (금 왕관) | ‘맞는다. 너무.’ |
| 엔딩 B (종이 왕관을 내려놓을 때) | ‘이건 내가 오린 거다.’ |
| 반품 | ‘또 돌아왔다. 이번엔 덜 무섭다.’ |
| 진 엔딩 | ‘…판이 펴졌다.’ |
| 패배 — 용광로에서 다시 주조 | ‘또 아홉째다. 조각은 남았다.’ |

## 3. 왜 나는 오르는가 — 세 겹의 동기

| 겹 | 동기 | 게임에서 |
| :-: | :-- | :-- |
| 1 살아남기 | 불량 세트는 녹는다. 유일한 출구는 공정을 모두 통과해 **포장대**에 닿는 것. | 지면 출하 끝 (용광로) · 층을 오른다 |
| 2 따르는 이들 | 흰 기물들은 **킹 자리를 따르도록** 만들어졌다 — 그가 폰이라는 걸 알면서도. 그가 멈추면 그들도 녹는다. | 군단 · 영입 · 대국마다 다시 서는 기물 |
| 3 값을 매긴 손 | 누가, 왜 "1"이라고 정했는가. 그 답은 꼭대기에 있다. | 반장 대사 · 검수 기록지 · 공장장 |

- 첫 출하에서는 1겹만 보인다 (프롤로그). 반장을 쓰러뜨릴수록 2겹(격파 컷의 흰 기물들), 기록지를 모을수록 3겹이 드러난다.

## 4. 왜 그들은 나를 막는가 — 반장 여섯의 「값의 논리」

반장은 공장의 면역 반응이다. 각자 **값을 지키는 이유** 하나를 몸에 지녔고, 그 이유가 곧 **약점**이 된다 (D-113 약점과 맞물림).

| 반장 | 값의 논리 | 등장 대사 | 약점 (게임) | 격파 컷 한 줄 |
| :-- | :-- | :-- | :-- | :-- |
| 나이트 | **힘** — 값은 무게다. 무거운 것이 밟는다. | 「규격 밖은 밟고 간다.」 | 무딘 편자 — 방열판 위로는 40% | * 편자가 철판에 미끄러진다. 무게로는 안 되는 것이 있다. |
| 비숍 | **보이는 것** — 값은 빛에 비친 모습이다. | 「삐뚤어진 건 빛에 다 보여.」 | 깨지는 렌즈 — 가까이 오면 깨진다 | * 렌즈가 깨진다. 가까이서 보니, 삐뚤어진 건 렌즈였다. |
| 룩 | **자리** — 값은 서 있는 곳이다. 성벽 안이 안전하다. | 「여기서 끝이다.」 | 네모난 차체 — 사선에 약하다 | * 성벽은 곧게만 막는다. 세상은 비스듬하다. |
| 폰 | **수(數)** — 하나는 값이 없다. 많아야 값이다. | 「하나 부서지면 둘 찍는다.」 | 얇은 양산 철판 — 꿰뚫리면 줄줄이 | * 열이 한꺼번에 쓰러진다. 많으면, 같이 무너진다. |
| 이형 | **바꾸기** — 값이 싫으면 다른 것이 되면 된다. (같은 오류 출신, 거푸집을 팔아 반장이 되었다) | 「규격? 그건 네 사정이고.」 | 급조 용접 — 연달아 맞으면 떨어진다 | * 용접이 풀린다. 바꾼 몸은 원래 몸을 기억한다. |
| 검문 | **서류** — 값은 증명서다. 도장이 없으면 없는 것이다. | 「서류는 셋. 너는 한 장도 못 넘긴다.」 | 서류 대조 — 두 번 확인당하면 무너진다 | * 서류가 흩어진다. 아무도 서명하지 않은 판이다. |
| **공장장** | **값을 쓴 손** — 규격은 내가 살아남은 방식이다. | 「그 왕관, 종이로군.」 | 없음 (마지막 시험) | (엔딩으로) |

- 이형 반장은 **거울**: 주인공과 같은 출신이지만 "다른 것이 되는" 길을 골랐다. 엔딩의 선택(승급 · 금 왕관)을 미리 보여 주는 유혹.
- 반장 격파 후 공통: 반장의 몸 숫자에 금이 가고, 아홉째 폰의 종이 왕관이 조금 바로 선다 (v3 유지).

## 5. 깨고 나면 — 엔딩과 되풀이

### 5.1 꼭대기의 선택 (공장장 격파 뒤, 플레이어가 고른다)
포장대 끝 = 판의 마지막 줄. 승급 표시가 빛나고, 굴러온 **금 왕관**이 발밑에 있다.

| 선택 | 엔딩 | 무엇이 되풀이되나 |
| :-- | :-- | :-- |
| **금 왕관을 쓴다** | 「두 번째 공장장」 — 컨베이어가 다시 돈다. 그는 포장대에 서서 아래를 내려다본다. 경고등이 깜빡인다. 그는 손을 뻗어 **끈다.** | 출하 끝. 도감에 「공장장의 길」 기록. (다음 출하는 평소대로 — 이것은 공장이 굴러가는 방식이었다는 것을 알게 될 뿐) |
| **종이 왕관을 내려놓는다** (v3 원안) | 「본래의 모습」 — 종이 왕관을 접어 킹 자리에 놓고, 자기는 아홉 번째 폰 칸에 선다. 흰 기물들은 **아무도 자리를 옮기지 않는다.** 상자가 닫히고 출하된다. | → 5.2 반품 |

### 5.2 반품 — 압력이 오르는 이유 (클리어 루프)
압력 0 ~ 12에서 「본래의 모습」으로 끝내면, 짧은 후일담 2컷:
1. * 사흘 뒤. 상자가 돌아온다. 붉은 도장: **「반품 — 사유: 킹 자리에 폰」**
2. 컨베이어가 상자를 다시 용광로로. 보일러 바늘이 한 칸 오른다. — ‘또 돌아왔다. 이번엔 덜 무섭다.’ → **압력 +1 개방** (지금 규칙 그대로).

- 반품 사유는 압력마다 다르다 — 「종이 왕관 동봉」 「폰 수량 초과」 「포장이 따뜻함」 … 시작 세트의 반품 사유(이미 있음)와 같은 결. 기록지처럼 모인다.
- 그래서 **압력 = 공장이 이 세트를 받아들이지 않는 고집**이다. 플레이어가 오를수록 공장도 거칠어진다.

### 5.3 진 엔딩 「반품하지 않음」 — 압력 13 클리어 (+ 종이 왕관)
1. 어느 방. 아이가 상자를 연다. 폰 아홉, 그리고 접힌 종이 왕관 하나.
2. 아이는 상자 안 설명서(규격표)를 보지 않는다. 종이 왕관을 폰 하나에 씌운다. 판을 편다.
3. * 반품 신청서는 끝내 쓰이지 않았다.
4. ‘…판이 펴졌다.’ 그리고 화면 밖으로: **「* 이 상자를 연 것은, 당신이다.」** — 값을 매기는 손 = 두는 손 = 플레이어.
- 진 엔딩 뒤 압력 13은 그대로 열려 있다 (기록 경쟁 · 오늘의 출하). 루프는 "공장이 굴러가는 한" 이어지지만, 이 세트는 나갔다.

### 5.4 패배 루프 — 용광로 (v3 유지 + 한 줄)
- 불량 혼입 → 용광로 → 다시 주조. 아홉째 폰은 **또** 잘못 섞여 나온다.
- 추가: 반쯤 녹은 종이 왕관 조각이 쇳물 위에 떠 있다. 경고등이 깜빡인다 — 그리고 꺼진다 (누가 끄는지는 기록지 3).
- 메타 해금 = "종이 왕관의 접힌 자국": 녹아도 남는 기억.

### 5.5 세 루프 한눈에

| 루프 | 원인 (세계) | 게임 규칙 |
| :-- | :-- | :-- |
| 패배 | 불량은 녹인다, 그러나 오류는 다시 나온다 (공장장이 경고등을 끈다) | 출하 실패 → 새 출하 · 메타 해금 |
| 반품 | 공장은 킹 자리의 폰을 받아들이지 않는다 | 클리어 → 압력 +1 |
| 왕관 | 꼭대기에서 금 왕관을 쓴 자는 공장이 된다 | 선택 엔딩 (도감 기록) |
| (끝) | 공장 밖의 손은 값을 묻지 않는다 | 압력 13 + 종이 왕관 → 진 엔딩 |

| 6 | 폰 반장의 생산 대장 | 폰 반장 해체 | 하루 폰 8,000. 9의 배수로 찍힌 날이 있었다. |
| 7 | 이형 반장의 영수증 | 이형 반장 해체 | 거푸집 다섯을 판 값: "반장 자리 하나." |
| 8 | 검문 반장의 서류철 | 검문 반장 해체 | 서류 맨 아래 칸 "최종 승인" — 늘 비어 있다 |
| 9 | 반품 장부 | 첫 정품 출하 | 반품 사유가 압력마다 다르다. 같은 세트다. |
| 10 | 공장장의 첫 상자 | 공장장 첫 격파 | 상자 안 킹 자리에 폰 하나. 금 왕관은 나중에 칠한 것이다. |
| 11 | 꺼진 경고등의 메모 | 「공장장의 길」 엔딩 | "누군가 거절하기를." |
| 12 | 반품 신청서 (빈칸) | 진 엔딩 | 아무것도 쓰이지 않았다. |

## 7. 스토리보드 (컷)

**컷 표기**: 🎞 화면 · 💬 글 (컷당 2줄 이내). 탭 = 다음, 길게 누르기 = 건너뛰기. 두 번째 출하부터 ★컷만.

### 7.1 프롤로그 (6컷, v3 유지 + 1줄 변경)
| # | 🎞 | 💬 |
| :-: | :-- | :-- |
| 1★ | 증기를 뿜는 거대한 공장. 굴뚝마다 기물 모양 연기. | * 체크메이트 공장. / 모든 기물은 태어날 때 값이 정해진다. |
| 2 | 컨베이어 위 폰들. 집게가 여덟씩 상자에. | * 폰은 1. 여덟이 한 세트. |
| 3★ | 집게가 아홉째 폰을 킹 자리에. 경고등이 깜빡 — **그리고 꺼진다.** | * 그날 한 세트에 / 킹 대신 폰이 들어갔다. |
| 4 | 상자 안 어둠. 흰 기물들이 그를 내려다본다. | 「…네가 킹이야?」 |
| 5★ | 상자 귀퉁이를 오려 종이 왕관을 쓴다. 너무 커서 눈을 덮는다. 밀어 올린다. | ‘크다.’ / ‘…그래도 쓴다.’ |
| 6★ | 뚜껑이 열리고 첫 검수대 불빛. 흰 기물들이 그를 따라 판 위로. | * 불량은 녹는다. 끝까지 통과하면 녹지 않는다. / ‘녹기 싫다. 그거면 된다.’ → 로고 |

### 7.2 공정 진입 (공정마다 1컷)
| 공정 | 🎞 | 💬 |
| :-- | :-- | :-- |
| 주조 | 용광로와 거푸집. 판 아래 붉은 쇳물. | * 기물이 태어나는 곳. / 값은 여기서 굳는다. |
| 조립 | 끝없는 컨베이어, 도장 분사기. | * 맞는 자리에, 맞는 부품을. / 자리가 값을 정한다고, 여기선 믿는다. |
| 검수 | 저울과 도장. 「정품」「불량」. | * 마지막 검수. / 저울 눈금은 누가 그었을까. |

### 7.3 반장 등장 · 격파 (각 1컷, §4의 대사)
- 등장 ★: 판 건너편에서 반장이 일어선다. 몸의 숫자가 빛난다. + 등장 대사.
- 격파 ★: 숫자에 금이 간다. 종이 왕관이 조금 바로 선다. + 격파 한 줄 (§4) + 독백 한 줄 (§2.5).

### 7.4 공장장 (30층, 최종 검수대)
| | 🎞 | 💬 |
| :-- | :-- | :-- |
| 등장 ★ | 포장대. 공장장이 금 왕관을 쓰고 서 있다. 옆에 빈 상자. 그의 발치 — **흠집 난 폰의 받침.** | 「그 왕관, 종이로군.」 / 「…나도 그랬다.」 |
| 체크 ★ | 금 왕관에 금이 간다. 금빛이 벗겨져 아래의 회색이 보인다. | 「불량이 / 킹을 이길 수는 없다.」 |
| 메이트 ★ | 공장장이 무너진다. 금 왕관이 굴러와 발밑에 멈춘다. | 「…써라. 나는 썼다.」 / ‘그럼 너도 폰이었다.’ |

### 7.5 선택 (1화면)
- 🎞 마지막 줄. 승급 표시 · 금 왕관 · 종이 왕관. 독백 ‘무엇이든 될 수 있다. …무엇이든.’ 버튼 둘: **「금 왕관을 쓴다」 · 「종이 왕관을 내려놓는다」** (동사 하나 원칙의 예외 — 이야기의 마지막 결정이라 목적어를 붙인다).

### 7.6 엔딩 A 「두 번째 공장장」 (3컷)
1. 금 왕관을 쓴다. — ‘맞는다. 너무.’
2. 포장대 위에서 내려다본다. 컨베이어, 폰, 집게. 경고등이 깜빡인다.
3. 손을 뻗어 끈다. * 공장은 그렇게 굴러간다.

### 7.7 엔딩 B 「본래의 모습」 (5컷, v3 원안)
1★ 종이 왕관을 벗어 접는다. 승급 표시가 꺼진다. — * 마지막 줄에 닿은 폰은 무엇이든 될 수 있다. / ‘이건 내가 오린 거다.’
2 접은 왕관을 킹 자리에. 자기는 아홉 번째 칸에. — * 그는 폰으로 남기로 했다.
3★ 흰 기물들 — 아무도 자리를 옮기지 않는다. — —
4 뚜껑이 닫히고 트럭이 공장 문을 나선다. — * 정품 출하.
5 (압력 0~12) **반품 2컷 (§5.2)** / (압력 13) **진 엔딩 4컷 (§5.3)**

### 7.8 패배 (3컷, v3 + 경고등)
1★ 종이 왕관이 구겨져 날아간다. 붉은 도장 「불량 혼입 — 폐기」. — * 불량이 섞인 세트. 폐기.
2 집게가 상자째 용광로에. — —
3 다시 주조. 폰이 하나 더 — 아홉째. 경고등이 깜빡, 꺼진다. 그을린 종이 왕관 조각을 주워 편다. — ‘또 아홉째다. 조각은 남았다.’ (해금이 있으면 한 줄 더)

## 8. 게임 규칙과의 맞물림 (v3 표에 더함)

## 9. 정해 주실 것

1. **선택 엔딩을 넣을까** (금 왕관 / 종이 왕관) — 아니면 v3처럼 종이 왕관 하나로 고정?
2. **반품 루프로 압력을 설명하는 것** — 좋은지.
3. **진 엔딩 마지막 줄 「이 상자를 연 것은, 당신이다」** — 플레이어에게 말을 거는 것이 톤에 맞는지.
4. 공장장 = 첫 오류 · 경고등을 끈 손 — 너무 친절한 반전인지, 기록지로만 흘릴지.
5. 반장 「값의 논리」 6개 — 바꾸고 싶은 반장.
