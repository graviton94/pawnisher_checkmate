# 스토리보드 v5 — 「아홉째 폰」: 모양이 길을 정하지 않는다

> 상태: 💬 사용자 확인 대기 (D-130 — v4 「값은 누가 매기는가」를 사용자 방향으로 다시 세움).
> 사용자 방향: 킹 대신 섞여 든 폰 때문에 세트 전체가 폐기 위기 · 같은 편에게도 "폰"이라 무시당함 · 고위 기물은 따르지 않고(작은 시작 군단의 이유) 일부만 곁에, 나머지는 영입 · 흑 세트는 "태생대로만 움직여야 한다"는 잘못된 신념 · 이길 때 "너의 한계를 스스로 단정 짓지 마라".
> 철학: **태생은 정해진 것이 아니고, 누구에게도 정해진 길만 있는 것은 아니다.** 교훈: **모난 돌이라는 손가락질을 이기고, 내 길은 내가 낸다.**
> 형식은 그대로: 컷은 짧게, 이야기는 게임 규칙이 대신 말한다. 주인공은 짧게 말한다 (D-129). 말투는 짧고 차갑게 + 언더테일식 서술 (D-093 · D-098). **설교하지 않는다** (§11).

---

## 0. 한 문장

> **킹 자리에 잘못 들어간 폰 하나 때문에 세트 전체가 폐기될 처지. 같은 편조차 "폰 주제에"라며 등을 돌린다. 그는 모양이 정한 길 말고, 자기가 낸 길로 꼭대기까지 간다 — 그리고 지나는 곳마다 묻는다. 그 길, 정말 하나뿐이었나.**

## 1. 철학 — 세 문장

| | 세상의 말 (공장 · 흑 세트 · 처음의 흰 기물들) | 아홉째 폰이 판 위에서 보여 주는 것 |
| :-- | :-- | :-- |
| 태생 | 모양이 곧 너다. 폰은 폰이다. | **모양은 시작일 뿐이다.** 개량 · 개조 · 결합 · 이형 — 판 위에서 바뀐다. |
| 길 | 나이트는 L자, 비숍은 사선. 정해진 길로만 가라. | **길은 하나가 아니다.** 비켜 주면 사선이 열리고, 앞이 쓰러뜨린 자리로 뒤가 돌파한다. |
| 시선 | 틀린 건 틀린 거다. 저건 괴짜다. 모난 돌은 정을 맞는다. | **손가락질은 길을 막지 못한다.** 이기면 하나씩 곁에 선다. |

- 이 게임의 모든 성장 장치가 이 철학의 증거다: 거푸집 개량(같은 모양, 다른 힘) · 개조(규격서에 없는 수) · **거푸집 교환(나이트가 비숍처럼, A05)** · **결합(두 모양이 하나로)** · **이형(다른 꼴로 붓기)** · 에픽(규칙째 바꾸기). 플레이어는 출하 한 번마다 "정해진 길이 아닌 길"을 직접 만든다.
- 상대(흑 세트)는 같은 규칙으로 두지만 **그 장치를 믿지 않는다** — 그래서 약점이 생긴다 (§4).

## 2. 시작 — 폐기 위기

- 조립 라인. 집게가 킹 자리에 **아홉째 폰**을 넣는다. 경고등이 깜빡, 꺼진다 (누가 껐는지는 기록지).
- 첫 검수 전 점검: 「킹 자리에 폰. **세트 전체 불량 처리 예정.**」 — 이 세트의 흰 기물 열여섯이 모두 용광로 앞에 선다.
- 살 길은 하나: 공정을 모두 통과해 **포장대에서 정품 도장**을 받는 것. 그러려면 킹 자리가 이겨야 한다.
- 흰 기물들의 반응 — 대부분 등을 돌린다:
  - 퀸: 「폰이 킹 자리에? 우리까지 녹이려고.」
  - 룩: 「나는 폰 명령은 안 받는다.」 (상자 구석으로 돌아선다)
  - 비숍: 「모양을 봐. 저건 틀렸어.」
  - 몇몇만 남는다 — 같은 라인에서 함께 굴러 나온 폰 몇, 혹은 자기도 "불량" 소리를 들어 본 나이트 하나. **이것이 시작 세트**다.

## 3. 내 편 — 따르지 않던 이들이 하나씩 (게임 규칙과 맞물림)

| 게임 | 이야기 |
| :-- | :-- |
| **작은 시작 군단** (3~4기) | 고위 기물은 폰의 명령을 듣지 않는다. 곁에 선 건 몇뿐. |
| **시작 세트 3지선다** | 누가 먼저 곁에 섰는가 — 반품 사유처럼 각자 사연 한 줄 (지금 SET_LORE) |
| **라인** (돌격 · 사선 · 물량) | 곁에 선 이들이 나온 라인 |
| **보상 「새 기물」 3지선다** | 상자 구석에서 지켜보던 흰 기물이 **이긴 것을 보고 합류**한다 (예: 「* 룩 하나가 상자 구석에서 걸어 나온다. “…한 판만 따라가 본다.”」) |
| **영입** (검문! · 반장) | 진 흑 기물이 **설득되어** 넘어온다 — 「* 쓰러진 흑 나이트가 일어나 판 이쪽으로 건너온다.」 |
| **군단이 커질수록** | 마지막에는 처음 등을 돌린 퀸도 줄에 선다 (공장장 앞, 군단 16기 근처면 컷 한 장 추가) |
| **대국이 끝나면 다시 선다** | 정비 라인이 세트를 고친다 — 아무도 버리지 않는다 |

- 처음 등을 돌린 고위 기물이 합류할 때 대사 한 줄씩 (`src/data/story.ts`의 합류 대사, 유형마다 2~3줄 중 하나):
  - 퀸: 「…폰이 여기까지 온 건 처음 봤어.」 · 룩: 「명령은 안 받는다. 옆에 서는 거다.」 · 비숍: 「모양이… 틀린 게 아니었나.」 · 나이트: 「나도 L자만 뛰는 건 지겨웠다.」 · 폰: 「하나 더.」

## 4. 막는 이들 — 흑 세트의 신념 「태생대로만」

흑 세트(시험용 흑 세트와 반장)는 같은 규칙으로 두지만, **"모양이 정한 대로만 움직여야 한다"** 를 믿는다. 그래서 킹 자리의 폰을 인정하지 않고, 그 신념의 틈이 곧 **약점**(D-113)이다.

| 반장 | 그의 신념 | 등장 대사 | 약점 (게임) | 아홉째 폰의 승리 대사 ‘ ’ |
| :-- | :-- | :-- | :-- | :-- |
| 나이트 | 무거운 것이 밟는다. 나이트는 뛰고, 폰은 밟힌다. | 「규격 밖은 밟고 간다.」 | 무딘 편자 — 방열판 위로는 40% | ‘밟히는 쪽이 정해져 있다고 누가 그랬지.’ |
| 비숍 | 사선만이 바른 길이다. 삐뚤어진 건 빛에 드러난다. | 「삐뚤어진 건 빛에 다 보여.」 | 깨지는 렌즈 — 가까이 오면 깨진다 | ‘가까이서 보면, 길은 사선만이 아니다.’ |
| 룩 | 곧게, 자리를 지켜라. 벽 밖은 위험하다. | 「여기서 끝이다.」 | 네모난 차체 — 사선에 약하다 | ‘벽만 보고 섰으니 옆을 못 봤지.’ |
| 폰 | 하나는 아무것도 아니다. 줄 맞춰 앞으로만. | 「하나 부서지면 둘 찍는다.」 | 얇은 양산 철판 — 꿰뚫리면 줄줄이 | ‘너희도 하나씩이었다. 줄 밖으로 나와도 된다.’ |
| 이형 | 모양이 싫으면 다른 모양을 사라. (틀을 바꿨지만 여전히 남이 판 틀) | 「규격? 그건 네 사정이고.」 | 급조 용접 — 연달아 맞으면 떨어진다 | ‘바꾼 것도 남이 판 틀이다. 길은 사는 게 아니다.’ |
| 검문 | 서류에 없는 길은 없는 길이다. | 「서류는 셋. 너는 한 장도 못 넘긴다.」 | 서류 대조 — 두 번 확인당하면 무너진다 | ‘서류 밖에도 판은 있다. 지나간다.’ |
| **공장장** | **모양이 운명이다** — 그가 쓴 규격 그 자체 | 「그 왕관, 종이로군.」 | 없음 | (엔딩으로) |

- 승리 대사는 **조롱이 아니라 건네는 말**이다 — 상대도 같은 틀에 갇힌 기물이라는 시선. 상대가 무너질 때 반장 몸의 숫자(3 · 3 · 5 …)에 금이 가고, 흑 기물 하나가 **영입**으로 넘어올 수 있다 (게임 그대로).
- 일반 검문! · 대국에는 흑 세트의 짧은 비웃음을 대국 시작 한 줄로 섞는다 (무작위 하나): 「폰이 킹 흉내를.」 · 「괴짜 세트다.」 · 「모양부터 틀렸어.」 · 「정해진 대로 둬.」 — 이기는 순간 그 말이 판 위에서 반박된다.

## 5. 꼭대기 — 공장장과 규격의 진실 (기록지로 흘린다)

1. **공장장도 폰이었다.** 최초의 세트에서 킹 자리에 들어간 것도 폰이었다. 그는 손가락질을 견디지 못했고, 꼭대기에서 **금 왕관을 칠해 "진짜 킹"이 되는 쪽**을 골랐다. 그리고 다시는 자기 같은 것이 나오지 못하게 **"모양이 운명"이라는 규격**을 썼다.
2. **경고등은 그가 끈다.** 매번. 누군가 자기와 다른 답 — 모양을 바꾸지 않고도 끝까지 가는 답 — 을 보여 주기를 기다리며.
3. 반장들은 그 규격 아래서 숫자를 지키려 섰다. 신념이 단단할수록 두려움도 크다.

공장장의 마지막 말: 「모양이 길이다. 그래야 아무도 안 다쳐.」 → 무너지며 「…나는 칠했다. 너는?」

## 6. 목소리 — 독백 ‘ ’ 과 건네는 말

- 아홉째 폰의 말은 모두 작은따옴표 ‘ ’ (혼잣말 · 상대에게 건네는 말 모두). 흑 · 흰 기물 대사는 「 」, 서술은 「* 」.
- 1인칭 반말, 한 줄 한 생각. 감탄 · 다짐 · 설교 없이 **관찰 → 짧은 판단**. 정겨운 말꼬리 · 농담 금지 (D-093).
- 출하 하나에 열 줄 안팎 — 프롤로그 · 반장 격파 · 공정 진입 · 공장장 · 엔딩. 대국 중엔 처음 체크를 당할 때 한 번.
- 흐름: 처음엔 시선을 견딘다(‘폰이 맞다. 그래서?’) → 곁에 선 이들을 본다(‘하나 더 섰다.’) → 남에게 건넨다(승리 대사) → 끝에서 자기에게 묻는다(‘…나는 뭐가 되고 싶었지.’).

| 때 | ‘ ’ |
| :-- | :-- |
| 프롤로그 — 「세트 전체 불량 처리 예정」 | ‘나 때문이다.’ |
| 프롤로그 — 퀸이 등을 돌릴 때 | ‘폰이 맞다. 그래서?’ |
| 프롤로그 — 종이 왕관을 쓸 때 | ‘크다. …그래도 쓴다.’ |
| 첫 검수대 | ‘녹게 두지 않는다. 아무도.’ |
| 첫 체크 (대국 중 유일) | ‘한 번은 버틴다. 두 번은 없다.’ |
| 처음 합류가 생길 때 | ‘하나 더 섰다.’ |
| 주조 공정 진입 | ‘여기서 모양이 굳는다고 했다.’ |
| 조립 공정 진입 | ‘맞는 자리. 누가 정한 자리.’ |
| 검수 공정 진입 | ‘틀렸다는 도장. 많이 받았다.’ |
| 반장 격파 | §4 승리 대사 |
| 공장장 등장 | ‘모양이 운명이라고 쓴 손.’ |
| 공장장 「…나는 칠했다. 너는?」 뒤 | ‘…나는 뭐가 되고 싶었지.’ |
| 선택 화면 | ‘무엇이든 될 수 있다. 무엇이 되든, 내가 고른다.’ |
| 엔딩 A (금 왕관) | ‘맞는다. 너무.’ |
| 엔딩 B (종이 왕관을 접을 때) | ‘폰으로 여기까지 왔다. 그거면 됐다.’ |
| 반품 | ‘한 번에 바뀌진 않는다. 다시.’ |
| 진 엔딩 | ‘…판이 펴졌다.’ |
| 패배 — 다시 주조 | ‘또 아홉째다. 이번엔 누가 먼저 설까.’ |

## 7. 엔딩과 되풀이

### 7.1 꼭대기의 선택 (공장장 격파 뒤)
마지막 줄 = 승급 칸. 굴러온 금 왕관, 빛나는 승급 표시.

| 선택 | 엔딩 | 뜻 |
| :-- | :-- | :-- |
| **금 왕관을 쓴다** (승급 · "진짜 킹") | 「두 번째 공장장」 — 포장대 위. 경고등이 깜빡인다. 손을 뻗어 끈다. * 공장은 그렇게 굴러간다. | 남이 정한 "높은 모양"이 되는 길 — 공장장이 간 길. 도감 기록. |
| **종이 왕관을 접는다** (폰 그대로) | 「본래의 모습」 — 접은 종이 왕관을 킹 자리에, 자기는 폰 칸에. 처음 등을 돌린 퀸 · 룩 · 비숍까지 **아무도 자리를 옮기지 않는다.** * 정품 출하. | 모양을 바꾸지 않고도 끝까지 왔다. 따르는 이들이 그 증거. |

- v3 사용자 원안의 엔딩(승급을 고르지 않고 본래 모습)은 B 그대로. A는 "다른 길도 있었다"를 보여 주는 거울.

### 7.2 반품 — 압력이 오르는 이유
- 압력 0~12에서 B로 끝내면: * 사흘 뒤. 상자가 돌아온다. 붉은 도장 「반품 — 사유: 킹 자리에 폰」. → 용광로 → **압력 +1**.
- 세상의 시선은 한 번에 바뀌지 않는다. 그래서 다시 오른다 — 압력이 오를수록 공장은 더 거칠게 막는다.
- 반품 사유가 압력마다 다르다 (「폰이 너무 당당함」 · 「종이 왕관 동봉」 · 「흑 기물 혼입(영입)」 …) — 시작 세트 반품 사유와 같은 결.

### 7.3 진 엔딩 「반품하지 않음」 (압력 13 + 종이 왕관)
1. 어느 방. 아이가 상자를 연다. 폰 아홉, 접힌 종이 왕관, 그리고 흑 기물 몇 (영입한 이들).
2. 아이는 설명서(규격표)를 보지 않는다. 종이 왕관을 폰에 씌우고, 흑 나이트를 흰 줄에 세운다. 판을 편다.
3. ‘…판이 펴졌다.’
4. **「* 정해진 길은 없었다. 이 판을 펴는 것도, 당신이다.」**

### 7.4 패배 — 용광로
- 불량 혼입 → 용광로 → 다시 주조. 아홉째 폰은 또 섞여 나온다. 경고등이 깜빡, 꺼진다.
- ‘또 아홉째다. 이번엔 누가 먼저 설까.’ — 메타 해금(시작 세트 · 도감)은 "지난번에 곁에 섰던 이들의 기억".

## 10. 게임 규칙과의 맞물림

| 게임 | 이야기 |
| :-- | :-- |
| 작은 시작 군단 · 시작 세트 | 폰의 명령을 듣는 건 몇뿐 |
| 새 기물 보상 · 영입 | 지켜보던 이들의 합류 · 진 흑 기물의 설득 |
| 반장 약점 | 「태생대로만」 신념의 틈 |
| 거푸집 교환 · 결합 · 이형 · 에픽 | 정해진 길이 아닌 길 — 철학의 증거 |
| 압력 (반품) | 세상의 시선은 한 번에 안 바뀐다 |
| 대국마다 다시 서는 기물 | 아무도 버리지 않는다 |
| 오늘의 출하 | 같은 날 모두가 같은 상자를 연다 — 각자 다른 길로 |

## 11. 설교하지 않는 법 (톤 규칙)

1. **철학은 말이 아니라 판이 증명한다.** 승리 대사는 이긴 다음에만, 한 줄로.
2. 아홉째 폰은 **남을 가르치지 않는다** — 자기가 본 것을 말할 뿐이다 (‘~했다’ · ‘~이다’, ‘~해라’ 금지).
3. 상대를 깎아내리지 않는다. 흑 기물도 같은 틀에 갇힌 기물이다 — 그래서 영입이 가능하다.
4. 정답을 대신 말하지 않는다. 마지막 말은 질문이나 플레이어에게 넘긴다 (‘…나는 뭐가 되고 싶었지.’ · 「이 판을 펴는 것도, 당신이다.」).
5. 서술은 언더테일식으로 담담하게, 작은 엉뚱한 디테일 하나 (「* 종이 왕관이 또 눈까지 내려온다. 그는 또 밀어 올린다.」).

## 12. 정해 주실 것
1. 시작 장면에서 등을 돌리는 고위 기물 셋(퀸 · 룩 · 비숍)과 대사 — 이 정도 차가움이면 될까?
2. 승리 대사 여섯 — 톤 · 문장 (상대에게 건네는 말로, 설교처럼 들리지 않게).
3. 선택 엔딩(금 왕관 / 종이 왕관)을 유지할까, 종이 왕관 하나로 고정할까?
4. 진 엔딩 마지막 줄 — 플레이어에게 말을 거는 것.
5. 공장장 = 첫 폰 · 경고등을 끄는 손 — 컷으로 보여 줄지, 기록지로만 흘릴지.
