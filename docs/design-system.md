# 디자인 문법 정본 — 「주물 공방 문법」 (D-259)

> 사용자 (2026-11-06): 「전투 씬 FX나 대화창, 안내창, 팝업창 등도 어떤 건 잘 만들고, 어떤 건 엉망으로 만들고. 디자인 철학 제대로 안 세울래?」
> 원인: 원칙(D-216 도트만 · D-213 글씨 · D-180 박자)은 있었지만 **「무엇으로 만드는가」(재질 · 빛 · 부품)** 가 없었다. 화면마다 손으로 새로 그려서 같은 게임 안에서 문법이 달랐다.
> 이 문서는 모든 화면 요소가 따르는 하나의 문법이다. 새 화면 · 효과 · 팝업은 여기 부품을 조합해서만 만든다. 어기는 것은 고칠 목록에 올린다.

## 0. 한 문장
**작업대 위의 물건만 있다.** 화면의 모든 것은 공장에 실제로 있을 법한 쇠 · 황동 · 나무 · 종이 물건이고, 같은 빛(왼쪽 위)을 받고, 같은 손(코드 부품)이 찍는다. 떠다니는 글자 · 납작한 색 상자 · 출처 없는 빛은 없다.

## 1. 세 층 — 층마다 그리는 법이 하나
| 층 | 무엇 | 도트 | 그리는 법 |
|---|---|---|---|
| **장면** | 받은 장면 그림 · 판 · 기물 · 사건 장치 · 소품 | 3px (판 위는 판 격자) | 도트 캔버스 + `view/pxkit` 재질. 받은 그림(장면 · 초상)은 격자만 맞춘다 |
| **장치** | 패널 · 명패 · 단추 · 칸 · 테이프 · 판결 명패 | 2px (`--px`) | UI 크롬 9-slice(`assets/ui/chrome`) + 갈무리. 결과 알림은 `verdict()` |
| **빛** | 불꽃 · 불씨 · 연기 · 빛살 · 번쩍 | 장면과 같은 3px | `view/pxfx` 입자 · 빛만 (더하기 빛 · 연기 반투명은 이 층에서만 — D-249) |

- **섞지 않는다.** CSS 상자가 장면 속 물건인 척하지 않는다(예: 예전 「합격」 도장 = HTML 테두리 상자 → 금지). 캔버스가 패널 · 단추를 흉내 내지 않는다.
- 한 층 안에서는 도트 크기가 하나다. 아이콘 · 기호는 그 층의 도트에 정수 배율로만 올린다.

## 2. 재질 다섯 — 뜻이 정해져 있다
| 재질 | 램프 (`pxkit.M`) | 뜻 | 쓰는 곳 |
|---|---|---|---|
| **철** | iron | 구조 · 틀 · 중립 | 패널, 기계 몸통, 판, 리벳 |
| **황동** | brass | 손댈 수 있는 것 · 보상 · 이름 | 단추 · 명패 · 깔때기 · 자물쇠 · 좋은 판결 |
| **쇳물** | molten | 위험 · 힘 · 열 | 불, 경고 불빛, 공격 |
| **종이** | paper | 글 · 기록 · 주인공(종이 왕관) | 손짓 테이프 · 서류 · 카드 글 |
| **녹** | rust | 쇠락 · 손해 | 녹슨 카드 · 봉인판 녹 · 나쁜 판결의 얼룩 |
| (신호) 청록 / 진홍 | teal / crimson | 내 편 · 합격 / 적 · 불량 | 등불의 **빛**으로만 (물건의 몸 색으로 쓰지 않는다) |

## 3. 빛 공식 — 모든 물건이 같은 빛을 받는다
1. 1도트 먹 테(`#0b0b0e`)
2. 위 가장자리 = 램프 +2단, 왼 가장자리 = +1단 (빛은 왼쪽 위)
3. 몸 = 램프 가운데(3단)
4. 아래 · 오른 가장자리 = −1단
5. 바닥에 먹 그림자 1~3도트 (오른아래, 반투명 없음)
6. 부피가 있는 물건(기계 · 상자)은 **3/4 시점**: 위 면(밝게) + 앞 면 — `box3()`
7. 중간 톤은 같은 램프 이웃 단끼리 4×4 베이어 디더로만 (그라데이션 금지)
8. 유리 = 어두운 안 + 대각 반사 두 줄(디더), 등불 = 둥근 유리 + 흰 반사 한 점 — `lamp()`

## 4. 부품 — 이것만 조합한다
| 부품 | 코드 | 규칙 |
|---|---|---|
| 철판 패널 | `.panel9` (chrome/panel) | 모든 창 · 팝업 · 안내창의 몸 |
| 황동 명패 | `.plate` (chrome/plate) | 창 이름은 패널 위 가장자리에 걸친 명패 하나 |
| 움푹 칸 | `.inset` | 목록 · 기록 · 대사 칸 |
| 단추 | `.btn` 철 · 황동 · 진홍 · 청록 | 동사 하나. 황동 = 진행, 진홍 = 되돌릴 수 없음, 철 = 보조 |
| 손짓 테이프 | `.ev-tap` · `.mg-hint` (chrome/tape) | 「▼ 무엇을 한다」 — 종이 테이프, 계단으로 살짝 들썩 |
| **판결 명패** | `verdict()` (`view/pxkit`) | **모든 결과 알림은 이것 하나** — 아래 5장 |
| 재질 덩어리 | `block()` · `box3()` · `rivet()` · `lamp()` | 장면 속 물건은 모두 이걸로 |
| 도트 글씨 | `pixelText()` | 장면 속 글(새김 · 표지)은 갈무리를 문턱으로 잘라 단색 도트로 |

## 5. 판결 명패 — 결과를 알리는 단 하나의 방법
- 모양: 철 테(리벳 넷) 안에 판. **좋음 = 황동 판 · 금 = 밝은 황동 판 · 나쁨 = 녹 얼룩 진 어두운 쇠 판(진홍 글)**. 글씨는 새김(어두운 글 + 아래 밝은 줄). 아래 줄에 무엇이 바뀌었는지 짧게(「분대 HP −20%」).
- 움직임(50ms 계단): 위에서 멈칫(예비) → 떨어져 2도트 파고듦(좋음이면 흰 한 장) · 먼지가 양옆으로 → 1도트 튀어 오름 → 섬. 장면이 3px 흔들린다. 남은 먼지는 디더로 꺼진다.
- 금지: 장면 위에 색 글자만 띄우기, 테두리 상자 도장, 기울인 글씨, 페이드.

## 6. 장치(미니게임) — 확률은 기계가 설명한다
- 확률이 걸린 사건은 **실재하는 기계**로 보여 준다: 무엇이 무작위를 만드는지(깔때기에서 떨어지는 부품, 녹 아래 각인, 던진 동전)가 눈에 보인다.
- 손이 닿는 것(단추 · 손잡이)은 황동이나 진홍, 깜빡이는 황동 테로 「여기」를 알린다. 손짓 테이프가 무엇을 할지 말한다.
- 애태움(앞 둘이 같으면 셋째가 오래 덜컹, 압력계 바늘이 붉은 칸에서 떤다)과 결과(경광등 회전 빛살 + 판결 명패)는 같은 박자: 예비 → 터짐 → 출렁임.
- 기계는 사건 창 위 철판 패널 안에서 돌고, 결과가 나면 디더로 걷히며 같은 창의 대화로 돌아온다(D-248).
- 장면 그림이 아직 없는 사건은 같은 문법의 정지 장면(공장 벽 · 매달린 등의 빛 웅덩이 · 장치 또는 철 표지판)을 깐다 — 빈 칸 · 아이콘 하나만 두지 않는다.

## 7. 움직임 · 글씨 (기존 원칙 그대로)
- D-180 박자: 예비 → 터짐 → 정지 프레임 → 출렁임. 공격 한 번 1초 안. 사라짐은 디더, 나타남은 계단(steps).
- D-213 글씨: 12 · 24 · 36 갈무리11(굵게), 15 · 30 · 45 · 60 갈무리14. 장면 속 글은 `pixelText()`.
