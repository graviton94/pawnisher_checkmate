# 아트 바이블 (초안)

> 그래픽·세계관·에셋 디자인은 사용자 담당. 이 문서는 사용자가 준 에셋에서 읽어 낸 규칙을 코드·UI가 지키도록 적어 둔 것이다.
> 구성은 Claude Code Game Studios `art-bible` 템플릿을 줄여 따른다.
> 세계관·테마: `docs/world.md` · 무엇을 그리고 무엇을 조합할지: `docs/art-assets.md`.

## 1. 정체성
- **한 줄**: 어두운 대성당의 체스판 위, 흰 군단이 붉은 일격으로 체크메이트를 노린다.
- **키 비주얼**: 앱 아이콘 — 검정 사선 체스판 · 흰 왕관 폰 · 붉은 사선 베기 · 세리프 로고 "PAWNISHER / CHECKMATE".

## 2. 색
| 역할 | 값 | 쓰는 곳 |
| :-- | :-- | :-- |
| 배경 | `#0b0b0e` ~ `#0e0e12` | 화면 바탕, 보드 밖 |
| 체스판 어두운 칸 | `#2f2e36` | 보드 |
| 체스판 밝은 칸 | `#56545e` | 보드 |
| 흰 기물·글자 | `#f4f1ea` | 플레이어 기물, 본문 |
| 붉은 강조 | `#e5262f` | 적·위험·공격 범위·적 의도 |
| 황동 | `#c89b3c` | 순번·AP 보너스·버튼(제출) |
| 금색 | `#facc15` | 처치·★각성·큰 배율 |
| 청록 | `#38bdf8` | 내 선택·이동 칸·AP |
- 위험/적 = 붉은색, 내 조작 = 청록, 보상·강함 = 황동/금. 이 세 의미를 섞지 않는다.

## 3. 기물
- **도트, 머리 강조형** (사용자 제공 `build-res/pieces-*-source.png`).
  - 작은 세트(흑백 12종) → 보드·목록 (`public/pieces/s-{P,N,B,R,Q,K}{0,1}.png`)
  - 큰 세트(흰 6종) → 기물 고르기·시작 덱 등 크게 보이는 곳 (`public/pieces/l-*.png`)
- 확대는 최근접(픽셀 그대로). 흐리게 보간하지 않는다.
- 진영: 흰 기물 = 플레이어, 검은 기물 = 적. 둘 다 흰 바깥 테두리라 어떤 칸에서도 실루엣이 보인다.
- 새 기물·변형(합체 등)이 필요하면 **사용자에게 에셋을 요청**한다 (직접 그리지 않음).

## 4. 글꼴
- **갈무리 (Galmuri, SIL OFL 1.1)** — 한글·영문·숫자 도트 서체. 앱에 내장 (`src/fonts.css`, woff2 3종).
  - 본문·보조: Galmuri11 (Bold 포함) · 제목·숫자·배지: Galmuri14
- 로고만 이미지(세리프)로 둔다.

## 4-1. UI 모양 (도트 패스)
- 모서리는 각지게(반경 0), 테두리 2px, 패널 3px + 검은 바깥선.
- 버튼은 아래로 떨어지는 단단한 그림자(0 3px 0 #000), 누르면 2px 내려간다. 부드러운 그라데이션·흐린 그림자 금지.
- 행동력(AP): 사용자 제공 날개 — 금색 = 남은 AP, 회색 = 쓴 AP, 보너스 AP는 금빛 테.
- 큰 기물 흑 진영(`l-*1.png`)은 흰 그림에서 바깥 흰 테두리만 남기고 안쪽을 어둡게 만든 파생본 (원본 에셋이 오면 교체).

## 5. 연출 (M6 이후 사용자 에셋에 맞춰 확장)
- 공격: 짧은 확대 → 흰 점멸 → 피해 숫자 위로 떠오름. 시너지 배율은 크기가 커질수록 크게(×2 이상 금색).
- 붕괴: 붉은 금 예고 → 칸이 어두워지며 흔들림.
- 과한 파티클·블룸 금지 (보드 가독성이 우선).

## 6. 하지 말 것
- 기물 위에 텍스트를 겹쳐 덮기 (숫자는 칸 모서리)
- 붉은색을 내 기물 장식에 쓰기
- 이모지를 아이콘처럼 남발 (☠ 같은 기능 표시는 예외, 장기적으로 도트 아이콘으로 교체)
