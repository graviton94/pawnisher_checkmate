# Play Console 「앱 콘텐츠」 답 기록 (D-637)

안드로이드 출시판(1.2.x, `io.github.graviton94.pawnisher`) 기준. 게임 내용이 바뀌면(통신 · 결제 · 광고 · 새 연출) 이 답부터 다시 본다. 근거는 코드 · 데이터를 직접 확인한 것이다 (2026-11-19).

## 1. 콘텐츠 등급 (IARC 설문)

- **카테고리**: 게임 (Game).
- **예상 등급**: 판타지 폭력이 중심이라 대략 PEGI 7 · ESRB E10+ · USK 6~12 · 한국 GRAC 12세 안팎. 어두운 이야기(동료를 녹이는 결말)가 글로 나오므로 낮게 나오면 그대로 두되, 다르게 나오면 아래 근거로 이의를 낸다.

| 설문 항목 | 답 | 근거 |
|---|---|---|
| 폭력 | **예 — 판타지 · 비현실적, 사람 아닌 캐릭터** | 판 위 싸움은 쇠로 된 체스 기물(폰 · 나이트 · 비숍 · 룩 · 퀸 · 킹, 64×64 도트)끼리 칸을 옮겨 치는 것이다. 맞으면 HP가 줄고 쓰러지면 판에서 사라진다. 사람 · 동물이 아니며 사실적인 신체가 없다. |
| 피 · 신체 훼손 | **피: 약간 · 비사실적 / 훼손: 없음** | 칠 때 · 반장 등장 때 붉은 도트 불똥 몇 칸이 튄다(코드의 색 이름이 `blood` — `cardfx.ts` `embers(…, 'blood')`, `bossintro.ts`). 쇠 기물이라 상처 · 절단 · 시체 표현은 없다. 보수적으로 「피 약간(비사실적)」으로 답한다. |
| 폭력의 대상 | 판타지 캐릭터만 | 실존 인물 · 사람 형상 없음. |
| 공포 · 무서운 장면 | 약함 | 컷신 글: 패배한 세트가 「용광로」에 녹는다는 설정, 넷째 왕관 전 결말에서 주인공이 동료를 녹여 금 갑옷을 입는다(글 · 도트 그림, 잔혹 묘사 없음). 갑자기 놀래는 연출(점프 스케어) 없음. |
| 성적 내용 · 노출 | 없음 | — |
| 비속어 · 욕설 | 없음 | `src/data` 전체에서 욕설 낱말 검색 결과 0건. 반장들의 비웃음 · 저주 섞인 예언은 있으나 욕설은 아니다. |
| 약물 · 술 · 담배 | 없음 | — |
| 차별 · 혐오 | 없음 | — |
| **도박** | **실제 돈 도박: 없음 / 모의 도박: 아니오 (아래 설명 참고)** | 아래 「확률 요소」 표. 카지노 게임(슬롯 · 포커 · 룰렛 · 블랙잭)을 흉내 낸 게임이 없고, 게임 안 돈(나사)은 플레이로만 얻으며 현금 · 아이템 구매와 이어지지 않는다. |
| 사용자 간 상호작용 · 채팅 | 없음 | 혼자 하는 게임, 온라인 기능 없음(인터넷 권한 없음). |
| 위치 공유 | 없음 | — |
| 개인정보 공유 | 없음 | 수집하지 않는다(처리방침 1~3조). |
| 디지털 상품 구매 · 결제 | 없음 | 게임 안 결제 · 광고 없음. 무료. |
| 무작위 아이템(루트박스) 구매 | 없음 | 돈으로 사는 무작위 상자가 없다. |

### 확률 요소 — 숨기지 않고 적는다

| 이름 (게임 안) | 무엇 | 거는 것 | 얻는 것 | 판단 |
|---|---|---|---|---|
| 「고장 난 조립 판정기」 사건 | 깔때기 세 칸이 도는 기계(슬롯머신 모양 연출). 옛 2.0의 「운명 기관 → 뽑기 기계」를 D-254에서 바꾼 것 | **게임 안 돈을 넣지 않는다** — 분대원 하나의 HP −35% | 40% 희귀 부품 · 25% 기물 한 단계 승급 · 35% 감전(HP −30% 더) | 로그라이크의 위험 · 보상 사건. 고르기 전에 선택지 줄에 결과 갈래가, 정보 단추에 확률이 보인다. 현금 · 게임 돈 걸기 없음 |
| 「동전 나이트」 사건 | NPC가 동전을 던진다 | 걸지 않는다 — 뒷면이면 분대원 하나 「심장 톱니 깨짐」 | 앞면 희귀 부품 | 50:50 사건 선택지 |
| 그 밖의 확률 사건(녹슨 각인 등) | 「n% 결과 · n% 결과」를 선택 전에 표시, 결과에 맞춰 룰렛 연출 | 분대 HP · 카드 상태 | 부품 · 카드 | StS류 사건 |
| 「판돈」(대국 전 선택) | 이번 대국 조건(무피격 · n처치)에 **게임 돈(나사)** 을 걸고, 이기면 더 받는다 | 게임 돈(나사)만 | 게임 돈 | 운이 아닌 **자기 실력에 거는 도전 과제**. 나사는 플레이로만 얻고 사거나 팔 수 없다 |
| 「뽑기」 카드 | 덱에서 카드를 더 「뽑는」 명령 카드(드로) | — | — | 카드 게임 용어일 뿐, 가챠 아님 |

이 때문에 「모의 도박」(카지노 게임을 흉내 내는 콘텐츠)에는 **아니오**로 답한다. 설문이 「게임 안 화폐로 무작위 결과에 거는가」를 따로 물으면 판돈은 실력 조건이라 해당하지 않고, 판정기는 화폐를 걸지 않는다고 적는다. 심사에서 판정기 연출이 슬롯으로 보인다는 지적을 받으면, 답을 「예(모의 도박 약함)」로 바꾸는 쪽이 정직하다 — 그때 이 표를 근거로 남긴다.

## 2. 데이터 보안 (Data safety)

| 질문 | 답 |
|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하는가 | **아니요** |
| 근거 | 인터넷 권한이 없어 앱에서 기기 밖으로 보내는 데이터가 없다(Google 정의의 「수집」 = 앱에서 기기 밖으로 전송). 플레이 기록 · 저장은 기기 안에만. 「결과 공유하기 → 기록 보내기」는 플레이어가 직접 복사 · 파일 저장하는 것이고 앱이 보내지 않는다 |
| 전송 중 암호화 | 해당 없음(전송 없음) |
| 데이터 삭제 요청 방법 | 앱 안 설정 › 게임 › 「진행 초기화」, 또는 앱 삭제 |
| Android 자동 백업 | 시스템 기능이라 앱의 수집이 아니다(`android:allowBackup="true"` — 기기를 바꿔도 저장이 따라오게 둔다). 처리방침 6조에 적었다 |
