# 아트팀 전달용 인물 참고 — D-437

2026-11-12. 서사 발주는 [화풍 참고도 포함한 새 묶음](../cinematic-reference/README.md)을 함께 사용한다. 현재 게임에서 사용하는 기물의 실제 PNG다. 새 디자인 제안이나 R1 원화의 인물을 정본으로 삼지 않는다. **발주 프롬프트와 이 파일들을 함께 전달한다.**

- [인물 비교표](character-sheet.png)
- [전체 PNG 묶음 다운로드](pawnisher-character-reference.zip)

## 어떤 파일을 첨부하나

| 장면 | 반드시 전달할 파일 | 추가 참고 |
|---|---|---|
| S-05 출하 · S-06 운송 | `preview/paperking-864.png` | 동료가 실제로 보이는 구도만 해당 유형의 PNG 추가 |
| S-07 금빛 왕 · 버린 왕관 | `preview/paperking-864.png` + `preview/king-form-only-864.png` | 앞 파일은 버린 종이 왕관, 뒤 파일은 킹 몸체의 구조 참고 |
| 동료가 보이는 변형 | 해당 `pawn` / `knight` / `bishop` / `rook` / `queen` PNG | 박차는 나이트형. 다른 동료의 흠집·개별 외형을 새로 확정하는 자료는 아님 |

`native/`는 투명 배경 72×72 정본이다. `preview/`는 같은 그림을 최근접 12배로 키운 투명 배경 864×864다. 축소·재해석·새 픽셀화 없이 같은 원본을 확대했다. 작업자에게는 큰 PNG를 주고 원본 도트 확인이 필요할 때 native를 쓴다.

## 고정할 것과 장면에 맞춰 그릴 것

종이왕은 **K0**다. 흰 폰 몸, 몸에 비해 큰 기울어진 황갈색 마분지 왕관, 고르지 않은 뿔과 **작은 청록 원형 장식 총 1개**의 위치·비례를 유지한다. 청록 장식을 사각형으로 바꾸거나 종이 왕관을 금속 왕관으로 다듬지 않는다. 저해상도 도트에서 장식의 외곽이 각지게 보이더라도 디자인은 원형이다(사용자 확인 D-438). 얼굴·눈·입·팔·다리를 새로 붙이지 않는다. 옛 폰+왕관 합성은 기준으로 쓰지 않는다. R1의 원형 장식 자체는 수정 대상이 아니다.

전투 도트 바깥의 굵은 흰 테는 게임판에서 구분하기 위한 표시다. **완성 장면에는 흰 스티커 테를 그리지 않는다.** 기물의 실제 밝은 몸체와 바깥 테를 혼동하지 않는다. 같은 원근·광원·접촉 그림자로 장면 안에서 다시 그린다. 이 PNG를 배경에 그대로 확대해 붙이는 발주가 아니다. 정면 자료만 있으며 옆면·뒷면의 새로운 장식이나 특징을 승인한 것은 아니다.

동료 PNG는 기물 종류별 몸체 기준이다. 특정 생존자 수·영구적인 상처·사망을 확정하지 않는다. 원화에 보이는 유형/수를 명시하고 실제 생존 분기에 맞춰 쓴다.

**`king-form-only`는 기존 검은 킹 K1이다. 새 금빛 왕의 최종 정본이 아니다.** 십자형 머리·긴 몸통·잘록한 허리·무거운 받침의 구조만 참고한다. 새 금빛 왕의 재질·색·종이왕에서 이어지는 특징은 S-07 디자인 검토에서 확정해야 한다. 기존 도금왕과 같은 인물로 취급하지 않는다.

## 출처와 검증

정본 격자는 `tools/pixel/pieces64.txt`, 재현 도구는 `tools/pixel/maker.py`다. `python3 -I tools/pixel/reference-pack.py`가 이 자료를 생성한다. 각 native를 최근접 3배로 확대했을 때 현재 실행용 `public/pieces/l-*.png`와 RGBA 픽셀이 완전히 같은지 확인한다. PNG 알파는 0/255, 확대는 정확히 12배, ZIP의 모든 내용도 대조한다. 경로·원본 커밋·SHA256은 `manifest.json`에 기록한다. 게임의 그림이나 코드에는 변경이 없다.
