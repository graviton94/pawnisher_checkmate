# 서사 그림 제작 — ChatGPT 프로젝트 방식 D-440

**이전 매번 채팅 첨부 방식은 폐기한다.** 프로젝트 지침과 소스는 한 번 등록하고 이후 채팅에는 프롬프트만 쓴다.

1. [프로젝트 지침](art/chatgpt-project/project-instructions.txt)을 프로젝트 지침 칸에 붙여 넣는다.
2. [프로젝트 소스 ZIP](art/chatgpt-project/project-sources.zip)을 풀어 PNG9개와 `ART-SOURCE-GUIDE.md`를 프로젝트 소스에 등록한다.

[설정 안내](art/chatgpt-project/README.md). 지침 파일·예시 채팅은 소스에 중복 등록하지 않는다. 현재 인물 참고와 기존 게임 화풍을 역할별로 고정하며 청록 원형 장식은 총1개다.
