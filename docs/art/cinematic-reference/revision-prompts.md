## 실제로 첨부할 파일

[화풍·인물 참고 ZIP](art/cinematic-reference/pawnisher-cinematic-reference.zip)을 풀어 **고칠 결과물 한 장과 아래 PNG만 실제 첨부**한다. 프로젝트에 파일이 있다는 전제로 생략하지 않는다. ZIP 자체 대신 그 안의 해당 PNG를 생성 채팅에 첨부한다.

| 이름 | 역할 | 가져올 것 |
|---|---|---|
| `paperking-864.png` | 인물 형태 | 몸·왕관의 비례와 기울기, 장식 위치. **청록 원형 장식 총 1개**. 저해상도 외곽이 각져 보여도 원형 |
| `style-shipping-1920.png` | 상자 화풍 | 실제 게임의 도트 크기·큰 색면·천과 판지의 명암. 빈 상자 구도나 인물 부재를 복사하지 않음 |
| `style-departure-1920.png` | 공장 화풍 | 철재·황동·색면과 픽셀 밀도. 기계의 위치를 복사하지 않음 |
| `king-form-only-864.png` | S-07에서만 추가 | 킹 몸 구조만. 검은 색·흰 테를 복사하지 않음. 새 금빛 왕의 최종 정본은 아님 |

인물 참고가 화풍을, 화풍 참고가 구도를 덮어쓰지 않는다. 왕관 뿔의 외곽은 인물 PNG를 따른다. 뿔마다 장식이 있는 디자인이 아니다. 얼굴·팔다리·흰 스티커 테 없음. 새 흠집이나 접착테이프를 인물 고유 설정으로 추가하지 않는다.

## S-06 · 지금 전달할 수정 프롬프트

첨부: **이번 컬러 상자 결과물** + `paperking-864.png` + `style-shipping-1920.png`. 이번에는 이 요청 하나만 전달한다.

```text
첨부한 컬러 상자 결과물 한 장을 수정해 주세요. paperking-864.png는 인물 형태 참고, style-shipping-1920.png는 실제 게임의 화풍 참고입니다.

왼쪽 종이왕, 앞의 천에 가린 받침, 오른쪽 위 틈에서 들어오는 사선 빛이라는 현재 구도는 유지합니다. 새 구도나 대안 여러 장을 만들지 마세요.

왕관의 청록색 원형 장식은 전체에 딱 1개입니다. 현재 여러 장식 중 인물 참고에서 보이는 앞면 위치의 1개만 남깁니다. 나머지 청록 점·보석은 없애고 황갈색 종이 면으로 잇습니다. 왕관의 기울기와 몸 대비 크기는 인물 참고를 따릅니다. 장식을 사각으로 바꾸지 않습니다.

화풍은 기존 게임 그림에 맞춰 정리합니다. 가로 320칸·세로 180칸의 저해상도 도트 장면으로, 인물과 배경 모두 같은 픽셀 격자와 밀도를 씁니다. 곡선은 작은 계단 모양, 종이·천·몸은 큰 단색 덩어리와 재질당 약 3~4단 명암으로 표현합니다. 가는 펜선, 미세한 얼룩·실밥·반짝임, 매끈하게 이어지는 명암을 없앱니다. 따뜻한 빛은 좁은 색면으로 남기고 번짐 없이 단단한 경계를 만듭니다. 몸의 흠은 간결한 몇 도트만 남깁니다. 모자이크 필터를 씌운 고해상도 그림이나 회화풍으로 만들지 않습니다.

표정·눈·입·팔다리·흰 스티커 테·글자·UI는 없습니다. 원본 320×180 PNG 한 장과 최근접 6배 미리보기 1920×1080을 요청합니다. 작은 원본을 만들 수 없다면 큰 출력만 제공했다고 명시하고 축소·확대 이력을 꾸미지 마세요. 이번 핵심은 장식 1개와 기존 게임에 맞는 굵은 도트 표현입니다.
```

## S-05 · 상자 화풍 확인 뒤, 세 번째 문턱 근접안 수정

첫 번째의 상단 직사각 가림과 배경 인물 증가, 두 번째의 문 앞 정지 구도는 보류한다. 세 번째의 받침·문턱·왕관 그림자를 작업 기반으로 권한다. 아직 구도 승인은 아니다.

첨부: **이번 세 번째 문턱 결과물** + `paperking-864.png` + `style-departure-1920.png`.

```text
첨부한 문턱과 받침의 근접 결과물 한 장을 수정해 주세요. paperking-864.png는 인물 비례, style-departure-1920.png는 기존 게임 화풍 참고입니다.

받침 근접 구도와 뒤로 드리운 왕관 그림자를 유지합니다. 받침 앞부분이 문턱 바깥에 걸치고 뒷부분은 안에 남아 경계를 넘는 순간을 보여 주세요. 위를 가리는 문틀이나 가로보는 기둥과 연결된 구조로 그립니다. 연결 없는 회색 직사각 띠는 없앱니다. 동료를 추가하거나 전신 구도로 바꾸지 않습니다.

가로 320칸·세로 180칸의 기존 게임 도트 밀도로 정리합니다. 기물·철판·바닥은 같은 격자, 일정한 계단 외곽, 재질당 약 3~4단 큰 색면으로 그립니다. 미세한 금·얼룩·펜선·매끈한 명암 대신 큰 마모 몇 군데만 남깁니다. 회화풍·모자이크 필터·블러·그라데이션 없이 출하구 참고의 철색·황동·좁은 바깥빛을 따릅니다. 흑백 구도안이 아닌 컬러 수정본입니다.

왕관이 프레임 밖이면 장식을 몸이나 바닥에 대신 그리지 않습니다. 보이는 경우 청록색 원형 장식은 왕관 전체에 총 1개입니다. 얼굴·팔다리·흰 스티커 테·문자·UI 없음. 원본 320×180 PNG 한 장과 최근접 6배 미리보기를 요청합니다. 원본 제작이 불가능하면 실제 제공한 크기만 명시합니다. 대안 여러 장은 만들지 않습니다.
```

## S-07 · 앞 단계 확인 뒤, 다섯 번째 받침·왕관안 수정

여섯 번째 전신안은 왕의 전시 인상이 남고, 일곱 번째는 왕관 장식 수와 형태가 인물을 바꾼다. 다섯 번째의 눌린 왕관·멀어지는 상자를 작업 기반으로 권한다. 상반신 새 디자인까지 동시에 발명하지 않는다.

첨부: **이번 다섯 번째 결과물(받침이 왕관을 누르는 안)** + `paperking-864.png` + `king-form-only-864.png` + `style-departure-1920.png`.

```text
첨부한 왕의 받침·버린 종이 왕관·멀리 떠나는 상자 장면 한 장을 수정해 주세요. 종이왕 참고는 옛 왕관 형태, 킹 참고는 몸 구조만, 출하구 참고는 기존 게임 화풍입니다.

현재 근접 구도를 유지합니다. 새 금빛 킹의 받침 가장자리가 종이 왕관 한쪽을 실제로 누르고, 종이는 아래에서 접히며 나머지 부분은 바닥에 닿습니다. 떠나는 상자는 멀고 작게 남깁니다. 카메라를 빼서 왕 전신을 보여 주거나 새 인물을 추가하지 마세요.

종이 왕관은 종이왕 참고와 같은 물건입니다. 청록색 원형 장식은 전체에 딱 1개만 남깁니다. 줄지어 붙은 점들은 지우고 종이 면으로 잇습니다. 접힘에 따라 유일한 장식이 가려질 수는 있습니다. 이를 보여 주려고 다른 면에 하나 더 그리지 않습니다. 종이 왕관을 금속으로 만들지 않습니다.

현재 흑백을 기존 공장 그림의 철색·황동·황갈색 종이로 채색합니다. 왕의 몸은 흰 도자기가 아니라 무거운 금빛 금속입니다. 밝은 면을 좁게 남겨 전체가 트로피처럼 빛나지 않게 합니다. 가로 320칸·세로 180칸의 동일한 도트 격자, 큰 단색 덩어리, 재질당 약 3~4단 명암으로 그립니다. 가는 펜선·미세 질감·매끈한 명암·블러·그라데이션·모자이크 필터·흰 스티커 테·글자·UI는 없습니다.

원본 320×180 PNG 한 장과 최근접 6배 미리보기를 요청합니다. 작은 원본을 만들 수 없다면 실제 제공한 크기만 명시합니다. 다른 구도와 전신 디자인 시안은 이번에 만들지 않습니다.
```

## 수령 후 판정

1. 장식 총 1개·원형·청록, 몸과 왕관의 비례부터 확인한다.
2. 기존 장면과 같은 표시 크기로 나란히 본다. 선·색면·재질이 다른 작품처럼 보이면 보류한다. 색 수가 적거나 외곽이 계단이라는 것만으로 도트 합격이라 하지 않는다.
3. 실제 작은 원본과 큰 출력의 픽셀·확대 관계를 검사한다. 채팅 미리보기만으로 네이티브 도트·정확한 팔레트·무보간을 입증했다고 하지 않는다. 큰 파일만 오면 실제 반입 격자와 결과를 대조한다. 잘못된 인물과 회화 표현을 축소로 해결했다고 하지 않는다.
4. 한 장의 인물·화풍이 맞으면 다음 장으로 간다. 생성 도구가 같은 실패를 반복하면 문장만 늘리지 않고 기존 배경 활용 또는 도트 작업자의 직접 정리가 필요한지 판단한다.

이번 채팅 결과 7장은 검토 자료이며 런타임에 반입하지 않는다. 생존 동료 분기와 대사 위치는 새 원화 확정 뒤 검수한다. main/APK 변경 없음.
