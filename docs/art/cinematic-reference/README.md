# 서사 수정 발주 참고 — D-439

**이번에는 상자 한 장부터** 고친다. `revision-prompts.md`의 S-06 프롬프트와 아래 이미지 세 장을 생성 채팅에 실제 첨부한다. 프로젝트에 저장해 둔 것만으로 전달했다고 보지 않는다.

1. 사용자가 받은 컬러 상자 결과물 — 고칠 대상. 이 ZIP에는 해당 원본을 넣지 않았다.
2. `paperking-864.png` — 인물 형태. **청록색 원형 장식 총 1개**, 몸·왕관 비례와 기울기. 전투용 흰 테는 옮기지 않는다. 도트가 각져 보여도 장식 디자인은 원형이다.
3. `style-shipping-1920.png` — 기존 게임 화풍. 도트 밀도·색면·재질만 따르고 빈 상자 구도를 복사하지 않는다.

출하구 장면에는 `style-departure-1920.png`를 화풍 참고로 쓴다. `king-form-only-864.png`는 S-07 몸 구조만 참고한다. 검은 색·흰 테는 복사하지 않는다. 새 금빛 왕의 확정 디자인이 아니다.

`style-*-320.png`는 실행용 320×180 파일 그대로다. `style-*-1920.png`는 최근접6배 표시용 파일이다. 역할별 참고만 첨부해 구도·인물·화풍이 서로 덮어쓰지 않게 한다.

수정 결과는 한 장만 받는다. 장식 개수·인물·게임 화풍을 먼저 확인하고 다음 장으로 간다. 큰 출력만 받았으면 네이티브320 제작을 확인한 것으로 쓰지 않는다. 실제 반입·격자 정리·전후 대조는 개발 측에서 수행한다.

새 그림이나 변경한 게임 에셋이 아니다. `python3 -I tools/pixel/cinematic-reference.py`로 복사/최근접 확대하며 출처·SHA256·변환은 `manifest.json`에 남긴다. 동봉 발주문은 오프라인 전달용 사본이며 최신 기준은 `docs/asset-order-story-cinematics.md`다.
