# 게임 전체 에셋 공통 기준 — D-441

이 문서는 이번 S-05~07만을 위한 지침이 아니다. 사건·보스·서사 일러스트, 기물, 아이템, UI에 공통인 제작 원칙과 유형별 차이를 구분한다. 모든 파일을 같은 크기·색상 수로 만드는 규칙이 아니다. 이번 결과를 반입하거나 기존 게임 그림을 자동으로 바꾸는 문서도 아니다.

## 공통 시각 언어

- 스팀펑크 체스 공장. 철·황동·종이·나무·녹의 재질이 구별되고 마모는 형태를 설명한다. 모든 면을 점무늬로 덮지 않는다.
- 원본 도트는 정사각형 격자. 확대는 최근접 정수배. 물체마다 다른 크기의 도트를 쓰거나 세밀한 붓그림 외곽만 계단으로 만들지 않는다.
- 인물 실루엣과 행동, 중요한 소품, 배경 순으로 읽힌다. 전경·중경·원경이 같은 선명도와 무늬 밀도를 갖지 않는다. 배경은 구조를 남기되 원경의 대비·세부를 줄인다.
- 차가운 먹색/철 회색의 구조와 따뜻한 황동/목재/불빛의 대비를 공유한다. 사건에 따라 녹색·청록·진홍을 쓸 수 있다. 모든 그림을 갈색으로 칠하거나 같은 밝기 분포로 만들라는 뜻이 아니다.
- 같은 재질은 유사한 명도 단계와 채도 관계를 쓴다. 그림자·중간색·빛이 분리된 색면을 우선한다. 주요 재질은 약3~5단으로 설계하되 기존 그림의 미세 RGB값 개수와 혼동하지 않는다. 장면 전체를 임의의 고정24색으로 줄이지 않는다.
- 밝고 강한 색은 인물·사건의 핵심·실제 광원에 집중한다. 배경의 모든 리벳과 얼룩을 같은 강도로 강조하지 않는다. 한 장 안의 광원과 그림자 방향은 일치해야 한다. 장면의 창·용광로·등불 방향을 UI의 왼쪽 위 광원에 억지로 맞추지 않는다.

## 디더링과 질감

기존 사건·보스의 디더링은 화풍의 일부이므로 전면 금지하지 않는다. 인접한 명도 단계 사이, 큰 어두운 재질이나 제한된 그림자 전이에 2×2 또는4×4 계열의 일정한 패턴을 사용한다. 무작위 점얼룩과 다르다.

인물의 주요 실루엣·작은 장식·기호·가독성이 필요한 아이콘 내부에는 디더링을 넣지 않는다. 화면 전체나 밝은 몸·보석·바닥에 동일한 체크 패턴을 두르지 않는다. 디더링과 녹·흠집은 각각의 위치·재질에 이유가 있어야 한다. 기본 큰 색면이 먼저 읽히고 무늬는 나중에 읽혀야 한다. 원경의 패턴 대비는 줄인다.

기존 사례를 보고 새 발주의 정확한 크기가 필요할 때는 채팅에서 프로필/슬롯을 정한다. 모든 기물에 보석1개 같은 특정 인물 규칙을 적용하지 않는다. 인물별 설정은 `ART-SOURCE-GUIDE.md`를 따른다. ChatGPT 지침에는 특정 주인공·이번 장면의 구도를 넣지 않는다.

## 참고 우선순위

1. 인물·아이템 정본: 생김새·비례·장식 수.
2. 해당 유형 사건/보스/아이콘/UI 참고: 픽셀 밀도·색면·명암·질감.
3. 장소 참고: 공간·소품·재질. 최근 배경이라는 이유로 기존 사건/보스의 화풍을 덮어쓰지 않는다.
4. 채팅의 장면/수정 지시: 사건·카메라·수정 범위. 기존 오류 시안의 임의 소품은 설정으로 승격하지 않는다.

## 반입과 일관성은 별개

현재 `scene-import.py`는 격자를 복원하고 장면의 `colors=0` 옵션으로 팔레트 축소를 끈다. 대표색을 고르는 과정에서 미세한 RGB 변형도 남는다. 격자 복원만으로 색 램프·디더링 양·장면 내용이 같아지지 않는다. 기존 그림이 모두 엄격한 소수 팔레트로 제작됐다고 주장하지 않는다.

새 결과는 인물·내용 확인 → 격자 복원 → 기존 사건/보스와 같은 표시 크기의 비교 → 색면/대비/디더링/재질 확인 순으로 검수한다. 자동 색상 집계는 진단 자료이며 그림의 합격 점수가 아니다. 전역 팔레트 강제·기존 그림 재반입·디더링 제거는 개별 결과 비교 없이 일괄 실행하지 않는다.
