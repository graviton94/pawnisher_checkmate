# ChatGPT 프로젝트 — 한 번 설정 후 프롬프트만 입력

## 1. 프로젝트 지침

`project-instructions.txt` 내용을 프로젝트의 **지침** 칸에 한 번 붙여 넣는다. 이전 사각 장식·다중 장식·매번 채팅 첨부 지시는 이 내용으로 교체한다.

## 2. 프로젝트 소스

`project-sources.zip`을 내려받아 풀고, 안의 **PNG9개 + ART-SOURCE-GUIDE.md = 총10개 파일**을 프로젝트 **소스**에 한 번 등록한다. ZIP 자체나 예전 발주서 여러 판을 소스로 중복 등록하지 않는다. `project-instructions.txt`와 `chat-prompts.txt`는 소스에 넣을 파일이 아니다.

PNG9개는 종이왕·동료5종·킹 형태 참고7개와 실제 게임의 공장·상자 화풍2개다. 화풍 파일은 최근접 확대본 하나씩만 넣어 같은 그림의 원본/미리보기를 중복 등록하지 않는다. 기존 프로젝트에 같은 이름의 예전 파일이 있으면 새 묶음으로 교체한다. 오류 시안은 정본 참고로 쓰지 않는다.

## 이후 채팅

`chat-prompts.txt`의 필요한 문장 하나만 입력한다. 첫 작업은 S-06 상자 한 장이다. 다음 장면과 같은 대화의 수정에서도 프로젝트 참고 이미지를 다시 첨부하지 않는다. 새로 받은 외부 결과물을 고칠 때만 그 새 결과물이 작업 대상이 될 수 있다.

프로젝트 지침은 요청을 정리하는 수단이며 생성 도구의 결과 정확성을 보장하는 장치는 아니다. 결과 파일의 실제 격자와 인물·화풍 검수는 별도로 한다. 게임 코드·그림을 변경하는 패키지가 아니다.
