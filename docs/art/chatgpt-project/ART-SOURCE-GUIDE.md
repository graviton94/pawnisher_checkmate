# Pawnisher : Checkmate — 프로젝트 소스 기준

이 문서와 같은 묶음의 PNG를 ChatGPT 프로젝트 소스에 한 번 등록한다. 장면 생성·수정 채팅에는 프롬프트만 쓴다. 참고 자료를 매번 채팅에 다시 첨부하는 방식이 아니다. 이번 기준은 과거 R1/R2/R3 발주문의 반복 첨부 요구와 장식 수가 다른 시안을 대신한다.

인물 PNG는 인물 형태, style PNG는 화풍이다. style 그림에 종이왕이 없다고 요청한 인물을 빼거나, 인물 PNG에 흰 테가 있다고 일러스트에 붙이지 않는다. 동료 PNG는 유형별 몸체 기준이며 생존자 수·개별 상처를 확정하지 않는다. 전투용 도트를 배경에 그대로 붙이지 말고 같은 원근과 광원 안에서 장면으로 그린다.

## 종이왕 고정

- 흰 폰 몸과 머리에 비해 큰 기울어진 황갈색 마분지 왕관. 외곽과 비례는 `paperking-864.png`를 따른다.
- **청록색 원형 장식은 왕관 전체에 총1개.** 사각이 아니다. 뿔마다 붙이거나 뒤·옆에 추가하지 않는다. 시점상 가려지면 숨겨도 되지만 대신 다른 위치에 새로 그리지 않는다.
- 무광 종이 왕관을 금속 왕관으로 바꾸지 않는다. 새 보석·접착테이프·흠집을 인물 고유 설정으로 추가하지 않는다.
- 인간의 눈·입·표정·팔다리와 전투용 흰 스티커 테를 붙이지 않는다.

## 화풍 고정

두 style 파일은 실제 실행용 320×180 그림을 최근접6배로 확대했다. 따라서 큰 파일 크기가 세밀한 그림을 뜻하지 않는다. 최종 게임과 같은 320×180 기준의 도트 밀도, 인물과 배경에 공통인 격자, 간결한 계단 외곽, 큰 색면, 재질당 약3~4단의 단단한 명암을 따른다. 매끈한 회화에 가장자리만 울퉁불퉁하게 만든 표현과 다르다.

미세한 펜선·잔얼룩·실밥·과한 반짝임·부드러운 명암·블러·그라데이션·빛 번짐·모자이크 필터 없음. 실제 출력 크기와 네이티브 도트 제작 여부는 구분한다. 생성하지 않은 작은 원본이나 확대본을 만들었다고 주장하지 않는다.

## 장면 번호 — 채팅에서는 번호로 요청 가능

### S-06 운송 상자 — 먼저 제작

종이왕이 왕으로 교체되지 않고 자기 몸으로 공장을 떠나는 길이다. 낮은 카메라, 화면 왼쪽 종이왕, 앞의 천이 받침 일부를 가림, 가까운 판지 벽, 오른쪽 위 아주 좁은 틈에서 들어오는 사선 빛. 빛은 종이 가장자리와 몸 한 면만 단단하게 비춘다. 넓은 창문이나 안락한 방으로 만들지 않는다. 왕관 장식1개. 기본 그림에는 종이왕1명만 보이며 다른 동료는 그리지 않는다. 화풍 `style-shipping-1920.png`.

### S-05 문턱 — S-06 화풍 확인 뒤

받침과 문턱을 바닥 가까이서 본 근접 구도. 받침 앞은 바깥, 뒤는 안에 남아 경계를 가로지르는 순간. 머리와 왕관은 잘려도 되고 왕관 그림자는 뒤로 남는다. 철 문틀은 실제 기둥과 연결되어야 하며 연결 없는 직사각 띠로 화면을 가리지 않는다. 동료 추가 없음. 화풍 `style-departure-1920.png`.

### S-07 왕만 남음 — 앞 단계 확인 뒤

주인공이 새 금빛 왕의 몸을 택하고 동료의 상자는 떠난다. 금빛 킹 받침을 가까이 보며 그 가장자리가 버린 종이 왕관 한쪽을 눌러 접는다. 멀리 작은 운송 상자, 가까이 금속 받침과 접힌 종이의 대비. 새 몸 전체를 전시하려고 카메라를 빼지 않는다. 옛 왕관은 같은 물건이며 청록 원형 장식 총1개. 새 몸은 무거운 금속, 종이 왕관은 황갈색 마분지다. 다른 폰 몸·동료·시체 추가 없음. 화풍 `style-departure-1920.png`. 킹 상반신의 최종 새 디자인은 이번 근접 컷에서 새로 확정하지 않는다.

## 생성·수정 방식

한 번에 한 장만 생성한다. 번호만 주면 위 장면을 따른다. 수정 요청에서는 해당 대화의 직전 결과를 대상으로 지정된 부분을 고치고 구도는 유지한다. 새로운 구도 요청이 있을 때만 카메라를 바꾼다. 사용자가 결과물 번호를 지정하면 그 결과를 사용한다. 이번 채팅에 나온 과거 오류 시안의 추가 보석·회화풍·인물 변형을 기준으로 학습하지 않는다.
