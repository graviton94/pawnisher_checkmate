# 11장. 심화 계획 — 레퍼런스(Gambonanza · Slay the Spire) 반영

> 상태: 💬 검토 중 (§11.7의 사용자 결정 후 해당 장에 반영하고 ✅로 바꾼다)

## 11.1 목적

게임 전체는 처음부터 끝까지 돈다 (M1~M8). 이제 "한 판이 재밌다"에서 **"수십 번 등반해도 매번 다른 판단을 하게 된다"**로 올린다.
두 레퍼런스에서 검증된 구조를 가져오되, **우리 근간 규칙은 하나도 바꾸지 않는다.**

### 지키는 것 (변경 금지)

| 근간 | 출처 | 이 계획에서 |
| :--- | :--- | :--- |
| 킹의 죽음 = 승패, 체크메이트(한 턴 몰살 금지) | 1장 §1.2, D-022 | 유지. 전멸 승리(Gambonanza) 채택 안 함 |
| 계획 → 제출 → 예약 순서대로 이동 → 공격 | 1장, D-016 | 유지. 모든 새 기믹은 이 시퀀스 안의 "착지 시점" 또는 "공격 시점"에 붙는다 |
| 이동한 기물만 공격, 겹쳐 잡기 없음 | 1장 §1.2 | 유지. 예외는 지금처럼 ⚠️로 명시 |
| 적 = 같은 규칙의 AI (반칙 없음) | D-002, 4장 | 유지. 엘리트 접사·지형도 플레이어가 얻을 수 있거나 양쪽에 같게 작용하는 것만 |
| 결정론 (`simulate()` 하나) | 10장 | 유지. 모든 새 확률은 런 시드 RNG |
| 기물은 판이 끝나면 완전 부활 | 6장 §6.1 | 유지. 영구 소멸(Gambonanza) 채택 안 함 |
| 덱 = 전원 출전 (드로우 없음), 유형 단위 대장간 | 6장 | 유지. StS 드로우 더미 이식(레포트 7.1) 채택 안 함 |
| 적 의도 예고는 인챈트 E16 전용 | D-027 | 유지. 대신 "공개 정보"인 위협 범위를 보기 좋게 한다 (§11.4-A3) |

## 11.2 진단 — 레퍼런스의 교훈 vs 우리 현재 상태

| 교훈 (출처) | 우리 현재 | 판정 |
| :--- | :--- | :--- |
| 결과를 미리 보여 주는 투명한 퍼즐 (StS 의도, ITB) | 내 턴 결과 100% 미리보기, 적 의도는 E16 | ✅ 이미 강점 |
| 결정적이고 "말이 되는" 적 AI (StS 상태 기계 / Gambonanza 블런더 비판) | 빔 서치, 실수는 단계별 "차선책"만 | ✅ 유지 |
| 교착 처벌 (Gambonanza 크럼블) | 요충지 + 붕괴하는 대성당 + 서든데스 | ✅ 이미 있음 |
| 이산적 규칙 비틀기 유물 (Gambonanza 갬빗) | 인챈트 16종, 수치 성장 없음, ★각성 | ✅ 방향 같음 · **양이 부족** (16종) |
| 막마다 다른 질문을 던지는 보스·엘리트 (StS 게이트키퍼) | 컨셉 보스 3종 = 구성 + 인챈트만, 질문이 명시돼 있지 않음 | ⚠️ **보강** |
| 지형·타일이 만드는 공간 퍼즐 (Gambonanza 타일) | 요충지 1개 + 붕괴 칸뿐, 보드는 빈 체스판 | ⚠️ **보강** |
| 적 기물 개성 (Gambonanza 변조자) | 적은 유형·강화·인챈트로만 다름 | ⚠️ **보강** |
| 클래스별 정체성·풀 관리 (StS 4클래스·75장 / Gambonanza 풀 희석) | 시작 덱 3+3종, 공용 풀 하나 | ⚠️ **보강** |
| 대가성 선택 (StS 보스 유물) | 보상이 전부 순수 이득 | ⚠️ **보강** |
| 고정 층·보스 예고로 계획 가능한 맵 (StS) | 엘리트 5층부터만 규칙, 보스는 도착해야 앎 | ⚠️ **보강** |
| 판 사이에 이어지는 긴장 (StS 체력 누적 손실) | 완전 부활 → 판 안의 손실이 다음 판에 의미 없음 | ⚠️ **보강** (부활은 유지, §11.5-C4) |
| 빌드 보존형 난이도 (StS 어센션 vs Gambonanza 시련) | 승천 0~5, 빌드 파괴 없음 | ✅ 방향 같음 · **단계 확장** |
| 텔레메트리 3지표 (StS) | 자동 등반 시뮬, 층별 승률 | ⚠️ **지표 보강** |
| 확률 보정 (StS 오프셋) | 크랙 게이지(★ 천장), 태그 가중 (D-025) | 🔶 일부 · 희귀도 오프셋 추가 |

## 11.4 기둥 A — 전투의 깊이 (판 안의 판단)

### A1. 전술 키워드 판정
엔진이 공격을 처리할 때 아래 패턴을 **사건(event)으로 기록**한다. 피해 공식은 바꾸지 않는다.

| 키워드 | 판정 (실행 중 보드 기준) | 체스 대응 |
| :--- | :--- | :--- |
| **포크** | 한 공격이 적 2기 이상을 타격 | Fork |
| **관통** | 사선 공격이 첫 적을 지나 두 번째 적을 타격 (E02·A03) | Skewer |
| **사선 개척** | 앞 순번의 이동으로 열린 사선으로 공격 (E09가 이미 계산) | Discovered attack |
| **돌파** | 앞 순번이 처치해 비운 칸에 착지해 공격 (D-016 콤보) | — (우리 고유) |
| **연쇄** | 한 턴에 처치 3회 이상 | — |
| **체크** | 상대 킹을 체크 보호(HP 1)까지 몰아넣음 | Check |

- **화면**: 공격 순간 키워드 배너 (0.4초, 색 + 아이콘). 미리보기에도 예약 옆에 작은 키워드 칩 — "이 순서로 두면 포크가 난다"를 누르기 전에 보여 준다 (UI 원칙 1).
- **쓰임**: ① 학습 — 체스 전술 이름을 몰라도 배운다. ② 새 인챈트의 발동 조건 (§11.5-B4). ③ 전투 평가 (§11.5-C4).
- Balatro식 피해 폭발은 키워드를 조건으로 하는 **곱연산 인챈트**(E12~E15 계열)로만 낸다 — 몇 개를 모으느냐는 플레이어 선택.

### A2. 지형 칸
엘리트·보스 보드와 Act 2 이후 일반 보드에 시드로 배치한다. **기물이 이동해서 착지할 때** 발동하거나, 위에 있는 동안 작용한다. 양 진영에 같게 적용.

| 지형 | 효과 | 설계 의도 |
| :--- | :--- | :--- |
| **폐허** | 이동·착지 불가, 사선 차단 | 보드 기하 자체를 바꾼다 (가장 단순) |
| **고지** | 착지한 기물의 이번 공격 ATK +30% | 탐나는 착지점 → 상대가 그 칸을 노린다 |
| **엄폐** | 위에 있는 기물 받는 피해 −20% | 요충지와 달리 영구·소형. 수비 거점 |
| **덫** | 착지한 기물은 다음 자기 턴에 이동 불가 (1회 후 사라짐) | 적을 덫으로 유도하는 수 |
| **금맥** | 플레이어 기물이 착지하면 +골드 (판당 1회), 적이 착지하면 사라짐 | 경제 미끼 — 위험한 칸에 둔다 (Gambonanza 황금 타일) |

- 배치는 좌우 대칭(금맥 제외), 진영 끝 두 줄과 요충지 후보에는 두지 않는다.
- AI 평가 함수에 지형 항목 추가. 길게 누르면 설명 (UI 원칙 7).

### A3. 위협 지도 (D-027 범위 안)
- 지금: 적 기물을 누르면 그 기물의 위협 범위. → 추가: 「위협」 토글 버튼으로 **모든 적의 다음 턴 공격 가능 칸을 겹쳐 보기** (칸마다 겹친 수, ☠ = 처치 가능).
- AI의 실제 계획은 보여 주지 않는다 (그건 E16). 플레이어가 손으로 셀 수 있는 공개 정보를 대신 세어 줄 뿐이다.

### A4. 엘리트 접사
엘리트 군단의 기물 1~2기에 붙는다. **아이콘 + 이름이 항상 보인다.** 형식은 "적 기물에 붙은 1장짜리 인챈트"이고,
엘리트 보상에서 **약탈**(그 접사를 내 기물 유형 하나에 붙임, §11.5-B5)로 플레이어도 얻을 수 있다 → D-002 공정성 유지.

| 접사 | 효과 | 시험하는 것 |
| :--- | :--- | :--- |
| **최후의 방패** | 다른 적 일반 기물이 남아 있는 동안 HP 1 아래로 떨어지지 않음 (체크 규칙의 일반 기물판) | 처치 순서 계획 (Gambonanza 엘리트) |
| **보복** | 이 기물을 처치한 공격자에게 ATK 50% 반사 | 무작정 연쇄 처치 |
| **방벽** | 자기 턴 시작마다 보호막 +10 | 집중 화력 |
| **기동** | 이동 AP −1 | 위협 범위 계산 |
| **결속** | 인접 아군이 처치되면 ATK +30% (그 판) | 처치 순서 |
| **호위** | 자기 킹 인접 시 받는 피해 −30% | 킹 공략 경로 |

- 6종부터 시작, 접사 1개 = 군단 강화 약 +1 수준으로 시뮬 조정.

### A5. 보스 전장 규칙
컨셉 보스마다 **양 진영에 같게 적용되는 전장 규칙 하나** + 명시된 "질문"을 준다. 보스는 그 규칙에 맞게 구성돼 있어 유리할 뿐이다.

| 보스 | 질문 (게이트키퍼) | 전장 규칙 (안) |
| :--- | :--- | :--- |
| 기병 군주 (나이트) | "사선으로 막을 수 없는 L자 위협을 **착지 칸 점유**로 막을 수 있나?" | 기병 진영: 보드 양 측면 2열에 고지 지형 |
| 사선의 대주교 (비숍) | "관통하는 사선에서 **킹을 비켜 세울** 수 있나?" | 빛의 회랑: 대각선 두 줄이 엄폐 불가(엄폐·요충지 감소 무효) |
| 강철 성주 (룩) | "고HP 전열을 **순차 관통·돌파**로 뚫을 수 있나?" | 성벽: 보드 중앙 가로줄에 폐허 2~4칸, 붕괴 시작 +3라운드 |
| 균열의 왕 (최종) | 종합 — 빠른 엔진, 방어, 체크 마무리 | 2페이즈: 체크 상태 진입 시 균열 폭발 (붕괴 칸 2쌍 즉시) |

## 11.5 기둥 B·C — 빌드와 등반의 깊이 (판 사이의 판단)

### B1. 지휘관 4종 (해금 시작 덱의 확장)
StS 클래스처럼 **같은 규칙, 다른 자원 운용**. 지휘관 = 시작 덱 후보 + **시작 인챈트 1장(전용, 풀에 없음)** + 보상 가중치.

| 지휘관 | 시작 덱 | 시작 인챈트 (안) | 정체성 |
| :--- | :--- | :--- | :--- |
| 보병 원수 (기본) | 기존 시작 덱 3지선다 | **진군 나팔**: 폰이 첫 이동 2칸일 때 ATK +30% | 폰 물량·승급 |
| 기병 대장 | K N N | **박차**: 판의 첫 나이트 이동 AP −1 | 포크·처치 템포 |
| 사제장 | K B B | **성광**: 사선 개척 공격 시 공격자 보호막 +8 | 사선·관통·수비 |
| 성주 | K R P | **주춧돌**: 룩이 이동하지 않은 턴마다 보호막 +5 (최대 20) | 요충지·지형·버티기 |

- 공용 풀 + 지휘관 전용 인챈트 6~8종. 한 런에 보이는 풀은 **30종 안팎**으로 유지 (Gambonanza 희석 교훈).
- 해금 조건은 지금의 시작 덱 해금(D-025 이후 meta.ts)을 그대로 옮긴다.

### B3. 왕관 인챈트 (대가성 보스 보상)
Act 1·2 보스 보상 3지선다 중 1칸을 왕관으로. **별도 왕관 슬롯 1칸** (인챈트 6칸과 경쟁하지 않음, 런에 하나).

| 왕관 | 이득 | 대가 |
| :--- | :--- | :--- |
| 강행군 | 턴당 AP +1 | 이후 대장간 이용 불가 |
| 맹목 | 턴당 AP +1 | 적 위협 범위·E16 의도 예고를 볼 수 없음 |
| 탐욕 | 턴당 AP +1 | 상점 가격 +40% |
| 고독 | 턴당 AP +1 | 액티브 카드 슬롯 4 → 2 |
| 폭군 | 모든 기물 ATK +20% | 매 판 첫 턴 AP −2 |
| 무거운 왕관 | 턴당 AP +1 | 킹이 체크 보호를 받지 않음 (8×8 이상에서도 한 턴 몰살 가능) |

- "내 빌드가 이 페널티를 감당하나"를 판단하게 한다. 받지 않으면 일반 희귀 인챈트로 대체 가능.

### B5. 엘리트 약탈
엘리트 격파 시 보상에 "접사 약탈"이 한 칸으로 뜬다 — 그 엘리트의 접사 하나를 **내 기물 유형 하나**에 붙인다 (유형 단위, 6장 원칙 유지). 인챈트 슬롯을 하나 차지한다.

### C1. 고정 층 규칙과 보스 예고

| 층 (Act 안) | 규칙 |
| :-: | :--- |
| 1~3 | 쉬운 군단 풀 (지금과 같음), 엘리트 없음 |
| 5~ | 엘리트 등장 (지금과 같음) |
| 7 | **보물고 고정**: 전투 없이 희귀 가중 인챈트 3지선다 (모든 경로) |
| 11 | **야영지 고정** (보스 직전): 대장간 1회 할인 강화 / 카드 정비(지속형 1장 교체) / 기물 1기 교체 중 택1 |
| 12 | 보스 |

- 엘리트·상점·대장간·제단은 **2층 연속 배치 금지**.
- **보스 예고**: Act 시작 시 맵 꼭대기에 그 Act 보스 초상 + 질문 태그(§A5). 런 시작 화면에도 이번 런의 두 컨셉 보스를 보여 준다.
- **균열 엘리트**: Act당 1개, 맵에 균열 표식. 접사 2개 + 지형. 보상 = 희귀 인챈트 확정 + 크랙 게이지 +1.

### C2. 확률 보정 (희귀도 오프셋)
- 인챈트 3지선다의 희귀 확률: 기본값 + 오프셋. 오프셋은 런 시작 −5%p, **일반만 뜬 선택지마다 +1%p** (최대 +30%p), 희귀가 뜨면 −5%p로 초기화.
- 엘리트 카드 3지선다의 소멸형 포함 확률: 40%에서 시작, 포함되면 −10%p, 안 되면 +10%p (StS 포션 공식).
- 기존 장치(크랙 게이지 ★ 천장, D-025 태그 가중)는 그대로 둔다.

### C3. 승천 0~15 (빌드 보존 원칙)
**원칙: 획득한 기물·인챈트·카드를 빼앗거나 무효화하지 않는다.** 적과 경제만 강해진다.

### C4. 전투 평가 (판 사이의 긴장)
완전 부활은 유지하되, **어떻게 이겼는가**가 다음 판의 자원이 되게 한다.

| 평가 | 조건 | 보상 (초기값 🔧) |
| :--- | :--- | :--- |
| 무손실 | 아군 기물 파괴 0 | +15 골드 |
| 속전 | 기준 턴 이하 (보드·층별) | +10 골드 |
| 철벽 | 킹 무피해 | 다음 보상 3지선다 리롤 1회 |

- 결과 화면에 별 3개로. 키워드 기록(§A1)과 같이 보여 준다.

### C5. 재대국권 (⏳ 사용자 결정)
- 안: Act당 1회, 패배한 전투를 **같은 시드로 처음부터** 다시 둔다 (결정론 → 지난 판에서 배운 것을 쓸 수 있다). 승천 9 이상에서 제거.
- 근거: Gambonanza 되감기 3회, 모바일 45~60분 런이 실수 한 번으로 끝나는 부담. 반대 근거: 긴장 감소, 런 길이 증가.

### C6. 이자 (⏳ 사용자 결정, 시뮬 선행)
- 안: 전투 종료 시 보유 골드 50당 +5 (최대 +15). 저축 vs 대장간 투자 딜레마.
- 36층 경제(D-025 곡선)를 다시 맞춰야 하므로 시뮬로 먼저 확인한다.
