# 22장. 난이도 곡선 · 눈금 · 메타 속도 (D-542)

> 상태: **적용(2026-11-17)**. 사용자: 「게임이 너무 쉽다」 — 핵심 콘텐츠가 다 들어와 D-080의 수치 조정 보류를 풀었다.
> 근거: 출시 전 난이도 리뷰(두뇌 봇 왕관 1~4 × 150출하 · 도전 30출하)와 그 뒤 반복 측정 — `docs/reports/2026-11-17-difficulty-pass.md`.

## 1. 눈금 — 누구에게 맞추나

- **눈금 = 두뇌 봇(search)**. 두뇌 봇은 이번 턴 수 순서를 탐색하고 적 차례까지 굴려 보는 봇이다 — 화면이 예고 · 위험 칸 · 피해를 다 보여 주므로(UI 원칙 1) **꼼꼼한 사람의 대리**다.
- 옛 눈금(D-316 · D-382 · D-501 · D-518: 보통 봇 35~40%)은 버렸다. 보통 봇에 맞추면 예고를 다 읽는 사람에게 게임이 풀린다(두뇌 봇 98%).
- 사람은 봇이 쓰지 않는 보험(되감기 · 마지막 한 수 · 보이지 않는 손)만큼 표보다 5~10%p 쉽다고 본다. 사람 기록(텔레메트리)으로 눈금을 다시 맞춘다.

## 2. 목표 표

왕관 n = 승급 n−1(0~3) · 도전 n = 승급 n+3(4~13).

| 봇 \ 출하 | 첫째 | 둘째 | 셋째 | 넷째 | 도전 1 | 도전 5 | 도전 10 |
| :-- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| 두뇌 (search) | **70~80** (여벌 심장 있는 첫 출하 기준) | 55~65 | 45~55 | **35~45** | 30~40 | 20~30 | **10~20** |
| 보통 (greedy) | 12~22 | 5~12 | 2~8 | 0~5 | ~0 | 0 | 0 |
| 단순 (naive) | ≤ 5 | 0 | | | | | |
| 무뇌 (random) | 0 · 90% 넘게 1막에서 끝 | 0 | | | | | |

- 계단: 한 단계 −5~12%p, −15%p를 넘으면 절벽. **도전 1은 넷째 왕관보다 어렵다.**
- 위험(두뇌): 킹이 HP 50% 아래로 내려간 대국 15~25% · 출하의 85% 이상이 한 번은 겪는다.
- 반장별 승(두뇌): 85~95%.
- 출하 길이: 사람 55~70분(옛 약 85분).
- 첫째 왕관은 **첫 출하**로 잰다(처음 풀 · 여벌 심장 1 · 1막 반장 안전망 = `simulateRun`의 first, climb `--pools starter`). 다시 하는 첫째 왕관(여벌 없음 · 열린 풀)은 둘째 왕관보다 조금 쉽다.
- 표본: 왕관 1~4는 150출하(±5%p), 도전은 60출하(±12%p). 도구는 `/balance-check`(`npm run climb`)와 리뷰 계측판(보고서 재현 절).

## 3. 레버 — 무엇이 난이도를 정하나

단독 레버는 천장(대국 승 99.5%)에 막혀 안 보인다. 대국 패배율을 0.5% → 1.5~2%로 올리는 **동시 압력**으로 묶어 넣었다.

| 축 | 레버 (값은 보고서 · DECISIONS) | 하는 일 |
|---|---|---|
| 보험 | 여벌 심장은 첫째 왕관의 **첫 출하만**(`startRevive`)이고, 깨면 그 대국을 다시 두되 **상처 · 쓰러짐은 그대로**(`spareSquad` — 킹만 HP 50%로) · 되감기 시작 1 · 반장 되감기 0 · 상자 되감기 15% · 마지막 한 수 · 보이지 않는 손 · 사선 보상 축소 | 「지면 되감는다」 → 「드물게 되감는다」. 왕관 계단의 첫 단을 만든다 |

## 4. 첫 한 시간

- 첫 출하(처음 하는 출하 하나)만 안전망: 여벌 심장 톱니 1(상처는 남는다) · 1막 반장에 한 번 지면 HP −35%(`FTUE.firstBossHp`).
- 그 뒤 출하는 1막부터 위험하다: 1막 반장 승 90% 안팎 · 1막 반장에서 킹이 절반 아래로 내려가는 대국 20% 안팎(두뇌 봇).

## 5. 메타 속도 — 해금 계단

- 예전: 넷째 왕관을 깨면 92개가 한꺼번에 열려 약 6시간에 메타가 닫혔다.
- 이제(`src/data/unlocks.ts`):
  - 본편 풀(2차 부품을 뺀 64개)은 왕관마다 나눠 연다 — `CROWN_TIER` [16, 32, 48, 64]. k번째 왕관을 깨면 앞 `CROWN_TIER[k−1]`개가 보장되고, 출하마다 열리는 2~6개(`unlockCount`)는 다음 왕관의 몫까지만.
  - 이형 기물 · 시작 세트는 그대로 왕관마다(D-481 · D-485).
  - 도전 단계마다 부품 둘(`CHALLENGE_GRANTS` — 2차 부품 20개). 깬 단계 이하의 몫을 모두 준다(건너뛴 옛 기록도).
- 저장: 기록 판 1 → 2 이관 걸음(D-529 사슬)이 이미 깬 왕관 · 도전의 몫을 채운다. 가진 해금은 하나도 빼지 않는다.
