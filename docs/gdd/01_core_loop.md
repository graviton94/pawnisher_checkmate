# 1장. 코어 루프 & 턴 규칙

> 상태: ✅ 확정
> 출처: ideation 01 §1·§2.1·§3, DECISIONS D-002·D-003

## 1.1 게임 정의

체스 행마를 기반으로 한 **1:1 교대 턴제 퍼즐 택틱스**.
매 턴 행동력(AP) 안에서 여러 기물의 이동을 순서대로 예약해 제출하면,
**모든 기물이 한꺼번에 이동한 뒤 예약 순서대로 순차 공격**한다.
상대는 플레이어와 **완전히 동일한 규칙**을 따르는 AI다.

이 전투를 로그라이크 등반 구조(8장) 위에서 반복하며, 덱(6장)과 시너지(7장)를 키워 간다.

## 1.2 절대 규칙 (Engine Invariants)

어떤 카드·패시브·크랙 효과도 아래 규칙을 깨지 않는다.
예외가 필요한 효과는 해당 장에 **예외임을 명시**하고, 어느 단계에서 처리되는지 정의한다.

1. **킹의 죽음 = 승패**
   상대 킹의 HP가 0이 되는 순간 즉시 승리, 내 킹의 HP가 0이 되는 순간 즉시 패배한다.
   남은 기물 수와 무관하다.
2. **단일 시퀀스**
   한 진영의 턴은 항상 `계획 → 제출 → 일괄 이동 → 순차 공격` 순서로만 진행된다.
   계획 단계에서 즉시 발동하는 공격은 없다.
3. **이동한 기물만 공격**
   이번 턴에 이동한 기물만 착지 후 공격한다. 제자리에 있던 기물은 공격하지 않는다.
   (위치 교환·변신 등 카드 효과로 "이동 판정"을 받는 경우는 7장에서 정의한다.)
4. **겹쳐 잡기 없음**
   기물은 항상 빈 칸에만 착지한다. 피해는 착지 후 공격으로만 준다.

## 1.3 라운드 구조

```
[1P 턴]  계획 → 제출 → 일괄 이동 → 순차 공격
[2P 턴]  계획 → 제출 → 일괄 이동 → 순차 공격
→ 반복 (한 쪽 킹 HP 0 시 즉시 종료)
```

- 플레이어는 UI로, AI는 탐색으로 **같은 형식의 계획(Plan)**을 만들어 제출한다.
- 규칙 엔진은 진영을 구분하지 않는다.

## 1.4 계획 단계 (Planning)

### 행동력 (AP)
- 턴 시작 시 기본 **5 AP**를 받는다.
- 기물마다 이동 AP 코스트가 다르다 (2장).
- 패시브·요충지 보상 등으로 늘어날 수 있다.

### 이동 예약
- 기물을 하나 선택해 목표 칸을 지정하면 예약 순번(#1, #2, #3…)이 붙는다.
- **기물 하나는 한 턴에 한 번만** 이동할 수 있다.
- 예약할 때마다 **가상 보드가 갱신**되고, 다음 예약은 갱신된 보드 기준으로만 선택할 수 있다.
  - 예: #1 폰이 비켜 준 칸은 #2 룩의 이동 경로로 쓸 수 있다.
  - 따라서 같은 칸 중복 예약 같은 충돌은 구조적으로 발생하지 않는다.
- 예약된 기물의 착지 후 공격 범위를 미리보기로 보여 준다.
  미리보기는 앞 순번의 이동이 반영된 가상 보드를 기준으로 한다.

### 액티브 카드 예약
- 액티브 카드도 이동과 함께 계획 단계에서 예약한다 (7장).

### 예약 취소
- **마지막 예약 되돌리기**: 가장 마지막 순번의 예약 하나를 취소하고 그 AP를 환불한다.
  뒤 순번이 없으므로 다른 예약에 영향을 주지 않는다.
- **전체 초기화**: 모든 예약을 취소하고 AP를 전액 환불한다.
- 중간 순번의 개별 취소는 두지 않는다. 뒤 순번이 앞 순번의 이동에 의존할 수 있어 판정이 복잡해지는 반면,
  한 턴의 예약 수가 많지 않아 다시 짜는 비용이 작기 때문이다.

### 패스와 남은 AP
- 아무 기물도 이동하지 않고 제출(패스)할 수 있다.
- 쓰지 않은 AP는 턴 종료 시 소멸한다 (다음 턴으로 이월하지 않음).

## 1.5 실행 단계 (Execution)

### Phase 1 — 일괄 이동
- 예약된 모든 기물이 목표 칸으로 **동시에** 이동한다.
- 이동 단계에서는 피해가 발생하지 않는다.

### Phase 2 — 순차 공격
- 이번 턴에 이동한 기물이 **예약 순번대로 하나씩** 착지 칸에서 공격한다.
- 공격으로 HP가 0이 된 기물은 **즉시 보드에서 제거**된다.
  그 결과 뒤 순번 공격의 사선이 새로 열릴 수 있다 (전열 철거 후 후열 관통).
- 공격 도중 어느 쪽 킹이든 HP가 0이 되면 남은 공격을 생략하고 즉시 전투를 끝낸다.
- 공격 범위·사선·피해 계산은 2장·3장에서 정의한다.

## 1.6 전술의 원리

- **공격**은 "어디에 착지하고, 어떤 순서로 칠 것인가"로 결정된다.
  - **길 터주기**: 앞을 막는 아군을 치우는 이동과 장거리 기물의 이동을 한 턴에 같이 낸다.
  - **순차 관통**: 앞 순번으로 적 전열을 파괴해 뒤 순번의 사선을 연다.
- **수비**는 상대 턴 사이에 끼어들 수 없으므로 **내 이동 시점의 배치로만** 결정된다.
  - 제자리에 있는 적은 공격하지 않는다.
    따라서 위협은 오직 "다음 상대 턴에 적이 어디에 착지할 수 있는가"이다.
  - 아군으로 사선 막기, 적의 착지 칸 점유, 위협 기물 선제 제거, 킹 배치가 수비 수단이다.

## 1.7 기타 확정 규칙

- **선공**: 플레이어가 항상 먼저 둔다. 적 선공은 보스·엘리트 전용 기믹으로만 사용한다.
- **턴 제한 없음**: 무승부 규칙을 두지 않는다. 교착은 요충지(5장)가 깨는 역할을 한다.
  실제 플레이에서 교착이 문제가 되면 재검토한다.
- **아군 오사격 없음**: 공격 범위 안의 아군은 피해를 받지 않는다. 아군은 사선만 막는다.
