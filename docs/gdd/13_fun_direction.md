# 13장. 재미 방향 — "로그라이크 덱빌딩 체스"가 되려면

> 상태: 💬 1차 결정 반영 (2026-10-30, D-082·D-083). 11장(심화 계획)의 M10~M13을 대체하지 않고 **우선순위와 빠진 축**을 다시 잡는다.
> 이름은 작업명이다. 화면 이름은 `docs/world.md` 이름 규칙을 따른다.

## 13.1 솔직한 진단 — 재미가 나는 곳과 비어 있는 곳

| 층위 | 지금 재미 | 비어 있는 것 |
| :--- | :--- | :--- |
| **한 턴** | 순차 공격 퍼즐(길 터주기·관통·돌파) + 결과를 누르기 전에 다 보여 줌 → **우리의 심장, 지킨다** | 넓은 판에서는 대부분이 "자리 잡기" 턴. 칠 거리가 없으면 퍼즐이 없다 |
| **한 판** | 붕괴·정체 압박·연쇄 보너스로 길이는 줄었다 | **판이 다 똑같다.** 정통 배치 대 정통 배치, 적은 스탯만 다른 체스 세트, 목표는 늘 킹 처치 |
| **한 런** | 인챈트 16종·★각성·대장간·카드 | **덱빌딩이 "숫자 키우기"다.** 기물 종류가 6개뿐이라 덱이 정통 16기로 수렴한다. 런마다 군대가 비슷하다 |
| **런 사이** | 시작 덱 해금 · 승천 | 지휘관·보스 예고 등은 기획만 있음 (11장) |

핵심 결론 두 줄:
1. **판 단위 다양성이 0에 가깝다** — 같은 문제를 크기만 바꿔 계속 푸는 느낌. 피로의 진짜 원인.
2. **"덱"이 고를 게 없다** — 체스 기물 6종 + 유형 단위 수치 성장으로는 "나만의 군대"가 안 나온다.

## 13.2 북극성

> **매 판이 다른 체스 문제, 매 런이 다른 군대, 매 턴 "이 순서면 다 쓸어버린다"는 한 수.**

| 기둥 | 한 줄 | 벤치마크 |
| :--- | :--- | :--- |
| ① 결정적 한 수 | 좋은 수에 이름과 보상이 붙는다 | Balatro 족보 이름 · Into the Breach "막아 냈다" |
| ② 다른 군대 | 기존 6종의 변이 진화로 짜는 나만의 덱 | 요정 체스·장기 포 행마 · StS 카드 강화 · 포켓몬 분기 진화 |
| ③ 다른 문제 | 판마다 목표·지형·적 성격이 다르다 | Into the Breach 보너스 목표 · 체스 묘수풀이 · StS 엘리트 |
| ④ 다른 손 | 턴마다 쓸 수 있는 명령이 달라진다 | Slay the Spire 손패 |

## 13.3 제안

### P1. 전술 키워드 + 판 보너스 의뢰 (기둥 ①③, 그림 거의 불필요)
- 11장 A1 전술 키워드(포크·관통·사선 개척·돌파·연쇄·체크)를 **먼저** 넣는다. 공격 순간 배너, 예약 옆 칩, 기록 줄에 이름.
- **판마다 보너스 의뢰 1개** (Into the Breach 보너스 목표): 시작할 때 레일에 한 줄. 예: "포크 2회" · "폰으로 킹 마무리" · "기물 잃지 않기" · "6턴 안에" · "요충지 2턴 점거". 달성하면 골드·리롤·인챈트 희귀 확률.
  - 킹 처치 = 승리는 그대로(절대 규칙). 의뢰는 **어떻게 이기느냐**에 다른 질문을 던진다 → 판마다 다른 문제.
  - 11장 C4 전투 평가(무손실·속전·철벽)를 의뢰 풀 안으로 흡수 (사용자 결정 D-083).
- 비용: 엔진 이벤트 기록 + UI 배너/칩. 중간.

### P2. 변이 진화 — 규격 외 기물을 기존 6종에서 (기둥 ②, 덱빌딩의 몸통) · 사용자 결정 D-083
- 사용자: 완전히 새로운 기물 대신, **기존 6종의 뮤턴트 진화형**을 두고 인챈트·강화·가챠로 설득력을 준다 → 세계관 유지, 너무 낯선 규격 외가 생기지 않는다.
- 세계관: 공장의 "규격"에서 벗어난 **변이 부품** — 같은 나이트인데 다리가 길게 개조됐다, 같은 비숍인데 포신을 달았다.
- 형식: 기본 기물 + **행마 하나를 비튼 형태**. 변이체는 여전히 그 유형이다 (덱 한도·가치·대장간 강화를 그대로 받는다, 6장 원칙 유지).

| 기본 | 변이 A | 변이 B | 출처 (검증된 행마) |
| :-: | :--- | :--- | :--- |
| 폰 | **사선 보병**: 대각으로 전진, 정면 1칸을 친다 — 막힌 전열 사이로 빠져나감 | **방패병**: 대각 1칸 어느 방향이든 이동, 받는 피해 감소, 공격 약함 | 베롤리나 폰 · 페르츠 |
| 나이트 | **낙타 기병**: (3,1) 도약 — 멀리 기습 | **질주 기병**: 나이트 도약을 같은 방향으로 이어 감 (막히면 멈춤) | 낙타 · 나이트라이더 |
| 비숍 | **포격 비숍**: 대각 사선에서 기물 하나(받침)를 **넘어야** 친다, 대신 강함 | **수도사**: 비숍 + 직선 1칸 이동 (칸 색 고정 해소) | 장기 포 · 요정 체스 |
| 룩 | **도약 룩**: 직선으로 기물 하나를 넘어 바로 뒤 칸에 착지 | **공성 망치**: 직선 돌진 끝에서 맞은 적을 1칸 밀어냄 | 메뚜기 · (우리 A04 증기 충격파) |
| 퀸 | **아마존**: 퀸 + 나이트 도약 (비싸다) | — | 아마존 |
| 킹 | 없음 (주인공) | | |

- **얻는 길 3가지** (사용자 제안: 인챈트·강화·가챠):
  1. **대장간 분기**: 유형 강화 +3에 도달하면 그 유형 전체를 변이 A/B 중 하나로 바꿀지 고른다 (안 바꿔도 됨). StS 카드 강화·포켓몬 레벨 진화처럼 **확정 경로**.
  2. **인챈트 ★각성**: 그 유형 인챈트 3장째가 변이를 해금하는 것도 있다 (E07 학살자의 대관식이 이미 "승급" 형태).
  3. **가챠 (랜덤 기물 보상·크랙 제단)**: 드물게 **변이체 한 기**가 나온다 (그 기물 하나만). 운으로 만나는 "대박 기물".
- 적 군단도 같은 변이를 쓴다 (D-002 공정성) → 적 원형 군단(P4)의 재료.
- 그림: 기존 기물 그림 + **조합 표식**(혹·포신·방패 같은 작은 부품을 코드로 얹음, `docs/art-assets.md` §1 조합 우선). 마음에 안 들면 사용자가 변이체 그림을 따로 준다.
- 비용: 엔진 행마를 데이터(도약·미끄럼·넘기·받침)로 일반화 + AI 가치 + 대장간 분기 UI. 중간~큼.

### P3. 영입 (기둥 ②, 쇼기의 "잡은 말 쓰기"를 런 단위로)
- 엘리트·보스 전 보상에 **"처치한 적 기물 하나 데려오기"** 칸 (적의 변이체를 데려오면 그 변이체 한 기). 판 안에서 내려놓는 쇼기식 드롭은 하지 않는다(11장 기각 유지).
- 변이체를 얻는 넷째 길. 상점 진열보다 "저 기물 갖고 싶다 → 그 엘리트를 고른다"는 맵 판단이 생긴다.
- 비용: 보상 화면 한 칸. 작음 (P2가 있어야 의미).

### P4. 적 성격 (기둥 ③)
- 11장 A4 엘리트 접사 6종 + A5 반장 전장 규칙을 P1 다음으로 당긴다.
- 일반 군단도 **원형(아키타입) 3~4종**으로: "폰 물량 행렬" · "기병 기습대" · "포병 진지(포 + 받침)" · "방벽 대열(페르츠·룩)". 군단 이름이 판 시작에 뜬다 → 판마다 다른 문제.
- 비용: 군단 생성 데이터 + AI 가중치. 중간.

### P5. 묘수풀이 노드 (기둥 ③)
- 맵에 가끔 **고정 배치 짧은 판**: "3수 안에 킹을 잡아라". 우리 엔진은 결정론 + 완전 미리보기라 체스 문제와 궁합이 가장 좋다.
- 실패해도 런은 안 끝난다(보상만 없음). 숨 돌리는 노드 + 전술 학습.
- 비용: 고정 배치 데이터 + 목표 판정. 작음~중간. 문제 제작은 시뮬로 검증.

### P6. 명령 손패 (기둥 ④) · 사용자 결정: 나중에 이것만 집중 개발
- 지금 액티브 카드(슬롯 4, 쿨타임) → **명령 덱**: 매 턴 3장을 뽑아 그중 쓴다 (StS). 덱에 넣고 빼는 것이 진짜 "덱빌딩"이 된다.
- 기물은 여전히 전원 출전(드로우 없음) — 손패는 "이번 턴 무엇을 더 할 수 있나"만 바꾼다.
- 위험: AI도 손패를 써야 함, 판 길이·복잡도 증가, 정보량(D-081) 증가. **앞 단계가 끝난 뒤 별도 개발 주기로 이것만 집중한다** (사용자 결정).

### P7. 기물에 정 붙이기 (보류 재검토)
- 지금은 유형 단위 성장. 개별 기물 각인(11장 장기 과제)을 "**부품 1칸**"으로 작게 열 수 있다 — 특정 기물 하나에 부품을 끼움 (Monster Train 강화석).
- P2 이후에 판단. 지금은 기물 수가 많아 개별 관리가 피곤할 수 있다.
