## 용어

| 용어 | 뜻 |
| :--- | :--- |
| **턴** | 한 진영의 `계획 → 제출 → 일괄 이동 → 순차 공격` 한 번 |
| **라운드** | 전투 한 판 (적 군단 하나를 상대로 한 전투 전체) |
| **층** | 등반 맵의 한 칸. 전투 층과 비전투 층(상점·대장간·이벤트 등)이 있다 |
| **런** | 1층에서 시작해 패배하거나 최종 층을 클리어할 때까지의 한 번의 등반 |
