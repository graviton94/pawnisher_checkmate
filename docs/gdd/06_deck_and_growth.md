# 6장. 덱 & 기물 성장

> 상태: 💬 검토 중
> 출처: ideation 02 §1.1·§2.2·§5, ideation 01 §2.2, DECISIONS D-005·D-010

## 6.1 덱의 정의

- **덱** = 플레이어가 이번 런에서 보유한 기물 목록. 전투에는 덱의 모든 기물이 출전한다.
- 기물은 **개체 단위**로 관리한다. 같은 나이트라도 개체마다 강화 단계·변이가 다를 수 있다.
- **킹은 항상 정확히 1기**이며, 덱에서 제거하거나 교체할 수 없다.
- **덱 최대 매수: 16기** (킹 포함, 정통 체스 기물 수). 🔧
- 전투 중 파괴된 기물은 전투 종료 시 **완전 부활 + HP 전량 회복**한다 (기물 손실 스트레스 없음).

## 6.2 런 시작 덱

- 온보딩 트레이닝(D-010)과 별개로, 실제 등반은 **킹 포함 3~4기**의 소수 덱으로 시작한다.
- 매 런 구성이 조금씩 달라진다.
  - 시작 덱은 스코어 가중치(5장 §5.4) 합이 일정 범위 안에 드는 조합에서 무작위로 생성한다.
    (예: `킹 + 폰 3`, `킹 + 폰 2 + 나이트`, `킹 + 폰 2 + 비숍`, `킹 + 폰 + 나이트`)
  - 룩·퀸은 시작 덱에 나오지 않는다.

## 6.3 배치 (정통 체스 배치 규칙)

전투 시작 시 덱의 기물을 자기 진영 끝 두 줄(후열 + 전열)에 자동 배치한다.

- **후열 기본 순서** (보드 폭별, 왼쪽부터):

| 폭 | 후열 슬롯 |
| :-: | :--- |
| 6 | `R N Q K B R` 🔧 |
| 8 | `R N B Q K B N R` (정통 체스) |
| 10 | `R N ★ B Q K B ★ N R` — `★`는 추가 기물 슬롯 |

- **전열**: 폰을 배치한다. 킹 앞 열부터 중앙에서 바깥쪽으로 채운다.
- 덱에 해당 기물이 없는 슬롯은 비워 둔다.
- **슬롯을 초과한 기물**(예: 나이트 3기): 같은 줄의 빈 슬롯 중 원래 슬롯에 가장 가까운 칸 → 없으면 전열 빈 칸 순으로 놓는다.
- 폭 10의 `★` 슬롯은 정통 체스 변형 *카파블랑카 체스*의 배치에서 따왔다.
  카파블랑카 체스는 10열 보드에 아치비숍·챈슬러를 두는 변형으로, 크랙 합체 기물(6.6)이 자연스럽게 들어갈 자리다.

## 6.4 기물 획득

- 주 획득 경로는 **상점 구매**(골드)다. 상점 품목·가격은 8장(등반 구조)에서 정한다.
- 덱이 16기로 가득 차면 새 기물을 들이기 위해 기존 기물 1기를 내보내야 한다 (킹 제외).

## 6.5 대장간 (확정 스탯 강화)

- 기물 개체 하나의 HP·ATK·DEF를 **확정적으로** 올린다. 운이 나쁜 런에서도 성장을 보장하는 저점 장치다.
- 1강당 상승치 (초기값):

| 기물 | HP | ATK | DEF |
| :--- | :-: | :-: | :-: |
| 폰 | +8 | +3 | +1 |
| 나이트 | +12 | +5 | +1 |
| 비숍 | +10 | +6 | +1 |
| 룩 | +20 | +7 | +2 |
| 퀸 | +18 | +9 | +2 |
| 킹 | +25 | +4 | +2 |

- 강화 비용은 단계가 오를수록 증가한다. 비용 곡선은 8장의 골드 경제와 함께 정한다.

## 6.6 기물 변이 · 합체 (크랙)

정통 체스 룰을 비트는 성장. 정비소·크랙 제단 노드에서만 일어난다 (8장).

- **변이**: 기존 기물을 특수 기물이나 상위 기물로 영구 교체한다.
  - 예: 폰 → `자폭 태엽 폰`(파괴 시 주변 8칸 폭발), `방패병 폰`(기본 보호막), 나이트/비숍.
- **합체**: 두 기물을 제물로 바쳐 이형 기물 하나를 만든다.
  - `아치비숍` = 나이트 + 비숍: L자 도약과 대각선 이동·공격.
  - `챈슬러` = 나이트 + 룩: L자 도약과 직선 이동·공격.
- 특수 기물 목록과 효과는 콘텐츠 단계에서 확장한다.
