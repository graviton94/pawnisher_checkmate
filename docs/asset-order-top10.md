# 이미지 에셋 우선순위 — 상위 10장 발주서 (2026-11-03)

> 사용자: "지금 생성해야 하는 이미지 에셋 우선순위 어떻게 되냐? 상위 순위대로 10개 프롬프트 가져와."
> 기준: **자주 보이는 화면 × 지금 비어 있는 정도 × 레이아웃이 바뀌어도 살아남는지.** 대국 화면은 4안(아래 부채꼴 손패 + 판 옆 적 초상) · 판 사이는 「장소 화면」 틀을 전제로 했다 (`docs/reports/2026-11-03-screen-renewal-review.md`). 카드 디자인이 정해지면 바뀌는 것은 없다 — 카드 그림은 코드 · 도트로 만든다.
> 방법은 지금까지와 같다: **새 채팅 → 첨부 → 상자 하나를 통째로**, 채팅 한 번에 한 장. 받은 그림은 `python3 -I tools/scene-import.py`로 들인다.
> 첨부: ① 기물 도트 `build-res/pieces-small-source.png` ② 화풍 기준 V-07 `build-res/order/V-07-pact-source.png` ③ (반장만) `docs/asset-order/pieces/boss-plate.png` — 지금 게임 속 검은 킹.
