> **게임 세계관 · 이야기 정본 (D-412)**: 5차 편집본(main `861c4ca`)을 정본으로 확정했다(비평서 §22). 게임 문서 · 데이터의 이야기와 다르면 이 원고를 따른다.

## 원문과 집필 자료

- [원문 보존본](./종이왕관-원문.md): 첨부된 원고를 바이트 단위로 동일하게 보존했다. 원래 부록과 후기도 포함한다. 비평서의 행 번호는 이 파일 기준이다.
- [원문 부록 A · 세계](./archive/90-world.md)
- [원문 부록 B · 인물](./archive/91-characters.md)
- [원문 작가 후기](./archive/99-afterword.md)

`archive/`의 문서들은 개정 전 원문 자료이며 개정본의 설정 정본이나 독서 순서에 포함하지 않는다. 부록과 후기는 삭제하지 않고 본편에서 분리해 보존했다.

초기 체크아웃에 `docs/book/`이 없어 첨부 원고로 비평·개정을 진행했다. 이후 최신 `main`의 장별 원고가 첨부본과 공백을 제외하고 동일함을 확인하고, 기존 장별 파일에 개정 내용을 반영했다. 게임의 코드·세계관 기획 문서는 이 문학 개정에 맞춰 변경하지 않았다.
