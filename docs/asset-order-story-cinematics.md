# 전용 서사 일러스트 발주 — D-435

대상은 **배경 위에 전투 기물 아이콘을 겹친 출하·운송·배신 컷**이다. 현재 합성은 실행 가능한 임시 연출이며 최종 원화로 확정하지 않는다. 전투용 아이콘의 정면 시점·굵은 흰 테와 배경의 원근·광원이 달라 기물이 스티커처럼 보인다. 발 위치/간격만 맞추는 것으로 이 문제를 해결할 수 없다.

이번에는 아래 완성 컷3장부터 제작한다. 받은 아이템4종·빈 거푸집 S-02·부모/아이 S-01의 재제작 요청이 아니다. 부품 카드의 작은 규칙 아이콘까지 전면 재발주하는 범위도 아니다.

## 공통 연출 기준

- 화면에서 벌어지는 행동이 하나여야 한다. **문턱을 넘기 / 함께 이동하기 / 혼자 남기**를 물건의 거리·광원·화면 구도로 보여 준다.
- 배경·인물·접촉 그림자를 같은 그림 안에서 같은 원근과 광원으로 완성한다. 전투 도트·초상·아이콘을 확대해 위에 붙이지 않는다. 게임용 흰 외곽 테를 서사 그림에 복제하지 않는다.
- 캐릭터는 체스 기물이다. 사람의 얼굴·눈·입·팔·다리를 새로 붙이지 않는다. 감정은 왕관 기울기, 몸의 방향, 크기와 거리, 빛을 받는 면으로 전달한다.
- 종이왕 원형: 상아색 흰 폰의 둥근 머리·가는 목·아래로 넓어지는 몸·넓은 둥근 받침. 머리보다 큰 황갈색 마분지 왕관, 고르지 않은 뿔 넷, 약간 기운 모양과 작은 청록 사각 장식. 종이 접힘과 무광 재질을 살린다. **금속 왕관을 쓴 정품 킹으로 바꾸지 않는다.** 보드 정본은 `public/pieces/l-K0.png`, 구조는 `tools/pixel/paperking.py`다. 아래 프롬프트는 첨부 없이도 자체로 완결된다.
- 실제 동료는0~9명이며 종류·생존이 달라진다. 이3장은 주인공과 상황을 그린다. 동료 전원을 고정해서 그리거나 죽은 기물·그림자·반사를 암시하지 않는다. 동료가 있는 분기의 이름·대사는 게임이 현재 분대로 채운다. 화면 밖 동료의 존재는 대사로 이어진다.
- 완성 PNG에 배우를 이미 그리므로 반입 후 `showActors`는 사용하지 않는다. 현재 S-03/S-04는 새 그림 수령 전까지 임시로 유지하고, 원본은 보관한다.
- 한 장을320×180 도트로 완성한다. 1920×1080은 최근접×6 미리보기다. 더 큰 이미지에서 작은 격자를 꾸미거나 사진을 모자이크한 결과는 납품하지 않는다.
- 핵심 피사체는 화면 중앙75% 안에 둔다. 하단 약24%는 대사 판이 올라와도 핵심이 가려지지 않는 낮은 대비 영역으로 둔다. 이야기 정보는 이미지 안에 글자로 넣지 않는다.
