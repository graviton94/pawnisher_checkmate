# 조사 발주서 — 로그라이크 덱빌딩 게임의 중독성과 카타르시스는 어디에서 오는가

> 발주: 2026-11-01 · 수행: 제미나이 서칭 프로젝트 · 관련 결정: D-144

## 목적
체스 행마 기반 로그라이크 덱빌딩 게임 「Pawnisher : Checkmate」의 빌드 설계 근거를 만든다. 이 장르가 사람을 "한 판 더" 붙잡는 구조(중독성)와 "터지는 순간"(카타르시스)을 만드는 장치를, 게임별 사례와 수치 근거로 정리해 달라.

## 대상 게임 (필수 8종 + 선택)
- 필수: Slay the Spire, Balatro, Monster Train, Inscryption, Into the Breach, Vampire Survivors, Luck be a Landlord, Dicey Dungeons
- 선택: Backpack Hero, Peglin, Wildfrost, Cobalt Core, Shotgun King, Pawnbarian, Hades(덱빌딩은 아니지만 빌드 카타르시스 비교용)

## 조사 항목
1. **빌드가 "부서지는" 순간 (카타르시스의 핵심)**
   - 게임마다 대표적인 "깨진 빌드"·무한 콤보 사례 3개씩 — 무엇과 무엇이 결합해 폭발하는가.
   - 덧셈 → 곱셈 → 지수 성장이 어떤 구조로 설계되는가 (예: Balatro 칩 × 배수, 조커 순서).
   - 개발자가 일부러 "부서지게" 둔 것과 막은 것의 경계 — 공식 인터뷰·GDC 발표·패치 노트 근거.
2. **아키타입(빌드 축) 설계**
   - 게임마다 빌드 축이 몇 개이고, 어떻게 구분되는가 (예: StS 아이언클래드 = 힘·소멸·방어).
   - 축이 첫 1~2번의 선택에서 어떻게 "열리고", 중반에 어떻게 "확정되는가".
   - 하나의 카드가 여러 축에 걸치게 하는 방법 (교차 시너지).
3. **유물·조커형 "규칙을 깨는" 아이템**
   - 규칙 자체를 바꾸는 아이템의 유형 분류 (비용 무시, 횟수 증가, 조건 반전, 자원 변환 등)와 대표 예시.
   - 등장 빈도, 희귀도, 대가(양날) 설계.
4. **중독성의 고리 (한 판 더)**
   - 한 판 안: 보상 주기(몇 분마다 선택이 오는가), 위험과 보상의 선택, 근소한 패배("거의 이겼다")의 설계.
   - 판 바깥: 해금, 수집(도감), 승천 단계, 일일 도전, 시드 공유가 재플레이율에 준 영향.
   - 무작위성 관리: 운이 나빠도 "내 탓"으로 느끼게 하는 장치 (재굴림, 미리 보기, 선택지 수).
5. **피드백·연출 (카타르시스를 "느끼게" 하는 것)**
   - 숫자 연출(커지는 숫자, 정산 순서, 소리 음높이), 화면 흔들림, 정지 프레임.
   - Balatro의 정산 연출을 프레임·초 단위로 분해.
6. **보상 선택 화면의 설계**
   - 선택지 수(3장 등), 건너뛰기, 희귀도 색, 다시 뽑기의 효과.
   - 덱 압축(카드 제거)의 역할과 비용.
7. **상업 데이터**
   - 판매량·동시 접속·리뷰 수·평점 추이 (SteamDB, Steam 리뷰 등 공개 자료), 출시 시점, 가격.
   - 스트리머·영상에서 많이 공유된 장면 유형 (무엇이 "클립"이 되는가).
   - 같은 장르 실패작 3종과 실패 원인 (리뷰 근거).

## 결과물 형식
1. 게임별 1쪽 요약표: 빌드 축 · 대표 폭발 콤보 · 규칙 깨는 아이템 예 · 보상 주기 · 상업 지표.
2. 공통 원리 10개 이하: 원리 한 줄 + 근거 게임 2개 이상 + 출처.
3. "체스 기반 순차 공격 게임에 옮긴다면?" 제안 5개 (선택 사항 — 근거와 분리해 표시).
4. 모든 주장에 출처 링크 (공식 인터뷰, GDC, 개발자 블로그, 패치 노트, SteamDB). 추측은 추측이라고 표시.
