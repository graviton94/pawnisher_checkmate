# 레퍼런스 스터디 — Gambonanza · Slay the Spire

> 원본: 사용자 제공 해체분석 레포트 2종 (Gambonanza Vol.1 20쪽, Slay the Spire Vol.2 16쪽, 2026).
> 이 문서는 **우리 게임에 쓸 만한 사실만** 추린 요약이다. 반영 계획은 GDD 11장, 결정은 DECISIONS D-028.
> 레포트 7장(두 레포트 모두)의 "융합 설계안(Project: Grand Gambit)"은 **다른 게임의 제안**이다. 우리 근간 규칙과 충돌하는 부분이 많아 그대로 가져오지 않는다 (GDD 11장 §11.3).

## 1. Gambonanza (체스 덱빌딩 로그라이크, 2026)

### 구조
- 4×4~4×6 소형 보드, **적 기물 전멸 = 승리**, 잡힌 아군 기물은 **런에서 영구 소멸**.
- 턴당 1행동: 이동·포획 / 대기(판당 3회) / 리저브에서 착지(Landing).
- **크럼블 모드**: 3턴 연속 포획이 없으면 외곽 타일이 무너진다. 포획하면 카운터 초기화 → 소극적 수비 처벌.
- **스테일메이트 = 3회 되감기**: 수가 없으면 목숨 1개를 쓰고 그 판 처음으로. 보스 처치 시 3개로 충전.
- 5 스테이지 × 5판, 각 스테이지 5번째 판이 보스. **다음 보스를 상점 화면에서 미리 공개**.

### 시너지 3층
- **보드 타일 6종** (황금·망령·보호·축복·함정·저주): 아군이 **이동해서 밟을 때만** 발동, 좌표에 런 내내 남는다.
  황금+망령 타일로 퀸을 무한 복제하는 "퀸 복제"가 최상위 메타 — 시스템 간 교차 해킹이 덱빌딩의 쾌감.
- **갬빗 203종** (최대 5슬롯): 수치 +10%가 아니라 **체스 인과율을 비트는 이산적 규칙 변경**. 4등급, 판매 시 50% 환급.
- **10대 키워드를 색으로 구분** (보호=파랑, 축복=보라, 함정=초록 …) — 툴팁을 빠르게 읽게 한다.

### 경제·보스
- 처치 $1, 황금 생존 +$2, **보유 $10당 이자 $1** → 저축 vs 투자 딜레마. 리롤 $2, 보드 최대 기물 수 업그레이드.
- 아케이드 미니게임(기물 휠·가챠·파친코)로 보상 지급 — 초기엔 7~15초 강제 연출이 반복 피로 → 스킵 옵션 추가.
- 보스 8인: 각자 **규칙 비틀기 하나** (정지, 리저브 봉인, 기물 셔플로 정체 숨김, 안개, 저주 타일 생성, 턴 스킵).
- 적 변조자 5종: **엘리트(반드시 마지막에만 잡힘)**, 크럼블러, 스테이시스, 폴리모프, 인보커.

### 실패 요인 (레포트 6.2 — 우리가 피할 것)
1. **고난도 시련이 빌드를 파괴**한다 (갬빗 강제 만료, 기물 무작위 변이, 슬롯 잠금) → "전략적 도전"이 아니라 "불쾌한 압수".
2. **풀 희석**: 203종인데 슬롯 5개, 내 기물과 안 맞는 갬빗만 계속 뜸. 태그 필터·수직 변조 수단 없음.
3. **적 AI의 무작위 블런더**와 **의도 예고 부재** → 수읽기가 무의미하거나 억울한 손실.
4. **수작업 고정 포메이션** → 10시간 넘으면 첫 수를 외우는 암기 게임.

### 성공 요인
- "체스판에서 슬롯머신 돌리고 퀸 복제해 보스 때려잡기" — **1초 훅**이 명확.
- 4초 가독성 원칙 (작은 보드, 색 코드 키워드, 레트로 카지노 미학).
- PC·모바일 동시 출시, 모바일 판매 35~37%, 플레이 스토어 4.8★ vs 스팀 74% — 모바일에서 특히 강했다.

## 2. Slay the Spire (로그라이크 덱빌더의 정본)

### 밸런스 공학
- 첫날부터 **텔레메트리 서버** — 90개 이상 그래프. 핵심 지표 3개:
  **제시 시 선택률**, **승리 덱 포함률**, **조우별 평균 체력 손실**.
- 사례: 이도류가 "아무 카드 복제"일 때 1턴 무한 루프 → 공격·파워만 복제로 축소.
  "**사기적 시너지는 권장하되 무한 루프는 극도로 희귀하게**."
- **클래스당 카드 풀 ~75장** (기본 3~4 · 일반 ~20 · 고급 ~35 · 희귀 ~16). 늘릴 아이디어는 새 클래스로 분리.

### 적 의도 예고
- 초기엔 의도 표시가 없었고, 테스터가 방어/공격 카드 선택 근거를 못 찾았다. 아이콘 → 무기 종류 → **정확한 피해 수치 공개**로 진화.
- 적 AI는 난수가 아니라 **상태 기계 + 연속 발동 제한** (예: 강공격 2턴 연속 금지) → 숙련자는 2~3턴 앞을 읽는다.

### 성장 경제
- **스킵과 제거가 가장 강한 성장**: 덱 15장 유지 시 핵심 카드 동시 드로우 7.6% → 42.9%.
- **보스 유물 = 대가성(Kiss-Curse)**: 에너지 +1 (3→4) 대신 규칙 제약 하나 (휴식 불가, 의도 안 보임, 턴당 6장 제한 …). "내 덱이 어떤 페널티를 감당할 수 있나"를 스스로 진단하게 한다.
- **확률 보정**: 희귀 카드 오프셋 −5%에서 시작, 일반이 뜰 때마다 +1%p, 희귀가 뜨면 리셋. 포션 드롭 40% ±10%.
  초반 1~2전에 희귀가 안 나오게 해서 "초반 덱이 희귀로 꼬이는" 것도 막는다.

### 등반 맵
- 7×15 분기 DAG. **고정 층 규칙**: 1층 약한 적 100% · 처음 3전은 쉬운 풀 · 엘리트·휴식은 6층부터 · 9층 보물 상자 · 15층(보스 직전) 휴식 · 엘리트/상점/휴식 2층 연속 금지.
- 막 시작 시 보스 아이콘 공개.
- **게이트키퍼**: 막마다 다른 질문 — 1막 "3~4턴 안에 초반 딜을 뽑나?", 2막 "다수 적의 폭딜을 막으며 광역을 주나?", 3막 "특정 극단 아키타입 저격".
- Act 4: 열쇠 3개 (휴식 포기 / 보물 포기 / 불타는 엘리트 격파)로만 진입하는 진 최종전.

### 어센션 1~20 (빌드 보존형)
- A1 엘리트 +60% (고수에겐 오히려 버프), A2~4 적 공격력, A5~9 회복·체력 압박, A10~16 시작 저주·포션 슬롯·보상·골드 축소, A17~19 적 패턴 고도화, A20 보스 2연전.
- **획득한 카드·유물을 강제로 빼앗거나 증발시키지 않는다** — Gambonanza 시련과의 결정적 차이.
