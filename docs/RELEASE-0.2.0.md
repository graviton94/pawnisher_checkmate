# Pawnisher : Checkmate 0.2.0 — 유저 테스트 판 (2026-10-31)

## 받는 곳
- 안드로이드: GitHub 릴리스 `apk-latest` (최신 테스트 APK)
- 웹: `npm run build` 결과 (요청 시 링크)

## 이번 판에 있는 것
- **출하 30층** — 공정 3개 × 10층, 반장 둘 + 공장장. 반장마다 약점(지도에서 반장 카드를 누르면 준비할 것).
- **시험대** — 처음 새 출하 때 세 판 연습 (메인 메뉴에서 다시). **규칙서** — 메인 메뉴, 16장.
- **등급** 커먼 · 레어 · 유니크 · 에픽, **에픽 부품 10** + 공명 5쌍, **계약 6**, **라인 3** (시작 세트마다).
- 공방 **덜어내기**(분해 · 재주조 · 파쇄), **보관 이자**, **오늘의 출하**, **음악**, 도감, 압력 0~13.

## 테스트하는 분께
1. 처음엔 시험대부터 (권하는 창에서 「시험대로」).
2. 끝나면 **설정 → 출하 기록 내보내기** 로 나온 파일을 보내 주세요 (안 되면 클립보드에 복사된다 — 메신저에 붙여 넣기).
3. 한 출하가 얼마나 걸렸는지, 어디서 막혔는지, 억울했던 판 — 한 줄씩.
