# Pawnisher : Checkmate 1.0.0 — 정식판 (2026-10-31)

## 받는 곳
- 안드로이드: GitHub 릴리스 `apk-latest`
- PC: 같은 빌드 작업의 윈도 · 맥 · 리눅스 묶음
- 웹: `npm run build` 결과 (요청 시 링크)

## 0.2.0 이후 달라진 것
- **이야기** (D-130 · D-131 · D-135): 첫 출하 전 프롤로그 7컷 — 킹 자리에 들어간 아홉째 폰. 공정마다 진입 컷, 반장마다 소개 · 해체 컷(신념과 건네는 말), 도금왕 최종장.
- **승급의 고리**: 도금왕을 넘으면 승급 화면. 압력 0~12에서는 「내려놓는다」가 떨리다 꺼진다. 압력 13에서만 내려놓을 수 있다 → 진 엔딩 「해방」.
- **대사**: 새 기물이 합류할 때 · 영입할 때 · 대국 시작 흑 세트의 비웃음 · 첫 체크의 독백. 패배하면 용광로 컷.
- **검수 기록지 12장**: 도감 맨 위. 프롤로그 다시 보기도 도감에서.
- **말하는 기물** (D-134): 눈 달린 기물 초상화 19종 (임시 그림 — 사용자 그림으로 바꿔 끼울 자리).
- 용어 정리 (D-133): 사람이 나오지 않는 공장 — 검수 저울 · 녹슨 룩 · 외눈 비숍 등.

## 알려진 것
- 컷 · 초상화 그림은 코드로 그린 임시본 (배경 그라데이션 + 기물 도트 + 눈). 그림이 오면 같은 자리에 끼운다.
- 밸런스는 자동 등반 기준 — 사람 데이터는 설정 → 출하 기록 내보내기.
