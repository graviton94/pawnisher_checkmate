## 화면 위에 무엇이 얹히나 (모든 배경 공통 — 중요)
휴대폰 가로 화면 915×412(약 2.2 : 1). 판 밖 화면에서는 **양옆 레일**(왼쪽 덱 · 분대, 오른쪽 나사 · 부품 칸)이 남고, **가운데에 창**(고물상 진열 · 보상 카드 · 결과 집계 · 지도 노드)이 뜬다.

```
┌──────────────────────────────────────────────┐  ← 위 10%: 잘릴 수 있다
│ 레일 │                                │ 레일 │
│ ~15% │      가운데 약 60% × 70%        │ ~15% │  ← 창이 덮는다: 고요하고 어둡게
│      │      (창 · 지도 노드 · 글)       │      │
│      │                                │      │
└──────────────────────────────────────────────┘  ← 아래 10%: 잘릴 수 있다
   보이는 곳 = 창 둘레의 띠 (위 · 아래 · 레일과 창 사이)
```

- **가운데는 비우고 어둡게**: 밝기 #0E0E12 ~ #1E1E26 근처, 무늬는 아주 낮은 대비의 디더링만. 그 위 글자(#F4F1EA)가 4.5 : 1 이상 읽혀야 한다.
- **디테일은 가장자리에**: 장소를 알리는 물건(선반 · 모루 · 파이프 · 컨베이어)은 화면 바깥쪽 20% 띠에.
- **전체를 어둡게**: 가장 밝은 빛은 작은 점 몇 개뿐. 배경이 창보다 눈을 끌면 실패다 — 정보 위계는 창 → 배경 (UI 원칙 7).
- 가로 2 : 세로 1, 2048×1024 정도. 위아래 10%는 잘릴 수 있다(넓은 화면에서는 좌우가 잘림).
- 받은 뒤 게임이 그 위에 어두운 막을 한 겹 더 깔 수 있다 — 그래도 **그림 자체가 이미 어둡게** 오는 것이 좋다.
