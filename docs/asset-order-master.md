## 5. 반입·검수 기준

개발 측이 원본 보관→실제 격자 확인→정수 픽셀화→알파/색 확인→게임 접속→네 대표 규격에서 확인한다. 원본 전체의 비율·색·장식을 보존한다. 상징·핀·모서리를 임의로 떼어 재조립하지 않는다. 기본 파일은 개별 완성 PNG이며 ZIP은 필수가 아니다.

수령한 원본은 `build-res/order/<발주번호>-source.png`, 현재 프레임은 `src/assets/ui/chrome/v2/`, 장면은 `public/scenes/`에 둔다. 기존 UI-31~33 재현은 `tools/pixel/ui_delivery_import.py`, 장면은 `tools/scene-import.py`와 `tools/pixel/scene_recipe.py`를 쓴다. 원본 도트가 명세와 다르면 자동으로 더 잘게 쪼개지 말고 실제 격자를 먼저 확인한다. CSS `pixelated`만으로 반입 완료라 하지 않는다.

UI/아이템은 알파0/255·정수배·테두리와 실루엣 보존, 장면은 비율·초점·대사 공간·실제 배우와의 겹침을 확인한다. 667×375 / 915×412 / 1024×768 / 1280×720 네 규격을 기준으로 한다. 후보 UI는 조건 로직과 함께 검수한다.

완료/폐기된 옛 발주는 [보관본](asset-order-history.md), 이번 필요성의 근거와 현재 사용처는 [감사 보고서](reports/2026-11-12-content-art-audit.md)를 따른다.
