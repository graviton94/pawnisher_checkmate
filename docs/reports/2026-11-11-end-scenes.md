# 출하 크레딧 · 승급 결정 · 사건 효과 검수 (D-424)

사용자 요청: 기록 사진의 아이콘 나열과 옛 종이왕 디자인 폐기, 승급 결정의 장면화, NPC 대사와 풀이 분리, 손실/획득 색과 수치 강조.

옛 `public/ui/hud/paper-crown.png`, 생성 코드와 합성 CSS를 제거했다. 컷신 대역의 왕관을 쓴 폰도 K0 정본을 사용한다. 폐기된 `fakeking.py apply`는 정본을 덮을 수 없다. 일반 폰과 이야기에서 왕관을 벗은 폰의 P0는 유지한다.

기존 픽셀화 배경·도금왕 그림·도트 버튼을 재사용했다. 새로운 원화는 필요하지 않았다. 배경은 `coverArt`로 비율을 유지하며 기기 픽셀 정수배로 배치한다. 현재 발주 UI-31~33은 그대로이며, 안내서에서 낡은 기록 사진 시안과 과거 미수령 발주 목록을 걷었다.

## 검증

- `npm run build`: 통과. TypeScript 및 Vite 빌드, 프리로드 609장(폐기한 왕관 1장 제외).
- `npm test`: **33개 파일 / 252개 테스트 통과**. 모든 사건 선택지의 득실 데이터, 비용 감소/증가, 교환, 안전한 숫자 강조 포함.
- `slice-observe end-scenes`: **915×412 DPR 2.625 · 667×375 DPR 2.625 · PC 1280×720 DPR 1 통과**. 실제 탭으로 정보 열기/넘기기/닫기, 선택 유지, 결과, 승급 0/3/6/12, 거절 반응, 승급 확정, 14명 크레딧 모든 쪽, 제작진, 출하 장부를 확인했다.
- 실제 엔딩 흐름 `endFlow(0)`에서 승급 확정 → 승급 컷 → 크레딧 → 장부를 확인하고, 출하 횟수가 정확히 한 번 증가하는지 검사했다. 거절 시도는 저장을 바꾸지 않는다.
- `slice-observe event-layout`: **35종 / 효과 설명 32쪽**, 모바일 두 해상도에서 통과. NPC 대사 유지, 선택지·수치·쪽지 글자 경계, 터치 영역, 이미지 비율·기기 픽셀 배수 검사. 앞 사건의 결과 상태가 다음 사건 서술을 숨기던 문제도 수정했다.
- `ui-audit`: DPR 1에서 승급, 출하 명단/제작진, 사건 정보의 서체·굵기·글자 경계 검사 통과.
- 브라우저 오류·경고 없음. Tab 초점은 전체 장면 안에 유지하며 배경 입력을 격리한다. 이동 줄이기 설정에서는 계단 등장·흔들림을 생략한다.
- 선택 판 실제 바탕 `#56545e`에 이득 `#b6edc0`는 **5.61:1**, 손실 `#ffc0c0`는 **4.80:1**. 종이 결과 쪽지는 각각 **6.39:1 / 6.52:1**. 부호와 효과 동사를 함께 표시한다.

재현:

```bash
CHROMIUM_PATH=/usr/bin/chromium node tools/slice-observe.cjs end-scenes
CHROMIUM_PATH=/usr/bin/chromium OBSERVE_WIDTH=667 OBSERVE_HEIGHT=375 node tools/slice-observe.cjs event-layout
```

대상 화면의 모바일/PC 브라우저 UX는 **APPROVED**. 실제 Android 기기·스크린리더 사용성은 **NOT ASSESSED**. APK 생성과 공개 웹 아티팩트 갱신은 이번 범위에 포함하지 않았다. 안내서 HTML은 로컬 생성으로 확인했다.
