# 제안서 P1 — Gambonanza · Slay the Spire 대비 우리가 부족한 것 (2026-10-31)

> 근거: `docs/reference/reference-study.md` (사용자 제공 해체분석 2종 요약) · 현재 코드 · 자동 등반 300판 (`docs/reports/B2-balance-pass.md`).
> 원칙: 우리 근간(킹의 죽음 = 승패 · 판 끝나면 부활 · 빌드를 빼앗지 않는 난이도 · 결정적 엔진)은 그대로 두고, 그 위에서 모자란 것만.
> 평가는 "있다/없다"가 아니라 **플레이어가 느끼는 차이** 기준. 좋은 점도 적는다 — 무엇을 지켜야 하는지 알아야 해서.

## 1. 지켜야 할 우리 강점 (레퍼런스보다 나은 것)

- **결과를 누르기 전에 보여 준다**: 이동 칸 · 과녁 · 처치 금색 · HP 예측 바 · 적 다음 수 감청. Gambonanza의 최대 비판(의도 예고 부재 · AI 블런더)을 처음부터 피했다.
- **빌드를 빼앗지 않는 난이도**: 압력 14단계는 StS 어센션처럼 빌드 보존형. Gambonanza 시련(갬빗 만료 · 슬롯 잠금)의 "불쾌한 압수"가 없다.
- **풀 희석 방지**: 주력 유형 가중 · 쌓인 개조 가중 · 에픽은 주력 유형 두 배. Gambonanza 203종 / 5슬롯 문제를 이미 막았다.
- **순차 예약 공격**이라는 체스 위의 고유 규칙 — 레퍼런스 둘 다 없는 우리만의 결정 공간.
- **반장 약점 · 지도 사전 공개**: StS 게이트키퍼 + Gambonanza 보스 사전 공개를 합친 형태, 이번에 준비 → 보상 고리가 생겼다.

## 2. 항목별 진단과 제안

### 2.1 한 출하가 길다 — 최우선
- 사실: 36층 · 대국 평균 11~18턴(자동 등반). 사람이 한 턴에 20~40초 쓰면 대국 하나 5~10분, 출하 하나 **3시간 이상**. StS 45~60분, Gambonanza 한 판 1~3분.
- 판 길이를 줄이는 장치(정체 압박 · 넓은 판 · 군단 상한 · 기준 턴 보너스)는 이미 있다. 남은 축은 **층 수**와 **판 수**.
- 제안 (택1 또는 조합):
  - A. **공정 3 × 8층** (반장 포함, 24층) — 일반 대국 층을 줄이고 돌발·고물상 비중 유지. 곡선은 층을 압축해 다시 맞춘다.
  - B. **일반 대국 일부를 "속전" 판으로**: 6×6 · 군단 4~5기 · 기준 6턴. 지금 1~3층 같은 판을 중반에도 섞는다.
  - C. 실측 먼저: 유저 테스트에서 대국당 실제 분을 잰다 (아래 2.5 텔레메트리와 함께).
- 추천: **C → A**. 실측 없이 층을 깎으면 곡선을 두 번 만진다.

### 2.2 첫 출하 안내 (튜토리얼)
- 사실: 게임 안 튜토리얼이 없다. 「움직인 기물만 공격」 · 태엽 · 예약/가동 · 체크메이트 안전 밸브가 모두 첫 판에 한꺼번에 온다.
- 제안: 첫 출하 1~3층을 **고정 시드 · 고정 군단**으로 두고, 판 위 강조 + 짧은 서술 한 줄씩 (말투 규칙 그대로).
  1층 = 이동해 치기, 2층 = 두 기 순서 예약(연쇄), 3층 = 체크 · 적 다음 수 감청. 끝나면 일반 출하로 이어진다. 건너뛰기 가능.

### 2.3 덜어내기 — 제거 · 변환
- 사실: 기물은 고물상에서 팔 수 있지만, 개조는 칸이 찰 때 버리기뿐이고 천공 카드는 지울 길이 없다. StS에서는 카드 제거가 가장 강한 성장 수단이다.
- 제안:
  - 공방에 **분해** (개조 1종 떼어내고 나사 일부 환급) · **재주조** (개조 1종을 같은 등급의 무작위로 바꾼다).
  - 돌발에 「녹 제거」 류 — 대가를 치르고 하나 지우기.
- 비용 작음: 데이터 + 공방 화면 버튼 둘.

### 2.4 대가 있는 큰 선택 (Kiss-Curse)
- 사실: 에픽 부품 10종은 모두 순수 이득이다. 이득이 크면 고민은 "어느 게 더 세나" 하나뿐.
- 제안: **반장 해체 상자에 「계약 부품」 1칸**을 더한다 — 강한 이득 + 규칙 제약 하나.
  예: 「과급기 — 턴당 태엽 +1 · 대신 공방에서 수리 불가」, 「검사 면제 도장 — 개조 칸 +1 · 대신 적 다음 수 감청 없음」, 「야간 근무 — 대국 나사 +40% · 대신 대국 시작 때 킹 HP −20%」.
  에픽(순수 이득)과 계약(이득 + 대가) 중 하나를 고르게 하면 "내 빌드가 무엇을 감당하나"가 생긴다.

### 2.5 사람 데이터 (텔레메트리)
- 사실: 모든 밸런스가 자동 등반(AI) 기준이다. AI는 반장 약점을 일부러 준비하지 않고, 묘수는 정답을 안다.
- 제안: 기기 안에 **출하 기록**을 남기고 설정에서 파일로 내보내기 (서버 없이). StS 핵심 3지표를 그대로:
  **제시 시 선택률 · 완주 빌드 포함률 · 대국별 잃은 HP**, 더해 **대국당 실제 시간**.
  유저 테스트 때 이 파일만 받으면 시뮬과 사람의 차이를 바로 본다.

### 2.6 저축 vs 투자 (이자)
- 사실: 36층 도착 나사가 목표(300)보다 많다 (B2 참고). 나사를 아껴 둘 이유도, 써야 할 압박도 약하다.
- 제안: **보관 이자** — 대국을 이길 때 들고 있는 나사 50당 +5 (최대 +25). Gambonanza식 딜레마를 만들고, 동시에 고물상 공정 배율을 다시 올려 "모아서 에픽 진열을 산다"는 선택을 만든다.

### 2.7 사기 콤보 순간
- 사실: 에픽으로 축은 생겼지만, 두 축이 **곱해져 터지는** 조합이 드물다 (예: 도미노 공장 + 양산 명령서는 강하지만 각자 따로 논다).
- 제안: 에픽 2칸끼리 **공명** — 특정 두 에픽을 함께 가지면 추가 효과 한 줄 (예: 무한 궤도 + 도미노 공장 = 나이트가 도미노로 쓰러뜨려도 다시 움직임). 10종이면 공명 5쌍 정도. "무한 루프는 극히 희귀하게" 원칙대로 턴당 상한을 둔다.

### 2.8 출하 정체성 (클래스)
- 사실: 시작 세트 9종은 다르지만 개조 · 카드 · 에픽 풀은 하나다. 3번째 출하부터 "비슷한 판"이 된다.
- 제안: 시작 세트를 3개 **라인**으로 묶고 라인마다 전용 개조 10 · 전용 카드 4 · 전용 에픽 2를 더한다 (공용 풀은 그대로). StS 클래스의 축소판. 비용 크다 — 명령 손패 집중 개발과 같은 시기에.

### 2.9 소리 · 음악
- 사실: 효과음은 합성음으로 있고 음악이 없다. 쾌감 연출(D-104 · D-109 · D-113)의 절반은 소리에서 온다.
- 제안: 공정 3곡 + 반장전 1곡 + 공장장 1곡, 반복에 강한 짧은 루프. 설정에 음악 · 효과음 따로. (외부 에셋 또는 절차적 칩튠 — 사용자 결정 필요)

### 2.10 매일 도전
- 사실: 서명된 시드가 이미 있다 (D-100). 같은 시드 = 같은 출하.
- 제안: 날짜로 시드를 만드는 **오늘의 출하** (하루 한 번, 압력 고정, 결과 코드 공유). 서버 없이도 "같은 날 같은 판"을 비교할 수 있다.

## 3. 추천 순서

1. **유저 테스트 전** (이번 주): 2.2 튜토리얼 · 2.5 출하 기록 내보내기 · 2.3 덜어내기.
2. **유저 테스트 1회차 뒤**: 2.1 출하 길이 (실측 기반) · 2.6 이자 · 2.4 계약 부품.
3. **콘텐츠 2차**: 2.7 에픽 공명 · 2.10 오늘의 출하 · 2.9 음악.
4. **명령 손패 집중 개발과 함께**: 2.8 라인(클래스).
