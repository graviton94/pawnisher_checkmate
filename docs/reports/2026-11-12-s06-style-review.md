## 이번 그림의 개선과 문제

| 관점 | 판단 |
|---|---|
| 인물 동일성 | 청록 원형 장식1개는 맞았다. 흰 기물과 황갈색 왕관도 구별된다. 왕관의 광택은 종이보다 두꺼운 장식관처럼 읽힐 여지가 있다. 눕힌 포즈는 정본 비례 확인을 어렵게 하므로 그림을 그대로 정본 자료로 승격하지 않는다 |
| 픽셀 밀도 | 이전의 매끈한 상자 그림보다 큰 색면과 계단 외곽이 보인다. 그러나 목재·바닥·철판 곳곳의 점무늬가 균일한 도트 문법을 대신하고 있다. 새 그림의 네이티브 격자는 파일 검사 전 미확인 |
| 팔레트·톤 | 차가운 청회색 공장과 따뜻한 목재·왕관의 대비는 기존 사건 분위기에 더 가깝다. 이것은 개선이다. 다만 전경 궤짝의 넓은 주황 면과 잔무늬가 강해 인물보다 소품이 먼저 읽히기 쉽다. 모든 자산을 이 갈색/청색 조합으로 칠할 필요는 없다 |
| 명도·시선 | 밝은 폰과 어두운 공장의 대비는 확보했다. 하지만 왼쪽 궤짝의 밝은 테와 왕관, 오른쪽 출입구의 밝은 면이 각각 시선을 가져간다. 상자 내부의 좁은 빛이라는 S-06의 중심이 사라졌다 |
| 재질 | 황동 테·리벳·녹은 공장스럽지만 궤짝이 매우 무겁고 화려하다. 의도한 가까운 판지 벽·보호용 천·작은 틈 대신 목재 보물상자처럼 읽힌다. 재질별 차이보다 모든 면의 얼룩이 반복된다 |
| 디더링 | 기존 사건·보스에도 패턴이 있으므로 금지할 이유는 없다. 이번에는 상자 모서리·바닥·배경에 넓게 퍼진 점/체크 무늬가 주연의 큰 형태와 경쟁한다. 규칙적 디더링인지 무작위 얼룩인지 원본 검증은 별도이며, 시각적으로는 적용 면적·대비를 줄여야 한다 |
| 공간·서사 | **가장 큰 오류.** 닫힌 운송 상자 안에서 천에 둘러싸인 장면이 아니라, 공장에 놓인 열린 궤짝에 폰이 비스듬히 걸쳐 누운 장면이다. 운송의 좁음과 바깥을 모르는 시간이 아니라 포장 전 전시/수납으로 읽힌다 |
| 소품·정보량 | 궤짝의 체스 그림, 경고 줄무늬, 금속 모서리, 배관, 갈고리, 증기, 출입구가 한 컷에 겹친다. 각각 가능한 소품이지만 조용한 운송 컷에 필요한 정보는 아니다. 임의 추가 장식을 게임 설정으로 채택하지 않는다 |

## 기존 그림도 자동으로 통일돼 있지는 않다

| 파일 | 실제 크기 | 보이는 정확한 RGB 색 수 | 상위32색의 픽셀 점유 |
|---|---|---|---|
| smith | 256×192 | 16,627 | 20.74% |
| gambler | 239×179 | 7,240 | 31.96% |
| boss-inspector | 219×215 | 12,003 | 20.45% |
| boss-assembly | 152×152 | 4,181 | 27.96% |
| boss-gilded | 256×245 | 11,572 | 46.58% |
| shipping-interior | 320×180 | 8,384 | 17.28% |

보이는 픽셀은 alpha≥128, RGB는 정확한 바이트 값이다. 수치는 실제 장면이 엄격한24/32색 파일이 아님을 보여 준다. 많은 RGB값에는 생성/격자 추출 때 남은 미세 변형이 포함될 수 있다. **색 수가 많다는 이유만으로 그림이 나쁘거나 디더링이 많다고 결론 내릴 수 없다.** 상위32색 점유율 역시 화풍 점수가 아니다.

`scene-import.py`는 `scene_recipe.options()`의 `colors=0`으로 색 수 축소를 끈다. `snap.py`는 칸 중앙의 우세한5비트 색 묶음에서 평균 RGB를 뽑는다. 따라서 격자 복원 뒤에도 미세 색 변형·질감·원본의 서로 다른 색 램프가 남는다. 수동 격자값도 최근 서사 컷 일부에만 기록돼 있고 다른 장면은 자동 검출을 쓴다. 기존 사건·보스와 최근 서사 컷이 같은 규격으로 보정됐다고 말할 수 없다.

## 공통 지침을 어떻게 바로잡는가

1. **프로젝트 지침 = 모든 게임 에셋에 공통인 제작 절차·도트/재질/색/질감 원칙.** 특정 주인공과 이번 장면 구도, 전 자산320×180 지정은 뺀다.
2. **프로젝트 소스 = 유형별 규격/화풍 기준 + 개별 인물·장면 설정.** 실제 사건2·보스2 PNG를 추가해 공통 화풍의 근거로 삼는다. 최근 상자·출하구 배경은 공간/소품 보조 참고로 낮추며, 기존 사건·보스 스타일을 덮어쓰지 않는다.
3. **채팅 = 이번 장면이나 수정 범위만.** 참고 파일을 매번 다시 첨부하지 않는다. S-06 수정은 ‘구도 유지’가 아니라 잘못된 열린 궤짝 구도부터 고치는 요청이다.
4. 팔레트는 재질별 명도·채도 관계와 강조색 역할을 공유한다. 모든 장면 동일한 색상표/실색 수를 강제하지 않는다. 디더링은 주변·그림자에 제한하고 인물 실루엣/작은 장식은 깨끗하게 둔다.
5. 실제 반입 뒤 같은 표시 크기에서 사건/보스와 비교한다. 기존94장을 한번에 색상 축소하거나 디더링을 지우지 않는다. 전역 팔레트 정리가 필요하면 원본/후보 비교를 거쳐 개별적으로 결정한다.
