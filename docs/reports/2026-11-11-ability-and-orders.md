# 능력 세 줄·발주서 정리·격자 확인 — D-422

## 표시 규칙

능력은 **[명칭] / 조건·행동 / : 상세 효과** 세 줄이다. 기물 검사표, 반장 규칙창, 맞물린 톱니·공성 걸쇠 상세에 같은 데이터와 표시기를 적용했다. 전투 수치·판정은 바꾸지 않았다.

```text
[검수]
2턴마다 최강 동료에 도장
: 해당 동료 공격 ×0.5
```

검수의 실제 대상은 전투 코드와 같이 킹을 뺀 동료다. 반장들의 보조 철갑도 빠뜨리지 않는다. 도금왕 네 능력과 자폭·송곳을 함께 가진 폰은 같은 세 줄 자리에서 `1/4 · 다음`을 눌러 넘긴다. 능력 영역 전체가 누름 영역이며, 넘기는 동작으로 검사표가 닫히지 않는다. 원래 정보는 생략하지 않고 페이지로 나눈다.

이름은 12px 갈무리11 강조, 행동은 15px 갈무리14, 상세 효과는 12px 갈무리11 굵게다. 각 줄은 한 줄로 설계하며, 말줄임·가리기·자동 글자 축소는 사용하지 않는다. 기물 검사표는 S 폭을 레일 옆 공간으로 제한하고, 내용은 기존 검사표 안의 약 59px 세 줄 영역을 쓴다. 본문·계기판 여백을 조정해 기존 364px 창 한도와 하단 단추 비가림을 유지한다. 부품 그림·카드의 분위기 문장은 이 능력 규칙 영역과 구분한다.

## 이미지 격자 확인

현재 저장소의 반입 도구와 게임용 파일을 대조했다. 그림 전부를 같은 크기의 격자로 밀어 넣지는 않는다.

| 종류 | 실제 처리 | 대조 결과 |
|---|---|---|
| 아이콘 | `tools/pixel/icon_sheet_import.py`: 칸 중앙 대표색→32×32→공용 팔레트·투명색·외곽선→16px 파생본 | `forkGear.png` 32×32·21색, `forkGear@16.png` 16×16·13색, `anvilPlate.png` 32×32·15색. 세 파일 알파는 0/255뿐이다 |
| UI | `tools/pixel/ui_kit_import.py`: `snap.py`로 숨은 격자 복원→UI 팔레트→부품 분리 | `panel-iron.png` 44×44·10색, `inset-well.png` 19×19·6색. 알파 0/255. 현재 프레임은 이 부품을 9-slice로 사용한다 |
| 기물 | `tools/pixel/maker.py`: 64×64 정본+위 8줄인 72×72 캔버스→최근접 정수배 출력 | `s-K0.png` 144×144·2배, `l-K0.png` 216×216·3배. 72격자로 내렸다 다시 최근접 확대해 원본과 완전히 일치함을 비교했다. `m-*`는 별도 25px 미니 파생본이다 |
| 장면 | `tools/scene-import.py`→`snap.py`: 숨은 격자 복원, 장면의 색은 유지 | `act-1.png` 273×141·4,223색. 장면은 아이콘의 15색 제한을 강제하는 종류가 아니다 |
| 표시 | `src/slice/pxsnap.ts`: DPR에 맞춰 장치 도트 크기를 기기 픽셀 정수로 정한다. CSS는 `image-rendering: pixelated` | 915×412, DPR 1과 2.625에서 프레임·글 경계를 확인한다 |

이 기록은 현재 파일과 반입 경로 확인이다. 이번 네 첨부 아이콘의 파일 원본은 실행 환경에 여전히 노출되지 않아 **그 네 장을 격자화해 반입했다고 보고하지 않는다**. A/B는 기존 대체 아이콘이며, 원본 파일이 전달되면 논리 격자·알파·외곽선을 확인한 뒤 반입한다. 새 UI-31~33도 수령 후 각 원본 규격에 맞춰 가져온다.
