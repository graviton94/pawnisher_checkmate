# 전투 화면 배치 제안서 (2026-11-03, 승인 대기)

아티팩트: https://claude.ai/artifact/KZVzzQ6CQnreXX8T4hzcZw

## 사례에서 가져온 원칙
1. 손패는 누르지 않아도 이름·비용이 읽힌다 (Slay the Spire 모바일 "개미 UI", Monster Train "하나씩 눌러 봐야 안다").
2. 턴 끝은 오른쪽 아래 끝 고정, 되돌릴 수 없는 버튼은 자주 누르는 버튼과 떨어뜨린다 (Balatro 실수 판매 불만).
3. 적의 다음 행동은 그 적 몸 위에 (Wildfrost 카운터, Into the Breach 판 위 예고).
4. 긴 설명은 길게 누르기 (Hearthstone).
5. 끌기보다 탭 (Shotgun King·Pawnbarian 끌기 불만, ITB 탭 정확도 호평).
6. 가로 두 손 쥐기에서 편한 곳은 양쪽 아래 모서리, 가운데 위가 가장 멀다 (Hoober 1,333명 관찰).

## 지금(E안) 문제
- 손패가 왼쪽 위부터 쌓여 편한 왼쪽 아래가 빔
- 「적의 수」 목록이 판 위 예고와 중복
- 「1턴」 상자가 버튼(놋쇠색)처럼 보임
- 「증기」 뜻(빨리 이기면 나사 보너스, 턴마다 감소)이 화면에 없음
- 되감기 바로 아래 턴 끝 (간격 8px)
- 피해 숫자가 기물 그림·불꽃 예고를 덮음

## 시안
- **1안 (권장) 양손 분담**: 왼쪽 손패를 아래에서 위로, 오른쪽 아래에 되감기·턴 끝 가로 배치(턴 끝이 모서리), 위쪽은 읽기 전용(태엽·턴·속전 보상·반장 규칙 한 줄·적 턴 예상 합계). 칸 61→63px. 편한 곳 안의 탭 2/4 (지금 1/4).
- 2안 아래 손패: 칸 52px로 줄고 손패가 내 기물 줄을 덮음 → 비권장.
- 3안 판 왼쪽·레일 하나: 카드는 가장 잘 읽히나 손 경로 가장 김, 왼손잡이 반전 필수.

## 1안 세부
- 카드 112×72 (비용 20px·이름 16px·기물 28px), 맞는 기물 하나면 자동 선택, 기물 먼저 선택도 허용
- 피해 숫자는 맞을 칸 오른쪽 위 모서리 18px
- 「증기」 → 「속전 보상 나사 +50 (턴마다 −5)」
- 턴 끝 135×70, 되감기 96×70, 16px 간격, 태엽 남으면 한 번 더 눌러 확정
