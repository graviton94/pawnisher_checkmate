# 테스터 대기 중 콘텐츠·아트 감사 — D-432

테스트 기준은 main@2d020418로 고정했다. 후속 작업은 `content-art-audit-20261112` 브랜치에 준비하며 APK·공개 웹 아티팩트는 갱신하지 않았다. 전투 효과와 적 수치를 변경하지 않았다. 후속 슬롯/부품 문법 변경은 D-433을 따른다.

## 콘텐츠·설명

기본 명령92·보상 명령86·부품84의 해금/공급 참조와 실제 실행 모듈을 대조했다. 현재 검사에서 잘못된 해금 ID, 공급 경로가 없는 보상·부품은 없었다. 아이템 아이콘·공용 카드 그림·기물 초상·핵심 컷신의125개 참조에서 누락0을 확인했다. 파일 존재와 정적 참조는 기능 정확성의 증명이 아니다. [기계 판독 결과](2026-11-12-content-asset-audit.json), 재현: `node tools/content-asset-audit.mjs <결과.json>`.

실제 판정과 어긋난 설명은 다음과 같이 고쳤다. 효과는 그대로다.

| 부품 | 확인한 실제 조건 | 설명 수정 |
|---|---|---|
| 백전 훈장 | 처치>=8 | ‘8 넘으면’→‘8 이상’ |
| 무사고 명판 | 대국>=3, 생명 소모 defied=0 | ‘쓰러진 적 없음/무사고’→‘3대국·생명 소모 없음’. 쓰러짐0회·승리3회로 확대 해석하지 않음 |
| 이동식 옥좌 | 킹으로 이동 명령을 낸 뒤 | ‘킹 카드마다’→‘킹 이동 명령마다’ |
| 갈래 톱니 | 포크 속성 카드가 두 적을 겨눔 | 일반 다중 명중과 구분해 포크 조건 명시 |
| 셈 막대 | 현재 연쇄>=4이고 해당 턴 미발동 | ‘4에 닿으면’→‘4 이상’ |

기록·플레이 수치·희귀도는 바꾸지 않았다. 실제 카드에서 넘치던 맞댄 철판/공성 걸쇠 문구는 짧게 다듬고, 세 줄 상세의 정확한 조건은 보존했다.

## 이름과 카드 견본

긴 본명에 자동 별명을 붙이면 동료 명패가 옆 카드까지 침범하는 실제 상태를 재현했다. 명패에는 본명만, 별명은 기존 카드 받침 정보 줄에 표시한다. 별명·시리얼·기록 데이터는 그대로다. 긴 부품3종은 정식 name과 작은 카드용 shortName을 분리했다. 정식 이름은 접근성/설명/획득 기록에 남긴다.

개발용 전체 견본은 옛 작은 격자 대신 본편과 같은 카드 레일을 사용한다. 처음 작은 견본에서 나온77개 텍스트 경고를 그대로 본편 결함으로 세지 않고, 실제 카드 배율에서 다시 검증했다. 그 결과 남은 긴 조건 두 곳과 이름을 수정했다.

667×375 / 915×412 / 1024×768 / 1280×720에서176개 카드의 명패·설명 범위 검사0, 긴 이름 명패 검사0, 별명 보존을 확인했다. 부품 칸 가득 참의 기존 교체 화면도 열었다. 새 슬롯 확장과 고정 높이 교체 문법의 최종 검수는 D-433에서 이어간다.

## 이야기와 그림

본편3장·새 폰/새 분대·선대 왕·실제 생존자 약속·왕위/출하 선택·부모/아이 엔딩을 실행 각본과 대조했다. 본편 진입 모듈에서 보관용 `src/data/story.ts`는 참조되지 않는다. 현재 루트의 이야기와 옛 노벨은 구분했다.

S-01을 아직 미수령이라고 하던 실행 정본을 수령/접속 완료로 정정했다. 결정 장면의 alt도 실제 도금왕 초상에 맞췄다. 실제 이미지를 보니 ‘빈 거푸집’ 컷에는 옛 승급 그림, 출하/운송 컷에는 공장 실내 상자가 재사용되고 있었다. 그림 없이 접속 완료라고 하지 않고 S-02~04 신규 장면으로 발주 준비한다.

아이템은8쌍이 동일 아이콘을 공유한다. I-14A~D 네 장은 이미 제작 완료여서 재발주하지 않는다. 나머지 마지막 숨/피의 장부/백전 훈장/죽음 넘긴 표식 네 장은 I-15A~D로 분리한다. [현재 발주서](../asset-order-master.md)는 신규7건(아이템4·장면3)과 후속 UI 후보1건을 구분하며, P1 다섯 건부터 복사해 전달할 수 있다. UI-34 상태표식은 표시 로직 미접속 후보로 현재 테스트 필수품이 아니다.

초기 에셋 생산 계획/일러스트 목록의 옛 미수령 수량·왕관 합성 요청을 현재 주문으로 오해하지 않도록 정정했다. 현재 프롬프트는 원본 도트 크기·정수 확대·팔레트·여백·인물/인원 비고정·연결 위치를 각각 포함한다. 첨부 파일이나 ZIP은 필수가 아니다.
