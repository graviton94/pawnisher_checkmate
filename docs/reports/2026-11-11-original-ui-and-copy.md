# 원본 전체 반입·UI 문구 보정 — D-428

사용자 지적대로 D-427의 상징·핀 분리와 재조립을 폐기했다. 원본 프레임의 색·윤곽·장식 위치를 유지하는 전체 픽셀화로 교체했다. UI-32는 원래 시트의 네 칸만 나눈다. 독립 glyph/pin 파일, 모서리 복제, 임의 팔레트 치환과 런타임 합성은 제거했다.

## 적용 결과

| 대상 | 현재 처리 |
|---|---|
| UI-31 | 원본 전체 64×64, 고정 모서리 18도트 |
| UI-32 | 원본 네 프레임 각각 64×64, 모서리 18도트. 체력·방열판 / 공격·방어 2×2 |
| UI-33 | 원본 종이 전체 128×49. 양쪽 금색 핀을 원래 모서리 안에 보존 |
| 위험 예고 | 폰 위 해골 글리프를 기존 X 그림+짙은 붉은 배지로 변경. 적 처치 칸은 금색 X |
| 카드 비용 태엽 | 왼쪽 손패에만 `+1px`. 915×412 DOM 실측 상대 Y **2.25→3.25px**, 다섯 카드 모두 크기 **20.9375×20.9375px** 동일 |
| 문구 | 실행 코드·현행 GDD/의뢰서의 ‘난도’를 ‘난이도’로 통일. ‘본편의 장→장 선택’, ‘다시 읽기→다시 도전’, ‘도전 난이도 열림→도전 모드 해금’ |

본편 3장·별도 도전 모드와 저장 키는 유지한다. 기존 기물 원화·S-01 집 장면은 바꾸지 않았다. 새 발주는 없다.
