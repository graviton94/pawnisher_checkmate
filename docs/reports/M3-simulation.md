# M3 시뮬레이션 리포트

AI 대 AI 대량 대전(`npm run sim`)으로 M3 규칙을 검증한 결과다. 판마다 시드를 바꿔 진행했다.

## 1. 6×6 교착 해소 (D-014, D-017)

붕괴 시작 라운드별 (공격형 AI 대 공격형 AI, 30판):

| 붕괴 시작 | 온보딩 A 결판 | A 평균 턴 | 온보딩 B 결판 | B 평균 턴 | 승급/판 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 없음 (M2 기준) | 7/30 | — | 24/30 | 51 | 0.3~0.4 |
| 8라운드 | 28/30 | 36 | 22/30 | 50 | 0.03 |
| 6라운드 | 28/30 | 33 | 22/30 | 44 | 0.03 |
| **4라운드 (채택)** | **29/30** | **23** | **30/30** | **24** | **0.00** |

- 6×6 기본값을 4라운드 시작으로 정했다. 한 번 무너지면 4×4가 되어 더 무너지지 않는다.
- 끝줄이 먼저 무너지므로 6×6에서는 승급이 사실상 사라졌다. 폰 우회 전진(D-017) 없이도 퀸 과다 문제가 생기지 않는다.

최종 규칙 검증 (40판):

| 판 | 결판 | 결판까지 평균 턴 | 승급/판 | 최후의 일격/판 | 붕괴/판 | 요충지 점령/판 |
| :--- | :-: | :-: | :-: | :-: | :-: | :-: |
| 6×6 온보딩 A | 38/40 | 22.8 | 0.03 | 0.53 | 1.00 | — |
| 6×6 온보딩 B | 40/40 | 25.7 | 0.00 | 0.30 | 1.00 | — |
| 8×8 풀 덱 | 40/40 | 19.7 | 0.17 | 0.05 | 0.25 | 0.80 |

## 2. 악용 전략 검증 (D-015)

| 전략 | 상대 | 승률 |
| :--- | :--- | :-: |
| ① 기물을 버리며 킹만 노림 (최후의 일격 노림수) | 튜닝 AI, 8×8 | 10% (1승 6무 33패) |
| ① 같은 전략 | 공격형 AI, 6×6 | 8% (3승 37패) |
| ② 전력을 가볍게 보고 요충지에 집착 | 튜닝 AI, 8×8 | 55% (22승 18패) |

- ① 최후의 일격 1회 제한이 의도대로 작동한다. 기물을 버리는 쪽이 크게 진다.
- ② 40판 기준 55%는 오차 범위(±8%p) 안이다. 뚜렷한 악용으로 보기 어렵다.

## 3. 요충지 (GDD 5장) — 관찰 필요

8×8 40판에서 점령 32회:

| Tier 1 | Tier 2 | Tier 3 | 점령한 쪽이 최종 승리 |
| :-: | :-: | :-: | :-: |
| 26 | 5 | 1 | 29/32 |

- 열세 쪽 근처에 생기지만 실제로는 **우세한 쪽이 점령하는 경우가 대부분**(Tier 1)이고, 점령한 쪽이 거의 이긴다.
- 역전 장치보다 굳히기 장치로 쓰이고 있다. 밸런스 조정 후보로 남긴다 (리포트 하단 참고).

## 4. AI 가중치 튜닝과 지능 단계 (D-018)

- (1+1) 진화 전략, 14세대 × 16판. 튜닝 가중치가 기본 가중치를 **64%** (40판) 로 이긴다 → `src/data/aiWeights.ts`.
- 지능 단계 요인 (8×8, 60판):

| 비교 | 승률 |
| :--- | :-: |
| 단계 3 vs 단계 1 | 65% |
| 탐색 폭 10 vs 3 (실수 없음) | 54% |
| 실수 0% vs 40% (탐색 폭 3) | 71% |
| 상대 응수까지 보는 2수 탐색 vs 없음 | 38% (오히려 약함 → 채택 안 함) |

- 실력 차이는 탐색 폭보다 실수율에서 크게 난다. 단계는 탐색 폭 + 실수율로 나눴다.
- 2수 탐색은 상대를 가벼운 탐색으로 흉내 내는 탓에 판단을 흐렸다. 더 강한 단계는 단계별 가중치 튜닝으로 만드는 편이 낫다.

## 조정 후보 (결정 필요)

1. **요충지가 굳히기 장치가 되는 문제**: 우세한 쪽의 점령 보상을 줄이거나(예: 우세 측은 AP 보너스 없음), 열세 쪽만 점령 보상을 받게 하는 안.
2. **AI 단계 간 격차**: 현재 최상위 단계가 최하위를 65%로 이긴다. 등반 후반 체감 난이도를 위해 단계별 별도 튜닝이 필요할 수 있다.
