## 1. 6×6 교착 해소 (D-014, D-017)

붕괴 시작 라운드별 (공격형 AI 대 공격형 AI, 30판):

| 붕괴 시작 | 온보딩 A 결판 | A 평균 턴 | 온보딩 B 결판 | B 평균 턴 | 승급/판 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 없음 (M2 기준) | 7/30 | — | 24/30 | 51 | 0.3~0.4 |
| 8라운드 | 28/30 | 36 | 22/30 | 50 | 0.03 |
| 6라운드 | 28/30 | 33 | 22/30 | 44 | 0.03 |
| **4라운드 (채택)** | **29/30** | **23** | **30/30** | **24** | **0.00** |

- 6×6 기본값을 4라운드 시작으로 정했다. 한 번 무너지면 4×4가 되어 더 무너지지 않는다.
- 끝줄이 먼저 무너지므로 6×6에서는 승급이 사실상 사라졌다. 폰 우회 전진(D-017) 없이도 퀸 과다 문제가 생기지 않는다.

최종 규칙 검증 (40판):

| 판 | 결판 | 결판까지 평균 턴 | 승급/판 | 최후의 일격/판 | 붕괴/판 | 요충지 점령/판 |
| :--- | :-: | :-: | :-: | :-: | :-: | :-: |
| 6×6 온보딩 A | 38/40 | 22.8 | 0.03 | 0.53 | 1.00 | — |
| 6×6 온보딩 B | 40/40 | 25.7 | 0.00 | 0.30 | 1.00 | — |

## 2. 악용 전략 검증 (D-015)

| 전략 | 상대 | 승률 |

## 3. 요충지 (GDD 5장)

> **정정**: 처음 리포트에서 "Tier 1 점령 = 우세한 쪽의 점령"으로 해석했으나 틀렸다. Tier 1은 열세율 0~15%라서 **조금 밀리는 쪽**도 포함한다.
> 점령 시점에 실제로 열세였는지(`behind`)를 따로 기록해 다시 측정했다.

8×8, 튜닝 AI 대 튜닝 AI, 60판:

| 조건 | 점령/판 | 열세 쪽 점령 비율 | 열세 쪽 점령 후 승 | 우세 쪽 점령 후 승 |
| :--- | :-: | :-: | :-: | :-: |
| 현재 (엄폐 30/30%, 유지 2/2턴) | 0.73 | 84% | 92% | 86% |
| 엄폐 차등 (우세 10% / 열세 50%) | 0.67 | 88% | 89% | 80% |
| 유지 차등 (우세 3턴 / 열세 2턴) | 0.73 | 91% | 85% | 75% |
| 둘 다 | 0.67 | 95% | 82% | 100% (2회) |
| 둘 다 + 열세 1턴 | 0.90 | 96% | 79% | 100% (2회) |
| 보상 없음 (인과 확인용) | 0.72 | 88% | 71% | — |

- 요충지는 **이미 대부분 열세 쪽이 점령**하고 있다. 우세 쪽 점령은 16% 정도다.
- 점령한 쪽이 이기는 비율은 보상이 없어도 72%다. 2턴을 버틸 수 있다는 것 자체가 국면을 쥐고 있다는 뜻이라서다. 보상은 여기에 약 15~20%p를 더한다.
- 차등 조건 중 **유지 차등(우세 3턴 / 열세 2턴)** 이 단순하면서 효과가 가장 분명하다: 우세 쪽도 점령할 수 있지만 더 오래 버텨야 하고, 우세 쪽 점령 후 승률이 86% → 75%로 내려간다.
## 3-1. 요충지 점령 시도 추적과 기여도 (`sim/strongholdAudit.sim.ts`)

- **시도**: 기물이 요충지에 올라선 순간부터 끝날 때까지 추적한다 (버티다 전사 / 자진 이탈 / 점령 / 붕괴·전투 종료).
- **기여도**: 점령이 일어난 턴에서 판을 둘로 나눈다. 한쪽은 보상을 주고 다른 쪽은 보상 없이, 같은 AI·같은 시드로 끝까지 둔 뒤 승률을 비교한다.
- 형편은 시도 시작 시점 기준: 우세·동률 / 조금 열세(T1, 열세율 15% 미만) / 크게 열세(T2·T3).

8×8, 튜닝 AI 대 튜닝 AI, 80판:

| 조건 | 형편 | 시도 | 전사 | 점령 | 점령 후 승리 | 보상 없이 두면 | 보상 기여 |
| :--- | :--- | :-: | :-: | :-: | :-: | :-: | :-: |
| 현재 (모두 엄폐 30%·2턴) | 우세·동률 | 27 | 3 | 20 | 85% | 75% | +10%p |
| | 조금 열세 | 43 | 2 | 37 | 86% | 81% | +5%p |
| | 크게 열세 | 13 | 2 | **1** | 0% | 0% | 0 |
| 형편별 (우세 20%·3턴 / T1 30%·2턴 / T2 40%·2턴 / T3 50%·1턴) | 우세·동률 | 24 | 4 | 18 | 72% | 72% | 0 |
| | 조금 열세 | 43 | 2 | 38 | 87% | 82% | +5%p |
| | 크게 열세 | 14 | 0 | **6** | **100%** | 33% | **+67%p** |

- 현재 규칙에서는 크게 밀리는 쪽이 요충지를 거의 점령하지 못한다(13번 시도 중 1번). 역전 장치로 작동하지 않는다.
- 형편별 조건에서는 크게 밀리는 쪽의 점령이 6번으로 늘고, 그 6번 모두 역전승했다. 같은 판을 보상 없이 두면 2번만 이긴다.
- 크게 열세인 표본이 아직 작다(6번). 채택 후 판 수를 늘려 다시 확인한다.

## 4. AI 가중치 튜닝과 지능 단계 (D-018)

- (1+1) 진화 전략, 14세대 × 16판. 튜닝 가중치가 기본 가중치를 **64%** (40판) 로 이긴다 → `src/data/aiWeights.ts`.
- 지능 단계 요인 (8×8, 60판):

| 비교 | 승률 |
| :--- | :-: |
| 단계 3 vs 단계 1 | 65% |
| 탐색 폭 10 vs 3 (실수 없음) | 54% |
| 실수 0% vs 40% (탐색 폭 3) | 71% |
| 상대 응수까지 보는 2수 탐색 vs 없음 | 38% (오히려 약함 → 채택 안 함) |

- 실력 차이는 탐색 폭보다 실수율에서 크게 난다. 단계는 탐색 폭 + 실수율로 나눴다.
- 2수 탐색은 상대를 가벼운 탐색으로 흉내 내는 탓에 판단을 흐렸다. 더 강한 단계는 단계별 가중치 튜닝으로 만드는 편이 낫다.
