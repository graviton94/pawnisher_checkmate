# 손 놓은 봇 줄이기 (2026-11-09d)

사용자: 「난이도는 봇의 강함 · 성향 · 실수가 다 중요하다. 태엽이 남았는데 아무것도 안 하는 봇을 최소화」.
게임 수치는 건드리지 않았다 — 봇(`src/slice/bot.ts` · `src/data/bot.ts`)과 측정(`src/sim/runbot.ts`)만.

## 잰 것

- **손놓음%** = 내 턴 가운데 「태엽이 남았고 낼 수 있는 카드도 있었는데 턴을 끝낸」 비율 (`playOut` · `playOutSearch`가 턴 끝마다 센다 → `RunResult.idle`, 퀵 등반 머신 표의 마지막 칸).
- 같은 게임(현재 HEAD · 기록 유물 2차 D-384 · 부품 칸 상한 포함), 같은 씨앗으로 봇만 바꿔 쟀다. `npm run climb` 표 그대로.

## 바꾼 것

- **카드는 턴이 끝나면 손패째 버려지고 태엽도 넘어가지 않는다** → 남긴 태엽은 그냥 버린 것. 그래서:
  - 수 점수의 태엽 값 2 → 0.5 (`costW` — 같은 수 사이 순서만), 두느냐는 태엽을 뺀 점수가 `passBar`(−1)를 넘느냐로. 옆걸음은 두고 물러나는 수는 두지 않는다.
  - **자리 값** `placeOf`: 킹이 아닌 기물이 가장 가까운 적 · 적 킹에 붙을수록 + (예전엔 모든 기물이 적 킹 쪽만 · 킹도 앞장섰다 → 킹은 0).
  - 보통 봇: 예고 칸에서 빠지는 수 가점 (킹 40 · 분대원 10). 단순 봇은 예고를 안 보니 없다 (성격 유지).
  - 방열판 · 땜질: 킹만 → 예고 칸의 킹 > 예고 칸의 분대원 > 다친 기물(채우는 HP만큼) > 그 밖. 다 찬 기물엔 땜질하지 않는다.
- **무뇌**: 30% 「그냥 턴 끝내기」 → 0 (`randomPass`). 실수는 아무 수나 두는 것으로 남는다 (완주 0%는 그대로).
- **두뇌**: 판 평가에 자리 값 · 남은 방열판, 둔 수마다 +0.03(`evalPlay` — 판값이 같으면 두는 쪽), 후보에 방열판 · 땜질, 찾은 순서를 다 두고 낼 카드가 남으면 다시 수읽기(`researchMax` 4).
  - 어느 고침이 세졌나 (승급 13, 50판, relic 씨앗): 다 끔 42% · 다시 수읽기만 끔 56% · 둔 수 가점만 끔 76% · 자리 값만 끔 78% · 다 켬 70~79%. 다시 수읽기 + 둔 수 가점이 거의 전부.
- **부품 칸 상한** (`runbot`, D-384와 같게): 막마다 `partSlotsAt` 칸, 넘치면 가장 낮은 등급(같으면 오래된 것)을 녹여 나사 `meltBack`, 새 것이 다 낮으면 새 것을 녹인다. 고물상은 남길 부품만 산다. 억지로 넣은 부품(힘 값 측정)은 녹이지 않는다.
