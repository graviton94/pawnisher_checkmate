# 출시 완주 점검 (2026-11-16)

본편(`src/slice/`)이 처음부터 끝까지 깰 수 있는지 확인했다. 확인한 범위: 넷 왕관 전부, 모든 결말, 기록 · 해금 저장, 선택 도전, 오늘의 도전, 앱을 닫았다가 이어하기.
밸런스 수치는 손대지 않았다(D-080). 완주율은 기록만 한다.

## 0. 돌린 것

| 점검 | 도구 | 결과 |
|---|---|---|

실제 화면 점검의 방식: 대국만 디버그 훅으로 판을 비워 곧바로 이긴다(`sliceApi.finish`). 그 밖의 화면은 모두 실제 단추를 누른다. 메뉴 · 시작 세트 · 지도 · 보상 · 사건 · 고물상 · 컷 · 왕위 결정 · 크레딧 · 결과 장부가 여기에 든다.
컷은 건너뛰지 않고 한 줄씩 눌러 넘겼다. 그래서 장면 순서가 그대로 기록에 남는다.
본편 넷은 **한 기록에 이어서** 했다. 왕관 하나를 끝내면 「메인 화면으로」를 누르고, 메뉴에 뜬 다음 왕관으로 새 출하를 시작했다. 해금 · 왕의 이력이 실제로 저장되고 다음 왕관에서 읽히는지 함께 본 것이다.

없는 그림 대신 쓴 대체 그림(404)은 한 건도 없었다.

확인하지 못한 것 (NOT ASSESSED):
- **도금왕 2단계 컷(GLD 격노)**: 대국을 한 번에 끝내는 훅 때문에 2단계가 오지 않았다. 대국 안 연출이라 흐름(결말 · 저장)에는 영향이 없다.
- **같은 왕관 재도전 그림자 컷(SHD-A, 둘째~넷째)**: 패배 뒤 같은 왕관을 다시 시작하는 경로는 단위 시험(`storyAttempts`)으로만 확인했다.
- **실기기(안드로이드 · Electron)**: 이번 점검은 브라우저(Chromium)만 봤다.

## 2. 이어하기 자리 (D-529 저장)

닫기 = `pagehide`(앱을 내림/닫음과 같은 저장 경로) → 첫 화면부터 새로 연다 → 메뉴 「이어하기」. 비교한 값은 막 · 줄 · 노드 · 나사 · 이긴 대국 · 덱 · 부품 · 분대 HP · 부적 · 지나온 길, 대국이면 턴까지.

| 닫은 자리 | 이어한 화면 | 잃은 것 · 겹친 것 | 판정 |
|---|---|---|---|
| 지도 | 지도, 같은 자리 | 없음 | ✓ |
| 대국 중간 (카드를 내고 턴을 넘긴 뒤) | 같은 대국, 같은 턴(2) | 없음 | ✓ |
| 보상 화면 (이긴 뒤 고르기 전) | 같은 보상, 같은 세 장 | 없음 (대국을 다시 굴리지 않음) | ✓ |
| 사건 안 | 그 사건에 들어가기 전 지도 | 사건 안에서는 저장하지 않는다. 다시 들어가면 **같은 사건**이 나오고, 그사이 생긴 득실은 나사와 함께 되돌아간다 | ✓ |
| 고물상 안 | 들어가기 전 지도 | 다시 들어가면 **같은 진열**. 산 것은 나사와 함께 되돌아가 겹치지 않는다 | ✓ |
| 부품 상자 | 들어가기 전 지도 | 다시 열면 같은 상자 | ✓ |
| 반장 등장 컷 | 같은 반장 대국 (등장 컷 다시) | 없음 | ✓ |
| 왕위 결정 화면 | 왕위 결정 화면 | 기록 그대로 (runs 증가 없음) | ✓ |
| 결말 컷 (END-K 도중) | 왕위 결정 화면부터 다시 | 기록은 결말을 끝낼 때 한 번만 (runs 3→4, 본편 0→1) | ✓ |
| 하자 폐기 창 (여벌 심장 있음) | 그 대국 처음부터, 여벌 하나 깸 = 「다시 둔다」와 같은 자리 | — | **고침** (전: 진 대국의 앞 턴으로 돌아가고 여벌도 그대로) |
| 하자 폐기 창 (여벌 없음, 도전 10) | 이어하기 없음, 패배 기록 1회 | — | **고침** (전: 진 대국의 앞 턴으로 돌아가 패배가 사라짐) |
| 패배 컷 (END-F 도중) | 이어하기 없음, 패배 기록 1회 | — | **고침** (전: 같은 문제) |
| 크레딧 · 결과 장부 | (기록은 이미 남았고 저장은 지워졌다) | 없음 | ✓ |

출하 시작의 그림자 컷 도중에는 아직 저장이 없다. 이때 닫으면 이어하기 없이 메뉴로 돌아간다. 출하가 시작되지 않은 상태라 잃는 것은 없다.

| 1 | **오늘의 도전이 사람마다 다른 출하**였다. 같은 날 · 같은 시드인데도 갈렸다 | 최근 만난 사건(`evRecent`)을 사건 가방에서 뺐다. 또 원수가 있는 사람만 대국마다 출하 난수를 한 번 더 뽑고 그 적을 끼웠다. 실제 화면에서 두 기록을 비교하니 가방이 달랐다 | `director.eventBagFor` · `runNemeses`: 오늘의 도전은 늘 사건 전부, 원수 없음 | `tests/completion.test.ts` + 화면 비교 「같은 출하」 |
| 2 | **하자 폐기 창이나 패배 컷에서 앱을 닫으면 패배가 물러졌다**. 진 대국의 직전 턴으로 이어졌고, 여벌 심장도 깨지지 않았다 | 이긴/진 뒤에는 대국 중 저장을 건너뛴다. 그래서 직전 턴 끝 저장이 남았고, 기록 · 저장 지우기는 패배 컷이 끝난 뒤에야 했다 | `save.commitRunEnd`: 여벌이 없으면 하자 폐기 순간에 기록하고 저장을 지운다. 여벌이 있으면 「여벌 하나 깨고 그 대국 처음부터」를 저장한다. 「다시 둔다」도 저장한다 | `tests/completion.test.ts` + `resume.cjs` 세 줄 |
| 3 | 패배 컷 아래에 하자 폐기 창이 열린 채 남았고, 그 「끝낸다」가 살아 있었다. 다시 눌리면 패배 컷이 또 돌고 기록이 두 번 남았다 | 창을 닫지 않고 컷을 띄웠고, 출하 끝을 막는 장치가 없었다 | 창을 먼저 닫는다. 출하 끝은 한 번만(`endCalled`) 열리고, 기록은 출하 ID로 한 번만 남는다(`Meta.lastRun`) | `tests/completion.test.ts` (같은 출하 두 번 → 한 번) |

| 5 | 연출 줄이기에서 「고장 난 조립 판정기」가 첫 칸만 자동으로 열리고, 나머지 둘은 눌러야 열렸다 (멈춤은 아니다. 누르면 열린다) | 셋을 한꺼번에 열면 첫 칸이 `busy`를 잡아 나머지가 무시됐다 | 셋을 차례로 연다 (`evstage.ts`) | 화면 점검 (캔버스 연출이라 단위 시험 없음) |

멈춤(소프트락)은 없었다. 사람이 단추를 누를 수 없는 화면, 나갈 수 없는 화면, 오류 창 모두 0건이다. 점검 도중 멈췄던 것은 모두 점검 도구 쪽 문제였다(사건 안 카드 고르기 · 판정기 테이프). 실제 탭으로 다시 해 보니 모두 넘어갔다.

설계대로라 고치지 않은 것:
- 넷째 왕관에서 「왕관을 쓴다」를 고르면 왕의 이력에 넷째 왕이 더해진다(`recordRun`). 진엔딩은 다시 도전해서 볼 수 있다.
- 사건 · 고물상 · 상자 안에서는 저장하지 않는다. 닫으면 들어가기 전 지도로 돌아간다(같은 난수라 같은 내용).
- 첫 출하의 1막 반장에서 「다시 둔다」를 누른 직후 앱을 닫으면, 이어 갈 때 안전망 판(`ftueRetry`)이 아니라 원래 판이 선다. 첫 출하 한 번에만 해당하는 작은 차이라 기록만 남긴다.
