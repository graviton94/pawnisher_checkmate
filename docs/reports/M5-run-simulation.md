# M5 자동 등반 시뮬레이션 (Act 1, 1~12층)

`npm run sim -- sim/run.sim.ts` (SIM_GAMES=150). 플레이어 쪽 전투도 AI(단계 2, 튜닝 가중치)가 두고,
노드·보상 선택은 단순 규칙(`src/sim/runner.ts`)을 따른다. 사람은 AI보다 잘할 것이므로 **절대값보다 곡선**을 본다.

## 현재 곡선 (8단계)

- 층 도달: 4층 97% · 8층 75% · 12층(보스) 57%
- 전투 승률: 1~3층 99% · 4~7층 90% · 8~11층 92% / 엘리트 4~7층 67%(표본 3) · 8~11층 73% / 보스 59%
  - 보스별: 나이트 73% · 비숍 59% · 룩 47%
- 평균 전투 길이: 1~3층 15턴, 4~7층 27턴, 8~11층 20턴, 보스 25턴 (양 진영 합산 턴)
- 12층 도착 시: 덱 11.3기 · 강화 합 +3.3 · 인챈트 7장 · 카드 0.3장 · 골드 65
- 골드: 런당 획득 265 · 소비 216

## 남은 과제

- 자동 등반은 카드를 거의 안 쓴다(엘리트·보스에서만 3지선다). 사람 플레이에서 카드 체감은 따로 본다.
- 룩 보스가 가장 세다 (E03★ 돌진 + 룩 3기). 표본을 늘려 다시 본다.
- Act 1 대장간 완전 강화(+5)는 거의 나오지 않는다 — Act 2·3까지 가야 1개 유형이 목표 (GDD 8장 §8.6).
