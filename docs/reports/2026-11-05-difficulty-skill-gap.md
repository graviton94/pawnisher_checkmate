# 난이도 설계 — 두뇌 플레이는 깨고, 무뇌 플레이는 막힌다 (2026-11-05, D-228)

사용자: "두뇌 플레이로는 잘 클리어할 수 있어야 하지만 무뇌 플레이로는 클리어하기 힘들게 — 디테일한 난이도 조정이 핵심."

## 측정: 같은 등반 · 다른 머리
`sim/economy.sim.ts`에 봇 성향을 넣었다 (`EB`). 드래프트(카드 · 부품 · 지도 고르기)는 모두 같은 「평균 플레이어」 정책, 대국을 두는 머리만 다르다.
| 봇 | 두는 법 |
| :-- | :-- |
| 무뇌 random | 낼 수 있는 수 중 아무거나, 가끔 그냥 턴을 끝낸다 |
| 단순 naive | 지금 가장 세게 치는 수 — 적이 예고한 칸도 무시 |
| 보통 greedy | 위와 같되 예고된 칸을 피한다 |
| 두뇌 search | 한 턴 안의 순서를 3수 앞까지 읽는다 (연쇄를 쌓아 마무리) |

## 손보기 전 (다시 하기 무제한 · 적 공격 0.75)
- 단순 · 보통 · 두뇌 모두 완주 100% — 예고를 무시해도 안 죽고, 머리를 써도 차이가 없다.
- 지면 같은 판을 공짜로 무제한 다시 → 사람은 누구나 완주. 난이도가 「막힘」이 아니라 「시간」이었다.

## 바꾼 것
1. **1패 = 출하 끝** (사용자 결정). 대신 **부적**(부품 칸을 안 쓰는 개수):
   - 여벌 심장 톱니 — 킹이 쓰러지면 대신 깨지고 그 대국을 처음부터. 승급 0~1은 1개로 시작, 상자 8% · 고물상 가끔(140).
   - 역회전 톱니 — 되감기 1회. 시작 2 · 상자 30% · 반장 +1 · 고물상 45. 공짜 되감기는 없앴다(되감는 테이프 = 대국마다 공짜 1회).
2. **적 수치**: 공격 0.75 → 1.25, 공격 성장 0.015 → 0.055 (깊이당), HP 성장 1.05 → 1.065 (깊이당 곱).
3. 버그: 킹이 이기는 수와 함께 쓰러지면 분대에서 빠져 다음 대국이 깨졌다 → HP 1로 버틴다.

## 적 수치 탐색 (1패 끝 + 여벌 심장 1, 40~60판)
| 공격 · 공격 성장 · HP 성장 | 단순 | 보통 | 두뇌 |
| :-- | :-: | :-: | :-: |
| 0.75 · 0.015 · 1.05 (예전) | 100% | 100% | 98% |
| 1.0 · 0.04 · 1.06 | 65% | 78% | 93% |
| 1.25 · 0.05 · 1.06 | 35% | 63% | 95% |
| **1.25 · 0.055 · 1.065 (채택)** | **27%** | **30%** | **85%** |
| 1.25 · 0.06 · 1.07 | 18% | 33% | 70% |
| 1.35 · 0.06 · 1.08 | 8% | 18% | 55% |
- 채택안: 무뇌 0% · 단순 27% · 보통 30% · 두뇌 85%. 막힘은 대부분 3막(1막 패배 1/60) — 1막은 배우는 곳으로 남았다.
- 두뇌 봇은 3수만 읽는다. 사람은 덱을 계획하고 판 전체를 보니 이보다 잘한다 — 사람 기준 「생각하면 거의 깬다」.
- 영구 손실(분대원 폐기)이 판당 2.7 → 약 7로 늘었다. 분대원 하나하나가 아까워진다 — 사람 플레이로 지나친지 본다.

## 다음
- 단순 ↔ 보통 차이(예고를 피하는 값)가 작다 (27% ↔ 30%). 예고를 무시하면 아프게 — 킹을 노리는 예고 공격 · 되받아치는 적을 2 · 3막 일반 대국에도 — 을 다음 손질로.
- 승급 2부터는 여벌 심장이 없다 — 승급별 곡선은 사람 플레이 기록이 쌓이면 다시 잰다.
