# 사건 값어치 진단 (D-261 준비, 2026-11-06)

> 사용자: 「분대 체력이 대체로 너무 high cost 아닌가? 체력을 먼저 지불하는 것과 결과로 깎이는 것은 연출 순서가 달라야. 후반에 분대 전체 15% · 35%씩 갈려 나가면 지장이 크다. 나사 사용처도 줄었다. 고민할 법한 value인지 진단해 달라.」

측정: `ER=400 EB=greedy ETAG=-d261 npm run sim -- economy` (사건 1,029건, `sim/event-diag-d261.json`).
주의: greedy 봇은 완주 18/400으로 사람보다 약하다. 시뮬 고물상에는 D-247 서비스 값 누적이 없어 남는 나사가 조금 부풀어 있다.

## 기준 수치
- 사건을 만날 때 분대: 1막 4.3기 · HP 88% / 2막 5.5기 · 79% / 3막 4.5기 · 69% — 대국마다 30%만 회복해서 HP는 늘 빠듯하다.
- 사건 다음 대국에서 쓰러지는 분대원(평균 1.44): 회복(야간 교대 두드리기, 들어갈 때 HP 93%) **0.84** ↔ 분대 −35%(녹슨 금고, 48%) **1.59** · 불을 키울까 1.76 · 녹 긁기 1.64 — 분대 전체 HP 손해는 다음 판 쓰러짐을 약 2배로 만든다.
- 나사: 한 출하에 대국 531 + 상자 64 + 사건 **+38**을 벌고 370을 쓴다. 끝날 때 평균 **263이 남는다**. 사건 15종 중 나사를 쓰는 것은 땜장이 · 정비 폰(40) 둘뿐이고, 나사를 주는 것은 흑 비숍(+157) · 금고(+150)다.

## 사건별 (대가 → 얻는 것, 진단)
| 사건 | 대가 | 얻는 것 | 진단 |
|---|---|---|---|
| 녹슨 금고 | 분대 전원 HP −35% | 나사 +150 | **과함**: 분대 수에 비례해 커지는 대가 vs 고정 보상. 남는 나사라 가치도 낮음 |
| 판정기 | 분대 전원 −15% (먼저) · 35%면 −15% 더 | 40% 희귀 부품 · 25% 승급 | **과함**: 먼저 내는 값과 벌칙이 같은 모양(분대 전원 %) |
| 녹슨 봉인 상자 | 없음 (50%면 분대 −20%) | 50% 희귀 이상 부품 | **고민 없음**: 공짜 50% 희귀 부품 — 거의 늘 고른다 |
| 동전 나이트 | 없음 (50%면 분대원 하나 −50%) | 50% 부품 | 가벼운 도박으로 적당. 대가가 「하나」라 분대 수와 무관해서 좋다 |
| 정비 폰 | 나사 40 | 무작위 2장 다듬기(고물상이면 120) | **고민 없음**: 너무 싸다 |
| 땜장이 | 나사 40 | 문턱 +1 / 50% 문턱 +2 · 50% 심장 톱니 금 | 적당. 좋은 고민 |
| 견습 폰 | 없음 | 50% 2장 다듬기 · 50% 무작위 2장 부서짐 | 부서짐이 오히려 덱 압축일 때가 있어 결과가 애매 |
| 쇳물 담금질 | 무작위 분대원 | 50% 한 단계 위 · 50% 잃음 | 고를 대상을 못 고른다 (주도권 없음) |
| 쇳물 앞의 거래 | 분대원 하나(무작위) | 희귀 이상 부품 | 좋은 고민. 바칠 대상을 고르게 하면 더 좋다 |
| 흑 비숍 | 가장 비싼 분대원 | 나사 ×3 (최대 240) | 고민은 크지만 받는 나사가 쓸 데가 적다 |
| 조는 저울 | 50% 나사 절반 | 50% 폰 둘 → 나이트 | 적당 |
| 야간 교대 | 없음 / 50% 분대 −30% | +30% / 50% 가득 + 1장 다듬기 | 좋음 — 사건 주제가 HP라 분대 전원 %가 어울린다 |
| 부품 교환상 · 저울추 · 컨베이어 | 폰 둘 · 카드 · 카드 | 나이트 · 다듬기 · 새 카드 | 적당 |

## 결론
1. **분대 전원 % 대가는 분대가 커질수록, 막이 깊을수록 비싸진다**(고정 보상과 어긋남). HP 주제 사건(야간 교대)만 남기고, 나머지는 **「분대원 하나가 치른다」 — 플레이어가 누가 치를지 고른다**로 바꾸는 것이 맞다.
2. **먼저 내는 값과 결과 벌칙을 다른 모양으로**: 먼저 내는 값 = 고른 분대원이 장치 앞에 서서 HP가 황동빛으로 빨려 나감(바침), 결과 벌칙 = 장치 뒤 붉은 피격(전투와 같음).
3. **나사가 남는다** — 사건은 나사를 거의 안 쓰고 오히려 준다. 확률 사건에 나사를 거는 것은 심의 때문에 안 되므로(D-254), **확정 거래로 나사를 쓰게**: 정비 폰 40 → 70, 땜장이 40 → 60, 담금질 · 거래에 「나사 N으로 대상을 고른다」 같은 값 매기기.
4. **고민 없는 선택 정리**: 봉인 상자는 먼저 내는 값(고른 분대원 HP −40%)을 붙이고, 정비 폰은 값을 올린다.
