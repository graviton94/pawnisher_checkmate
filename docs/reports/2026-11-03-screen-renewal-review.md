# 화면 리뉴얼 검토 1~2단계 (2026-11-03)

> 사용자: "디자인이랑 레이아웃, UX 고려해서 새로 그릴 것은 새로 그리고 아예 리뉴얼 검토" → "1~2단계 바로 시작".
> 결과 페이지(스크린샷 · 와이어프레임): https://claude.ai/artifact/2HRNH5H6kP6Y26rMc3S1Rj

## 핵심
- 화면 높이 412px가 상한이라 6×6 판은 어느 안이든 칸 61~63px(지금 45). 판 크기로는 안이 갈리지 않는다.
- 안을 가르는 것: 손패를 얼마나 읽기 쉬운지 · 엄지 동선 · **반장 · 장소 그림이 들어갈 자리**.
- 반장 그림은 실제 유닛(검은 킹)으로(D-199). 크기 · 비율은 안이 정해진 뒤 발주한다.

## 1단계 — 화면 진단 (괄호는 같은 문제를 말한 페르소나)
| 화면 | 판정 | 문제 |
| :-- | :-- | :-- |
| 대국 | 구조 | 판 66% 높이 · 칸 45px · 양옆 여백, 오른쪽 레일 가운데 빔, 태엽과 증기가 멀리, 카드 설명 잘림 (지원 · 한PD · 민수 · 밤새) |
| 반장 대국 | 존재감 | 일반전과 같은 판 + 규칙 상자 하나, 반장이 작은 도트뿐 (한PD · 태오 · 밤새 · K교수) |
| 반장 전환 | 그림 | 반장 셋이 같은 큰 도트 (밤새 · 한PD) |
| 보상 | 장소감 | 끝난 대국 위 창, 고를 것 여섯이 한 화면 (한PD · 민수 · 밤새 · K교수) |
| 지도 | 배경 | 막마다 같은 단색, 아래 띠가 크고 비어 있음 |
| 고물상 · 작업대 | 장소감 | 창 + 카드 격자, 주인 · 화덕이 화면에 없음 |
| 사건 | 양호 | 그림 + 글 — 「장소 화면」에 가장 가까움 |
| 출하 결과 | 그림 | 글 · 숫자뿐 |
| 메인 메뉴 | 양호 | 베인 타이틀 강함, P-00 배경 대기 |

## 2단계 — 대국 화면 세 구조 (6×6 기준)
| 안 | 칸 | 손패 | 반장 그림 자리 | 새로 그릴 것 |
| :-- | :-: | :-- | :-- | :-- |
| 1 양 날개 (지금 다듬기) | 61px | 이름만 | 없음 | 작은 카드 틀 |
| 2 판 왼쪽 · 지휘대 오른쪽 | 63px | 큰 카드 2줄 · 설명까지 | 없음 | 큰 카드 틀 · 지휘대 |
| 3 판 무대 · 떠 있는 장치 (권장) | 61px | 세로 탭 + 펼침 | **판 옆 큰 초상 (대국 내내)** | 카드 탭 · 펼친 카드 · 둥근 턴 끝 · 반장 초상 3 |

판 사이 화면은 세 안 공통으로 **장소 화면** 틀: 끝난 대국을 내리고 전체 배경(BG · A · E) + 왼쪽 주인 · 장소 그림 + 오른쪽 고를 것만.

## 사용자가 정할 것
1. 대국 구조 1 · 2 · 3안 (섞기 가능).
2. 판 사이 「장소 화면」 틀로 통일.
3. 정한 뒤 3단계: 실제 도트 · 색 · 글꼴 정밀 목업(FX 랩) → 반장 초상 · 배경 발주서를 그 크기에 맞춤.
