# Balance Check

## 입력 확인 먼저 (Game Studios: 없는 데이터로 통과 판정 금지)
- 시뮬레이터 `sim/run.sim.ts`, 러너 `src/sim/runner.ts`가 있어야 한다. 실행이 실패하면 판정은 **NOT ASSESSED — 이유**.
- 표본이 20판 미만인 구간은 수치를 적되 판정하지 않는다 ("표본 부족").

## 실행
`SIM_GAMES=<runs> npx vitest run -c vitest.sim.config.ts sim/run.sim.ts --silent=false` (60판 ≈ 5분, 백그라운드 권장)

## 목표 곡선 (D-025, AI 플레이어 기준 — 사람은 더 잘한다)
| 구간 | 목표 승률 | 의도 |
| :-- | :-: | :-- |
| 1~3층 일반 | 95% 이상 | 덱빌딩에 집중, "나 좀 잘하는데" |
| 4~11층 일반 / 엘리트 | 85~92% / 65~80% | 머리 써야 이긴다 |
| Act 1 보스 | 65~80% | 첫 고비 |
| Act 2 일반 / 보스 | 88~95% / 65~85% | 파츠 모으기 |
| Act 3 일반 / 엘리트 | 90% 이상 / 70~85% | 시너지로 쓸어버림 + 엘리트 긴장 |
| 최종 보스 | 55~80% | 마지막 고비 |
| 36층 완주 | 5~15% | |

## 그 밖에 볼 것
- 골드: 후반에 쌓이기만 하고 쓰이지 않으면(300 이상 남음) 상점·대장간 가격 점검.
- 대장간 강화 합계: 36층 도착 시 15 안팎 (+5 완성 유형 1~2개 목표, GDD 8.6).
- 퇴화 전략: 한 유형·한 카드만으로 쉽게 이기면 그 요소를 따로 시험 (`sim/cards.sim.ts` 방식).
