# Balance Check (D-385)

## 도구 — 둘을 섞지 않는다 (사용자 결정)
- **퀵 등반 머신** `npm run climb -- --styles search,greedy,naive,random --asc 0,4,8,13 --n 50 --jobs 4`
  화면 없이 `src/sim/runbot.ts`(실제 대국 엔진 + 봇)로 출하를 돌리고 **표 한 장만** 찍는다 — 토큰 · 세션 절약. 원자료가 필요하면 `--out sim/climb-<날짜>.json`.
  50판 × 조합 4개 ≈ 2분(4코어). 결과 표를 그대로 보고에 붙인다(로그를 읽지 않는다).
- **화면 리뷰** `npm run review -- <폴더>` (프리뷰 서버 4173이 떠 있어야 함): 실제 단추를 누르며 한 판을 끝까지 — 멈춤 · 오류 · 깨진 화면만 본다. 밸런스 수치는 재지 않는다.
- 아이템 힘 값 · 짝 비교는 `sim/relic.sim.ts`, 부품 칸 점검은 `sim/slots.sim.ts`.

## 목표 띠 (D-316 · D-382 — 슬더스식 계단)
| 봇 · 승급 | 목표 완주 |
| :-- | :-: |
| 보통(greedy) 승급 0 | 35 ~ 40% |
| 무뇌(random) 승급 0 | 15% 아래 |
| 두뇌(search) 승급 0 → 13 | 단계마다 조금씩 내려가 13에서 20 ~ 35% (한 단계에서 15%p 넘게 떨어지면 절벽) |
| 반장별 승률(보통) | 60 ~ 85% |
- 손 놓은 턴(태엽이 남고 낼 카드가 있는데 끝낸 턴)은 봇 실수가 아니라 측정 오차다 — 높으면 봇부터 고친다.
- 50판 표본은 ±13%p — 차이가 그보다 작으면 판정하지 않는다.
